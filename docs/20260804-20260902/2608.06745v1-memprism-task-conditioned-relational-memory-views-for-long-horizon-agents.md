## 摘要
长时程智能体依赖记忆来复用经验，然而现有的记忆系统通常假设证据可以直接通过固定表示来消费。这会导致表示不匹配，即相关信息可用却未针对当前决策进行组织。为此，我们提出MemPrism，一个任务条件化的关系记忆框架，将持久经验存储与决策时的工作记忆分离。MemPrism将交互记录为事件流，并根据当前任务上下文动态构建关系视图。一个轻量级视图策略选择关系结构、证据范围、结果条件和粒度，而确定性的组合器和渲染器将历史事实转换为临时的视觉工作记忆视图，以供冻结的任务策略使用。在长时程具身智能体和网页智能体基准上的实验表明，MemPrism能够持续提升任务性能，尤其是随着轨迹变长，同时降低记忆令牌消耗。此外，学习到的视图策略无需额外适配即可跨不同的视觉语言模型迁移，展示了任务条件化关系视图作为智能体通用记忆接口的有效性。

## Abstract
Long-horizon agents rely on memory to reuse experiences, yet existing memory systems often assume that evidence can be directly consumed through a fixed representation. This leads to representation mismatch, where relevant information is available but not organized for the current decision. To this end, we propose MemPrism, a task-conditioned relational memory framework that separates persistent experience storage from decision-time working memory. MemPrism records interactions as the event stream and dynamically constructs relational views according to the current task context. A lightweight view policy selects the relation structure, evidence range, outcome condition, and granularity, while a deterministic composer and render transform historical facts into a temporary optical working-memory view for a frozen task policy. Experiments on long-horizon embodied and web-agent benchmarks show that MemPrism consistently improves the task performance, especially as trajectories become longer, while reducing memory token consumption. Furthermore, the learned view policy transfers across different VLMs without additional adaptation, demonstrating the effectiveness of task-conditioned relational views as a general memory interface for agents.

# MemPrism：任务条件化关系记忆视图——详细论文总结

## 1. 核心问题与研究动机

现有长时程智能体的记忆系统通常遵循一个隐含假设：**一旦相关证据被存储并被检索出来，就可以通过一种固定不变的表示形式直接提供给任务策略使用**。然而，论文指出这一假设并不成立——在实际决策中，同一段历史事实可能需要以不同的关系组织形式呈现才能发挥效用：回路检测需要对比重复动作与其结果，状态追踪需要将同一实体在不同时间的变化进行归并，失败分析需要将动作与环境反馈相关联，而依赖分析又需要把时间上相隔较远的相关事件串联起来。时间线、状态表、动作-效果视图和依赖追踪可以由完全相同的事实构建，但各自凸显的却是不同类型的证据。

论文由此提出并命名了**“检索后表示不匹配”（post-retrieval representation mismatch）**这一新的失败模式：相关证据已存在且已被检索到，但采用的表示方式没有暴露当前决策所需的关系结构——这不是存储失败，也不是检索失败，而是位于检索到的证据与任务策略之间的“读取时接口”问题。核心的观察是：

> **获取了正确的证据，是否就能保证它对当前决策有用？**

## 2. 方法论

### 2.1 核心设计思想

MemPrism依据上述观察提出一条关键原则：**持久性记忆应保存稳定、可复用的交互事实，而工作记忆则应针对当前决策来按需构建**。框架将二者的建构解耦为两个层面：

- **持久历史层**：以统一的事件流（event stream）格式记录真实交互，保证事实不被破坏或不可逆扭曲；
- **临时工作视图层**：在每个决策时刻，依据当前的任务上下文，从事件流中按需构建一个临时的、任务条件化的关系视图供策略消费；该视图只服务当下的决策，用完即弃，**永不写回持久记忆**。

### 2.2 五个模块

MemPrism由五个模块构成。前四个形成推理管线，Adapter仅用于训练阶段：

| 模块 | 功能 |
|---|---|
| **Recorder（记录器）** | 持久化存储每次真实交互，保留原始事件（观测、动作、反馈、奖励、元数据），并经事件提取器Φ与规则校验映射为结构化事件：主实体、规范化动作类型、结果类型（异常/状态更新/无变化）、稀疏状态更新集合、可选附加证据（标签、图像、包围盒等）。最新状态值按需跟踪。 |
| **Router（路由器）** | 依据当前观测、任务目标、近期事件特征与全局历史统计量编码决策状态，从**144个联合视图动作**（4种关系类型 × 3种时间范围 × 4种结果过滤 × 3种粒度）中选出一个视图配置，而非直接输出环境动作。采用联合分布建模以便保留四个因子间的依赖关系。 |
| **Composer（组合器）** | 依据所选视图动作先进行事件范围筛选（时间范围、结果过滤），再恢复与任务目标直接匹配的事件，最后构建关系特定结构。支持四种关系视图：TemporalTrace（时间线）、ActionEffect（动作-效果）、EntityState（实体状态）、DependencyChain（依赖链）。 |
| **Render（渲染器）** | 用固定的视觉语法将关系结构映射为光学工作记忆视图：空间邻近编码分组、行列对齐支持状态比较、箭头表示变化或依赖、高亮标记失败和任务相关证据。渲染是确定性、无参数的。 |
| **Adapter（适配器）** | 只在训练期启用，通过两阶段方式训练Router：先经由动作条件化的软监督（视图教师蒸馏）做**决策条件化初始化**，再用**分组GRPO**在真实环境中用任务级奖励做**结果导向优化**。任务策略、事件提取器、组合器与渲染器在全过程中冻结不动。 |

### 2.3 视图动作空间

视图动作由四个因子联合定义：

- **关系类型 τ**：TemporalTrace、ActionEffect、EntityState、DependencyChain；
- **时间范围 w**：近短（最近6条）、近长（最近10条）、全部；
- **结果过滤 c**：全部、仅异常、仅状态更新、仅无变化；
- **粒度 γ**：粗、中、细。

总计 4 × 3 × 4 × 3 = **144种联合视图动作**。

### 2.4 训练方法

**阶段一（监督蒸馏）**：离线状态下，视图教师以当前观测、目标、历史事件和参考下一动作为条件，输出视图动作的软分布，Router最小化KL散度并加上结构成本正则项，避免不必要的大范围或过细视图。

**阶段二（分组GRPO）**：每个任务采样G条轨迹，将组内收益归一化得到轨迹优势值，所有视图决策共享该优势。采用带裁剪的PPO目标加参考策略KL约束和熵正则。**只有Router被更新**，因此收益信号专门用于学习“如何呈现历史”，而不改变任务策略本身。

## 6. 主要结论与发现

1. **MemPrism显著提升任务成功率**：ALFWorld上SFT+GRPO达到40.71% SR（超过最强基线LangMem 2.44个点）；EB-ALFRED达到17.7% SR（超过Full History 7.4个点）；Mind2Web达到12.87%整体动作准确率（超过Full History 4.08个点）。
2. **长时程优势随轨迹延长而扩大**：Full History在≤30步后停滞，而MemPrism在≤30至≤50步之间仍增益9.3个点；同时提示token保持稳定（642–852之间），在≤50步处相比Full History减少33.6% token并提升9.3个点SR。
3. **“表示不匹配”假设获得直接证据**：相同证据窗口下不同固定关系视图SR在30.00%–35.71%间波动，最大差距5.71个点，说明信息在场但组织方式决定可用性。
4. **动态组织与光学呈现互补贡献**：光学呈现独立贡献3.57个点，动态组织独立贡献5.00个点，二者组合效果最佳。
5. **粒度是影响最大的视图因子**：固定为细粒度时性能下降最大（-7.84个点），其次为固定视图类型（-4.99）、固定时间范围（-2.13）、固定结果过滤（-0.70）。
6. **上下文条件化选择优于频率匹配**：频率匹配随机仅30.71% SR，而SFT达到34.29%，GRPO进一步到40.71%，证明收益不能由视图配置的边缘使用频率解释。
7. **视图策略可跨VLM零样本迁移**：同一规划器对四种VLM均带来增益（+2.26～+9.40个点SR）和token压缩（30.6%–48.15%）。

## 7. 优点

- **问题定义新颖且清晰**：明确提出“检索后表示不匹配”作为独立于存储失败与检索失败的第三类记忆瓶颈，构建了“持久存储与工作记忆解耦”的框架性解答。
- **设计概念优雅**：将记忆接口紧凑地参数化为四个可解释因子的联合动作空间（关系/范围/过滤/粒度），通过冻结任务策略来隔离并精确归因于记忆表示接口的贡献，在方法论上是干净的实验设计。
- **训练策略有层次**：先经由教师蒸馏获得上下文条件化的初始选择能力，再用分组GRPO用任务级奖励做端到端对齐，且KL约束限制了策略偏离参考——训练信号既直接又稳定。
- **光学视图的用法有深度**：不只是压缩历史的媒介，而是利用二维布局的语义（空间邻近、行列对齐、箭头、高亮）显式暴露关系结构的“结构化接口”。
- **实验验证充分且角度多元**：除了主角度SR之外，还覆盖了token消耗、轨迹长度效应、跨VLM迁移、分辨率敏感性、每因子的独立贡献等，有助于系统理解方法的行为。
- **工程可复现性好**：附录包含完整的提示词模板、解析规则、训练超参数、运行清单说明、基线对齐协议和公平性控制措施。与AgentOCR的光学基线对比时也诚实地说明token口径差异，不做过度的预算匹配声明。

## 8. 不足与局限

- **整体成功率仍然偏低**：即使在MemPrism最优设置下，ALFWorld也只有40.71% SR，Mind2Web仅12.87%，说明长时程智能体任务的整体难度仍然很高，方法只改善了记忆接口这一环节，远未达到逼近解决的程度。
- **视图空间离散且有限**：144种联合视图配置虽然覆盖面可观，但仍是人为设计的离散空间；真实任务中可能存在当前枚举之外的必要关系组织形式。此外ALFWorld上DependencyChain视图最终选择频率为0%，各视图类型的适用性和方法论价值在不同环境之间有显著差异。
- **视觉基准的覆盖存在明显短板**：EB-ALFRED的Visual子集在所有方法下均为0% SR，论文未深入分析原因，也没有说明MemPrism在这种纯视觉任务上的调整方案或失败机制，这是实验充分性上的一个明显缺口。
- **跨VLM迁移样本量有限**：只测试了4种Qwen系/MiniCPM模型，全部是7B及以下的较小规模模型，未涉及更大规模（如70B级）或更多样化的模型架构；规划器的文本编码器（MiniLM）与任务模型的视觉能力之间的交互也可能存在隐藏的架构依赖。
- **外部基线覆盖有取舍**：CFG-Bench作为转移基线改变了任务策略参数，被合理排除在受控比较外；但RL版的AgentOCR和MemOCR因联合训练任务策略等原因未纳入，虽附有理由，仍使“与最优光学记忆系统对比”的说服力打了折扣。
- **相对收益随模型能力变化的趋势不明确**：跨模型实验中，规划器在较强模型（Qwen3-VL-4B）只带来+2.26个点的提升，而在较弱模型（MiniCPM-V-2.6）带来+9.40——这种趋势可能意味着更强任务策略对记忆视图的依赖度降低，但论文未讨论这层含义。
- **GRPO训练的成本较高**：需要在线rollout（每迭代128条轨迹）并在H200×8上训练24–48小时，对算力受限的研究组复用门槛不低；Router输入中使用的全局统计量、窗口统计量的编码方式也较复杂且带有一定的启发式设计痕迹。
