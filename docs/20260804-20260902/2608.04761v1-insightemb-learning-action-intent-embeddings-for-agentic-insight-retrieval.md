## 摘要
自我改进的智能体会从先前的轨迹中积累可复用的洞察，这使得检索对于将积累的经验转化为可操作的指导变得越来越重要。在每个决策步骤中，检索到正确的洞察有助于智能体朝着其目标前进，我们将这种场景称为智能体洞察检索。然而，现有的检索方法主要建模语义相似性，而忽略了一条被检索到的洞察是否解决了智能体当前的决策瓶颈。我们提出了InsightEmb，一种对比嵌入框架，仅使用数学推理数据即可学习可迁移的、面向进展的检索几何结构。InsightEmb联合学习将具体情境与抽象启发式规则对齐，并聚类具有相似进展结构的推理轨迹。我们在动态智能体任务和一个静态技能检索基准上评估了InsightEmb。在没有环境特定训练的情况下，InsightEmb在所有这些评估中均有所改进，超越了现有推理嵌入模型的性能。这些结果表明，状态-洞察匹配的几何结构可以跨领域迁移，从而使得仅使用公开可用的推理数据即可进行有效训练，而无需昂贵的环境特定监督。

## Abstract
Self-improving agents accumulate reusable insights from prior trajectories, making retrieval increasingly important for turning accumulated experience into actionable guidance. At each decision step, retrieving the right insight can help the agent progress toward its goal, a setting we refer to as agentic insight retrieval. However, existing retrieval methods primarily model semantic similarity, while overlooking whether a retrieved insight resolves the agent's current decision bottleneck. We propose InsightEmb, a contrastive embedding framework that learns transferable progress-oriented retrieval geometry using only mathematical reasoning data. InsightEmb jointly learns to align concrete situations with abstract heuristic rules and to cluster reasoning trajectories with similar progress structures. We evaluate InsightEmb on dynamic agent tasks and a static skill-retrieval benchmark. Without any environment-specific training, InsightEmb improves over all these evaluations, surpassing the performance of existing reasoning embedding models. These results suggest that the geometry of state-insight matching can transfer across domains, enabling effective training from publicly available reasoning data without expensive environment-specific supervision.

### 一、核心问题与研究动机

- **研究背景**：基于 LLM 的智能体（agent）在交互式环境中执行任务时，需要遵循 ReAct 等推理-行动循环框架。此类智能体可通过从过去轨迹中提取"洞察"（insight，即从经验中蒸馏出的抽象规则和策略）来持续自我改进。然而当洞察库积累到一定规模后，智能体必须**在每一步动态检索最相关的洞察**，以突破当下的决策瓶颈、推动任务向目标前进——该问题被定义为"智能体洞察检索"。
- **核心挑战——抽象鸿沟（abstraction gap）**：查询端是智能体当前的**具体状态**（含任务描述、动作历史、观测），而目标端是**抽象洞察/启发式规则**。二者处于不同抽象层级，相关性的判定取决于智能体的"下一步意图"（当前必须解决什么瓶颈才能继续前进），而非表层主题相似性。标准嵌入模型按语义相似度匹配，往往会检索到主题相关但流程上"过早"的洞察，而非当下能解锁进展的规则。
- **现有工作的不足**：RAG 式经验检索主要针对具体表面对话/文档等工件，表面相似度往往足够；推理导向的稠密检索模型（如 ReasonIR、Llama-NV-Embed-Reasoning 等）虽针对静态查询-文档推理匹配进行优化，但**不面向目标条件下不断演化的智能体状态**，无法评估检索项是否推进智能体朝向目标。
- **核心洞察（跨域结构同构）**：数学启发式检索与智能体洞察检索在结构上同构——具体情境必须匹配到能解决当前瓶颈的抽象规则（如数学题"P（至少一个红球）"匹配"补集计数"，与具身任务中"先解决定位物体的瓶颈"本质相同）。作者提出，**这一从具体情境到瓶颈解决规则的几何结构可以跨域迁移**——用数学推理数据学到该结构后，无需环境特定微调即可迁移到多类智能体环境。

### 二、方法论：InsightEmb

#### 1. 问题形式化

- 目标是**面向进展、目标条件化的溯因检索**：洞察 I 的相关性在于其能否提高期望的"进展量"，而非语义相似：
  - I\* = argmax E[Δ(s_t, g) | agent 使用 I]（公式 1）
  - 推理时用嵌入检索器近似该准则：I\* = argmax sim(f_θ(s_t), f_θ(I))（公式 2）
- **动作意图嵌入定义**：对情境 s =（目标 g、动作历史 h、观测 o），其动作意图是"追求 g 之前必须被解决的潜在瓶颈"。嵌入函数 f_θ 使洞察按该进展条件相关性而非主题相似度排序。

#### 2. 结构类比

- 数学推理与智能体任务共享如下对应：情境（数学题 ↔ 任务+观测）、轨迹（解答步骤 ↔ 动作历史）、洞察（求解启发式 ↔ 执行策略）、抽象鸿沟（具体题面 ↔ 抽象规则）。
- 两域共享一组"瓶颈类别"（搜索/识别、状态转换、验证、错误恢复、结构/布局、先规划再执行）——该类别是蒸馏后洞察的**涌现属性**，而非训练管线中人为指定的标签体系。

#### 3. 两阶段对比训练课程

- **训练数据**（全部来自 MATH 数据集的计数与概率、数论、几何三个领域）：
  - 对每个数学问题运行 5 条轨迹，从随机轨迹子集蒸馏候选洞察；
  - 用实用性过滤器标注：若将某规则前置到问题上能比无洞察基线提高该问题的求解率，则加入 I+，否则作为 I−。标签与可验证的进展挂钩。
- **Stage 1：情境到洞察匹配**——教模型跨越抽象鸿沟：
  - 三元组为（q, I+, I−），q 有三种形式：纯问题陈述、问题+完整 CoT 轨迹、问题+截断轨迹（对应智能体不同决策阶段的无历史/完整历史/部分历史状态）；
  - 洞察包含两个粒度：BUNDLE（多规则概要）与 ATOMIC（单条规则）；
  - 训练损失为 InfoNCE：L1 = −log exp(sim(f(q),f(I+))/τ) / Σ exp(sim(f(q),f(I))/τ)（公式 3），τ=0.01，使用批内负样本；
  - 共 11,950 对训练样本。
- **Stage 2：情境到经验匹配**——教模型识别不同外观但同策略结构的情境：
  - 三元组为（q, T+, T−），T+ 为结构相似的已解决问题，T− 为不相似的问题；洞察替换为轨迹；
  - 2,896 个训练样本；从 Stage 1 检查点初始化继续训练。
- **推理（动态洞察检索）**：无需任何目标环境微调。每步将智能体当前状态加上任务特定的指令前缀编码，与预先编码的洞察库做 top-k 余弦相似检索，检索到的洞察前置到 LLM 的动作生成提示中。

### 六、主要结论与发现

1. **数学仅训练的指导嵌入提升动态 agent 任务成效**：ALFWorld 中 BUNDLE 与 ATOMIC 条件下 InsightEmb 较 Base 均提升约 5 个百分点（60.71 vs. 54.29；59.29 vs. 55.00）。WebShop 中 BUNDLE 情景下 InsightEmb 将 Base 显著性降低的成绩（18.42）提升至 31.74，几乎与行为不可用但无洞察的基线水平持平（31.03）。ScienceWorld 中 InsightEmb 在 ATOMIC top-1 条件下以 10.20 超过 Base 的 7.40，且所有洞察配置均使不可用基线 2.40 提升两倍以上。
2. **降低噪声池下的检索风险**：WebShop BUNDLE 与 Base 采用结果显著低于无检索基线，显示基于进展的检索能起到比语义检索更重要的作用——**将有害检索的设定逆转为可靠且有用的设定**，实现安全的下游使用。
3. **推理导向的检索器不能被直接替代**：InsightEmb 在 ALFWorld 与 WebShop 中于每个 k ∈ {1,3,5} 均超越 ReasonIR-8B 与 Llama-NV-Reasoning-3B。这些强推理检索器仅在相关定义为支持静态查询与文档的语义空间内给出准确结果，而 agentic insight retrieval 需面向步骤即时可执行性与状态感知的动作意图匹配。
4. **跨域训练优于域内微调**：即便 ALFWorld 域内数据量更大，InsightEmb 仍以 60.71 超过 ALFWorld 域内检索器的 57.86。几何多样性指标（成对余弦距离、最近邻距离、协方差有效秩）显示：数学情境-规则对覆盖的嵌入区域远比 ALFWorld 的更广且体现更高维秩结构，故其可泛化到界外瓶颈配置。
5. **双向迁移验证结构同构**：ALFWorld 微调模型同样提升数学各领域洞察检索准确率，证明共享的几何结构并非单向快捷方式。数学中多阶段情境锚点（截断轨迹）移除会清除该增益的大部分（ALFWorld 中 83%、WebShop 中 49%），支撑了领域间瓶颈解析迁移依赖跨扩展状态的对比学习前提。
6. **机制上，InsightEmb 进行程序性匹配而非主题性匹配**：其检索洞随任务分阶段动态转移（从搜索 → 验证/状态转换），而 Base 的检索分布基本固定；在 WebShop 中，它引导智能体进行变体选择、循环规避与流程排序；在 ScienceWorld 中，它带来更强的状态变量意识、动作排序与失败模式规避。
7. **稳健**：增益在洞察源（DeepSeek-R1/GPT-5.2）、行动模型（Qwen3-8B/GPT-5.2）、检索粒度（BUNDLE/ATOMIC）、检索预算（k=1/3/5）及三项 agentic 环境上均保持一致。

### 七、方法亮点与贡献

1. **问题重新定义清晰且具有很高实用价值**：将"检索什么经验"重新表述为目标条件化的动作意图匹配，并以操作瓶颈是否解决而非主题相似度作为相关性标准，准确识别出 agentic experience memory 设置中的真实失败模式。
2. **核心设计思想极具启发性**：将数学推理与智能体执行在结构上类比并利用数学数据完成跨域无标注训练，与"思维链检索进展相关"的可靠世界观相吻合；新兴共同瓶颈类别进一步呈现了数据本身蕴含结构的外在证据。
3. **标签与目标直接对应**：利用"能否提升 solve rate"来判断正/负样本，将对比标签与证明的（而非作者指定的）进展标准对齐，并联合使用多种查询粒度（纯问题/截断轨迹/完整轨迹），较好地控制了一种情境到多种状态阶段的迁移。
4. **验证层次全面且有说服力**：静态检索基准 + 动态 agent 执行 + 域内微调基线 + 推理导向检索器对比 + 双向迁移实验 + 逐游戏机制分析的组合，远超大多数仅报告端到端分数的经验工作。
5. **高质量分析型报告**：对失败条件、噪声池风险（无检索比低质量检索更好）、为何数学多样性优于域内 ALFWorld 数据等多个反直觉结果进行了清晰且可复现的研究，并给出相应补救措施（BM25 混合方案及其适用范围）。
6. **对实际部署的建议**：洞察池在不同环境下可能成为质量异构的风险，通过在无帮助池上的安全检索给出了低风险 RAG 的应用先例，且定量消除了模型/语料偏差的主要混叠效应。

### 八、不足与局限

1. **动态检索缺金标签**：在线 agentic retrieval 无法获得状态级"最优洞察"的黄金标注，下游任务成功率仅对检索质量给出间接（可能有噪声）证据；未来若设计更细粒度的逐状态评测指标将提升内部有效性。
2. **行动模型与洞察生成覆盖面仍窄**：虽然引入 ScienceWorld、GPT-5.2 行动模型及 GPT-5.2 生成源作稳健性检查，但主实验行动模型仍集中于单一的 Qwen3-8B 族中，主要生成源也集中于单一封闭模型；更多 LLM 与环境类别（如视觉、多模态任务）可进一步提升一般性声明强度。
3. **Stage 1 截断轨迹锚点的标签复用**：对部分（中间）轨迹查询复用与纯问题和完整轨迹相同的 (I+, I−) 集合，而未考虑状态到轨迹阶段的不同——某个在当前阶段无效、但在更早/更晚阶段可能有用的洞察也会被遗漏；未来可构造真正的状态条件偏好对，进一步区分相关性的选择。
4. **MedCalcBench 反向更新风险**：在医学计算族上 R@1 相对基准有显著回退（92.73 → 63.27），恢复预期要求必须采用混合形式（BM25 顶层重排）；文档虽明确给出了关于预期及适用条件范围的说明，但显著弱化了相应嵌入模型的总体能力：即用户需要额外预筛才可获得至少同等有效性。
5. **提升幅度相对次要**：特别是 ScienceWorld 的绝对成功率为 8–10%，表明最终端任务收益微小，仍受行动模型步骤限制；检索嵌入优化不能补偿行动模型程序上的缺陷。
6. **计算开销未充分量化**：未报告训练时长或完整成本对比，未估算推理期滚动嵌入、推理、循环评估的总成本——由于动态嵌入需在每步状态编码，真实世界实际应用中成本不一定可忽略，尤其大规模洞察库存在索引更新开销。
7. **算术评估的评估形态限制**：最后以受控推理数据完成训练，尚未系统证明指标提升源于本框架特定机制贡献（对比物节选或结构设计等双关考虑上缺少谨慎限定），但方法逻辑合理，主要结论中的几何假设中仍存在某种程度上的形式“软定义”（潜在瓶颈”。

### 九、总结评分

InsightEmb 是一项思路新颖、验证较为扎实的检索嵌入工作。其将数学推理与智能体执行类比、并用纯粹跨域数据训练以构筑"面向动作/面向进展"的检索几何，在动态与静态多个评测中胜过语义及推理导向检索器与经验型域内微调模型，且通过双向迁移、消融与机制分析夯实了核心论断。其主要短板，除硬件细节与耗时信息不充分披露外，还主要体现在多种实现选择对泛化能力与外部独立有效性的限制（如行动模型与 LLM 的覆盖范围、对单源洞察的依赖、部分标签及循环嵌入系统带来的工程成本）。整体来看，论文贡献了高质量的问题界定观点支撑，且实用性普遍较强，实验逻辑完备，属于高水平的智能体检索方向研究工作，在相关领域具良好启发价值。
