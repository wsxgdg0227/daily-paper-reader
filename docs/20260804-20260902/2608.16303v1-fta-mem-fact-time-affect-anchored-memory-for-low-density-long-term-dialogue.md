## 摘要
长期情感支持智能体需要记忆机制以实现跨会话的个性化理解。然而，情感支持对话通常是低密度的：语句不完整、证据分散，且用户状态随时间演变。现有记忆方法通常依赖于固定单元，如话轮级笔记或会话摘要，这可能会丢失细节或引入冗余噪声。我们提出FTA-Mem，一种面向低密度长期对话的结构化记忆框架。FTA-Mem使用边界保持窗口分割（BWS）形成连贯的情境片段，并构建事实-时间-情感记忆单元（FTA单元），该单元联合编码事实内容、时间依据和情感背景。检索到的单元随后被综合为结构化上下文以生成答案。在ES-MemEval和LoCoMo上的实验表明，FTA-Mem在不同信息密度特征的基准测试上提升了整体长期记忆问答性能。在ES-MemEval上，FTA-Mem达到了0.3871的F1分数和0.6668的BERTScore。进一步分析表明，情境级FTA构建比粗粒度的会话级或过细粒度的话轮对构建更好地平衡了证据保留与构建成本，为长期对话记忆提供了有效的粒度权衡。

## Abstract
Long-term emotional-support agents require memory mechanisms for personalized understanding across sessions. However, emotional-support dialogue is often low-density: turns are incomplete, evidence is scattered, and user states evolve over time. Existing memory methods usually rely on fixed units, such as turn-level notes or session summaries, which may lose details or introduce redundant noise. We propose FTA-Mem, a structured memory framework for low-density long-term dialogue. FTA-Mem uses Boundary-preserving Window Segmentation (BWS) to form coherent situation fragments, and constructs Fact-Time-Affect Memory Units (FTA Units) that jointly encode factual content, temporal grounding, and affective context. Retrieved units are then synthesized into structured context for answer generation. Experiments on ES-MemEval and LoCoMo show that FTA-Mem improves overall long-term memory question answering across benchmarks with different information-density characteristics. On ES-MemEval, FTA-Mem achieves 0.3871 F1 and 0.6668 BERTScore. Further analysis shows that situation-level FTA construction better balances evidence preservation and construction cost than coarse session-level or overly fine-grained turn-pair construction, providing an effective granularity trade-off for long-term dialogue memory.

- **研究问题**：低密度长期对话的记忆应在**何种粒度**上构建？什么才应该算作一个**可检索的记忆单元**？
- **核心主张**：FTA-Mem 提出用"情境级（situation-level）"的事实-时间-情感（Fact-Time-Affect）三元联合单元来表征长期对话记忆。

## 2. 方法论

### 2.1 整体框架

FTA-Mem 以外部结构化记忆 M 作为对话历史的中间表示，推理时根据问题 q 检索出记忆子集 M_sub，生成答案：
- a* = arg max pθ(a | q, M_sub)

核心问题转化为：**如何构建足够紧凑、可检索，又能保存事实证据、时间有效性和情感背景的记忆单元**。整体流程分为四步：对话轮次 → BWS 分段 → FTA 单元构建与链接 → 检索与回答。

### 2.2 Boundary-preserving Window Segmentation (BWS)

- **理论依据**：受事件分割理论（Event Segmentation Theory）启发，在进行记忆构建前先将对话切分为连贯的**情境片段（situation fragment）**。
- **工作方式**：
  - 对窗口大小为 W 的连续窗口，调用基于 LLM 的边界检测器 gφ，输出连续话轮区间和边界线索（话题变化、情感转变等）；
  - **边界保持策略**：不是以固定步长滑窗，而是将下一个窗口的起点重新定位到最后一个检测片段的开头（s ← bK），对窗口尾部的边界不确定内容用后续上下文重新处理；
  - 只完结最后一个检测片段之前的片段，最后一段保持"临时"状态进入下一窗口；
  - 若检测器只返回一个覆盖全窗口的片段，则强制推进至少一步以避免死循环；到达会话末尾时终结所有片段。
- 输出为每个会话的连续片段序列 F_i = {f_i,1, ..., f_i,L_i}，每个片段作为构建记忆单元的证据范围。

### 2.3 Fact-Time-Affect 记忆单元

理论上受 Tulving 的情景/语义记忆区分，以及 Zwaan & Radvansky 的情境模型（situation models）启发。基本节点格式为：

**m = ⟨xF, xT, xA, e, o⟩**

| 字段 | 含义 |
|---|---|
| xF（事实锚） | 事实性声明、情境类型、参与者、摘要 |
| xT（时间锚） | 对话时间、事件时间、时间朝向、情境完结状态 |
| xA（情感锚） | 情绪、意图、关系线索等主观情境 |
| e（证据指针） | 指向原始对话片段，支持溯源 |
| o（构建状态） | complete / partial / pending / unknown |

对一个片段 f_i,j 和未决单元 I_i,j，用 LLM 抽取器构建候选 FTA 单元（公式略），并规定了一个**状态推进规则**：片段 j 的 partial 单元会携带到片段 j+1——M_i,j+1 = {m ∈ M_≤i,j | o(m) = partial}，以确保跨片段不完整性不丢失。

### 2.4 单元整合与时间链接维护

两层维护机制：
1. **局部跨片段融合**：当新候选单元 m̃ 与从相邻片段传来的未决单元 m_p 兼容且能补全/细化它时，执行 m_p ← Fuse(m_p, m̃)。合并后的内容不获得独立记忆 ID。
2. **时间链接（Temporal Link）**：每个新存储单元与历史单元按嵌入相似度检索候选邻居，关系分类器标注为 same-situation / update / contradiction / follow-up / support / unknown，非 unknown 关系写入记忆图：E_r ← E_r ∪ {(m, m′, r)}，用于追踪情境是否被完成、修正、推翻或佐证。

此外，每个会话结束后更新**纵向辅助记忆**：用户语义记忆 U 和支持经验记忆 H。

### 2.5 检索与上下文合成

- **查询改写**：将原始问题改写为面向证据的检索查询 q′，保留显式实体、时间表达、关系和任务意图。
- **打分函数**：

  R(q′, m) = λ·s_emb(q′, ρ(m)) + (1 − λ)·c(q′, m)

  其中 s_emb 为嵌入相似度，c(q′, m) 为基于时间、情境类型、参与者、情感背景的结构化线索得分。
- **Top-K 初选**：M_sub = TopK_K{ m | R(q′, m) ≥ τ }。
- **邻居扩展**：对每个检索单元扩展 B 个有链接的邻居（用于捕捉更新/矛盾/后续证据），按记忆 ID 去重并依照时间排序。
- **结构化上下文包 P_q = Syn(M_sub, L_sub, A_sub)**：将主要内容分成主证据单元、链接邻居、源对话片段、辅助纵向记忆四类，而不是把检索结果当作扁平的段落列表；每单元保留证据指针 e(m) 以便在原始对话中溯源。
