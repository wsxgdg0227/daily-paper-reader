## 摘要
记忆正成为长周期LLM代理的核心基础设施，然而现有评估对于在不同运行机制下应使用哪种记忆底物（即记忆表示和存储的底层介质）提供的指导有限。我们提出了一种对记忆增强代理的记忆底物进行受控的测试平台评估，涵盖密集与稀疏索引、文本记录、结构存储、层次存储、基于精炼的记忆、参数更新以及与激活兼容的上下文机制。在三个骨干模型和四个基准套件（涵盖以用户为中心的事实问答和以代理为中心的决策制定）中，我们在统一测试平台下测量了26项性能与效率指标。结果表明，没有单一底物能持续占据主导地位：广泛的检索有利于长上下文事实问答，而过多的检索可能通过将注意力从行动关键上下文转移而损害顺序决策。可扩展性引入了另一条路由轴，因为在中度历史长度下表现良好的底物在更长周期下可能变得昂贵或脆弱。这些发现促使底物路由成为自适应代理记忆系统的必要组成部分，并为设计高效、可靠且感知机制的LLM代理长期记忆提供了经验指导。代码将在接收后公开。

## Abstract
Memory is becoming core infrastructure for long-horizon LLM agents, yet existing evaluations offer limited guidance on which memory substrate, namely the underlying medium in which memory is represented and stored, should be used under different operating regimes. We present a controlled harness evaluation of memory substrates for memory-augmented agents, covering dense and sparse indices, text records, structural stores, hierarchical stores, refinement-based memories, parametric updates, and activation-compatible context mechanisms. Across three backbone models and four benchmark suites spanning user-centric question answering and agent-centric decision-making, we instrument 26 performance and efficiency metrics under a unified harness. Our results show that no single substrate consistently dominates: broad retrieval benefits long-context factual QA, while excessive retrieval can harm sequential decision-making by shifting attention away from action-critical context. Scalability introduces a further routing axis, as substrates that perform well at moderate history lengths can become costly or brittle at longer horizons. These findings motivate substrate routing as a necessary component of adaptive agent memory systems and provide empirical guidance for designing efficient, reliable, and regime-aware long-term memory for LLM agents. ## 1. 核心问题与研究动机

- **背景**：基础模型代理正从单轮助手向长周期（long-horizon）应用演进，需要持久化记忆支撑编码助手、网页代理、个人伴侣及科学发现代理等场景。
- **核心问题**：记忆底物（memory substrate，即记忆表示与存储的底层介质）种类繁多——向量索引、文本记录、知识图谱、层级树、精炼记忆、参数更新、KV缓存激活等——各自存在准确性、效率与成本之间的权衡，但**没有任何单一底物在所有三维度上都最优**；而现有评测几乎无法为"在何种运行制度（regime）下选用何种底物"提供实证指导。
- **现状调查的三大缺口**（基于对 2023–2026 年间 52 个记忆增强系统的全景分析）：
  - **基准集中**：62% 的评测集中在 LoCoMo 与 LongMemEval 两个对话类数据集，代理中心（agentic）任务几乎未被考察；
  - **指标与骨干模型狭窄**：所有系统均报告准确率，但仅 21% 报告任何效率指标；81% 的系统仅用 GPT 系列作为骨干模型；
  - **评测范围浅**：一半系统只在单一基准上评测且不报告任何效率指标，没有任何系统同时做到广覆盖与全面效率报告。
- **整体含义**：设计通用自适应记忆系统（universal memory harness）需要了解底物在何种运行制度下更优，以实现"底物路由"（substrate routing）。

## 2. 方法论：核心思想与关键技术细节

- **总体思路**：将记忆底物作为唯一实验变量，在统一 harness（提示模板、骨干模型、辅助 LLM 设置均固定）下做受控横向评估，从而量化"底物单独对行为的影响"及其跨运行制度的稳定性。
- **底物分类学**：采用外部记忆（信息存储于模型外的数据结构，通过显式操作写入与检索）与内部记忆（信息编码于模型权重或激活中，生成时隐式访问）的二分类，共实现 **11 种方法（M1–M11）覆盖 7 大底物家族**：
  - **Flat Index（扁平索引）**：M1 Dense Vector（1536 维 dense top-k）、M2 Sparse Vector（BM25 top-k），均不调用辅助 LLM；
  - **Text Record（文本记录）**：M3 Gist Index（借鉴 ReadAgent，写入时逐页 LLM 生成 gist 摘要，读取时选择页展开）；
  - **Structural（结构化）**：M4 Evolving Notes（A-Mem 式带链接笔记+演化触发重写）、M5 Dual-Level Graph（LightRAG 式实体-关系图+块级向量混合检索）；
  - **Hierarchical（层级化）**：M6 Hierarchical Tree（RAPTOR 式递归聚类摘要+折叠树检索）；
  - **Refinement（精炼/提炼）**：M7 Distilled Strategies（ReasoningBank 式轨迹判定+策略提取）、M8 Skill Bundles（MemSkill 式经验聚类技能包）；
  - **Weight（权重）**：M9 Adapter Tuning（LoRA-FA，r=8，QA 对监督微调，参数化记忆）；
  - **Activation（激活）**：M10 Full Context（全历史拼接+截断）、M11 Episode-Clustered Re-prefill（EpiCache 式情节聚类+按匹配情节重填充）。
- **关键设计选择**：论文刻意排除法确定哪些方式值得进入主对比；MemGPT、Mem0、Zep 因辅助 LLM 成本过高（单次 LoCoMo 运行需 2,700–9,000 次调用、11–23 小时）仅做辅助成本分析。
- **消融/诊断手段**：
  - 检索深度 k 扫描：LoCoMo 上 k∈{1,2,5,10,20}，ALFWorld 上 k∈{1,2,3,4,5}，并设置空检索块的 no-memory 基线；
  - 上下文长度压力测试：MAB CR 能力下 6K / 32K / 262K token 三档；
  - 注意力探针：对响应令牌到 System/Retrieved/Context/Cue 四区域的注意力质量做归因分析。

## 3. 实验设计：数据集、基准与对比方法

- **骨干模型（3 个）**：Qwen3-8B、Qwen3-32B-AWQ、Gemma4-26B-A4B-IT（后者与 M9 LoRA 不兼容而剔除）；辅助 LLM 固定为 GPT-4o-mini（写入、管理、判分均同一模型）。
- **用户中心基准（事实检索型）**：
  - **LoCoMo**：10 段多会话对话、1,986 个问题、5 类问题；
  - **MemoryAgentBench（MAB）**：分为 Accurate Retrieval（AR，即 LongMemEval-S∗ 子集/LME-S）、Long-Range Understanding（LRU）、Test-Time Learning（TTL）、Conflict Resolution（CR）；
- **代理中心基准（决策执行型）**：
  - **ALFWorld**：134 个 valid-unseen 具身规划任务，含 episode 内累积与跨 episode 预建库两种制度，离线库为 100 条 AgentGym 成功轨迹 + 100 条 Qwen3-32B 真实失败轨迹；
  - **BigCodeBench-Hard（BCB）**：148 个代码任务，PYTEST 执行评分，离线跨任务池提供成功/失败代码片段。
- **指标**：共 26 个（P1–P12 性能 + E1–E15 效率），包括 EM、token F1、BLEU-1、LLM judge、Recall@k、任务成功率、目标条件成功率、Pass@1、SubEM，以及记忆体大小、推理/写入/检索延迟、各阶段 token 数、LLM 调用数、总墙钟时间等。
- **对比对象**：11 个底物间对比，并叠加 "No Memory" 基线（同一模板空检索块），另在附录中给出 Zep/Mem0/MemGPT 的辅助成本参考。

## 5. 实验数量与充分性

- **实验规模**：主评测矩阵为 "11 方法 × 3 骨干 × 4 基准"，每个 cell 报告 26 项指标；LoCoMo 含 1,986 queries，LME-S 300 queries，ALFWorld 134 episodes，BCB 148 problems。另有：
  - 检索宽度扫描（k∈{1,2,5,10,20} 与 k∈{1,2,3,4,5}，含注意力探针）；
  - 三档长度（6K/32K/262K）的可扩展性压力测试；
  - 52 系统的评测生态现状调查。
- **充分性评价**：
  - **优点**：这是首个在多个骨干模型、横跨用户/代理中心两大赛道且同时记录性能与全维度效率的统一受控评测；多骨干设计可解耦底物效应与模型行为；统一辅助 LLM 与判分模板控制了混杂变量。

## 6. 主要结论与关键发现

- **结论一：最优底物随运行制度反转**。结构化图底物（M5）主导对话问答（LoCoMo、LME-S 上跨骨干最好），但在代理任务上被帕累托支配；精炼型底物（M7）在 ALFWorld 上领先（Qwen3-32B 上 TSR 32.1% 为全场最高），在 QA 上却表现平平——QA 前沿与代理前沿**无共享底物**。
- **结论二：检索越宽，QA 越好、代理决策越差**。LoCoMo 上所有底物的 P4 随 k 单调上升；ALFWorld 上任务成功率随 k 下降（M7 从 k=1 的 32.1% 跌至 k=5 的约 25%，flat 检索跌到 no-memory 之下）。注意力探针揭示机理：k 增长时注意力从任务 Context 区流出、涌入 Retrieved 区；QA 中答案恰好住在那片区域，所以受益；代理任务中策略依赖的观察/可行动作列表在 Context 区，因此被"饿死"。
- **结论三：可扩展性是第三条路由轴**。外存底物在长历史上普遍质量上升（M8 在 CR 上 0.32→0.51、M5 0.28→0.48），但代价两极化：精炼族（M7/M8）以固定大小表示获得近常数级读成本，缩放优雅；结构化族（M4/M5）的图重建/实体抽取随输入线性扩张，在 262K 处出现部署上限；内部底物中 M10 质量随长度增长但读时线性膨胀，M9 无选择性时序更新机制、CR 上持平无增益（0.18–0.22）。
- **设计法则**：**"以读取广度换取写入深度"**——每次查询少检索条目，把预算投入到写入时的蒸馏与结构化上。
- **总体论断**：无单一底物能赢所有制度；通用智能体记忆必须实现为多底物或多代理系统，按运行制度做角色化组合与路由（精炼底物负责抽象策展、结构化/文本底物负责事实持有、激活/扁平底物负责原始经验留存）。

## 7. 优点与亮点

- **开创性框架**：首次将"记忆底物"作为唯一受控变量做跨 7 家族、11 方法的整体评估，为长时记忆研究提供了可复用的评测 harness（26 项指标，首次系统覆盖写入/读取/管理三阶段的延迟、token、调用、存储成本）。
- **跨制度视角**：同时覆盖用户中心与代理中心两类任务，揭示同一底物在不同制度中的优劣反转，填补了此前代理评测的空白。
- **丰富的诊断工具**：检索深度扫描 × 注意力归因 × 长度可扩展性测试的组合，不只报排行榜，还解释"为什么"——注意力稀释机制的解释很有说服力。
- **模型多样性**：使用 3 个非 GPT 开放骨干（Qwen3-8B/32B、Gemma4），避免了该领域普遍存在的"只测 GPT 家族"的主干偏差；统一辅助 LLM 和判分模板保证了对照公平。
- **诚实的覆盖边界**：

诚实的覆盖边界：论文不回避其评测框架的适用范围与刻意取舍——它明确声明不将外部记忆系统（如 MemGPT、Mem0、Zep）纳入主对比，而是以“辅助调用成本”字段单独列出；也未测试闭源大模型（如 GPT 系列）作为骨干，因为作者希望避免该领域因“只测 GPT”而造成的生态失衡，转而使用开放权重模型以保证结果可复现。同时，任务集采用合成构造的标准基准，而非真实用户日志；底物实现采用有代表性的简化变体（如用零样本 LLM 代替 PPO 控制器），这使得“底物家族行为”的归因更干净，但牺牲了对原始系统“端到端成品”的忠实度。这些边界都在文中有对应警示，并非隐藏。

## 8. 局限性与潜在争议

尽管该评测框架在广度与深度上均为当前少有，但仍存在几项必须指出的风险：

- **统计推断不足**：正文与附录基本只报告单次运行或重复后的均值，未提供置信区间、标准差或正式的显著性检验。虽然作者辩称问题规模足够大（LoCoMo 有近 2 000 个 query），但像 ALFWorld 这类仅 134 个 episode 的代理任务，点估计差异可能仍受环境随机性影响；在没有方差报告的前提下，部分“方法优劣”结论可能存在噪声主导的风险。
- **底物实现的代表性偏差**：文中将每种底物家族映射到一种自制实现。例如 M8（Skill Bundles）使用零样本 LLM 判定经验并聚类，而不是 MemSkill 原版的强化学习控制器；M11 用“重填充”代替原论文基于 KV 缓存的在线编辑。这种“概念化复现”能保证公平对照，但会低估原版系统在真实部署中的工程优化（如缓存管理、混合检索的精细调参），因而对“生产系统实际性能”的结论应持谨慎态度。
- **辅助 LLM 的双重角色混淆了效率归属**：辅助 LLM（GPT-4o-mini）被固定在写入、管理、判分环节，其时间与 token 开销并未归入各底物的 E 指标汇总；而不同底物对辅助调用的依赖程度差异巨大（如精炼底物 M7/M8 每次写入都要调用多次辅助模型，flat 索引几乎零辅助调用）。若把辅助成本也计入总运行时间，底物间的效率排序可能发生改变。论文将辅助成本单独报告，是一种合理取舍，但读者若只用“总墙钟时间”来选型，可能得到偏差结论。
- **外部有效性边界**：所有骨干模型均为开放权重、中等参数规模（8B–32B）；最强的商用模型不在覆盖范围内。而底物路由策略依赖具体模型，例如长上下文能力极强的闭源模型可能使激活类底物（M10/M11）的优势变大。因此，“最优底物随运行制度反转”这一论断在当前结论空间中成立，但不能排除未来模型改变曲线后需要重估。
- **缺少动态生命周期管理实验**：评测的是“一次性加载给定历史”的静态记忆，而对长期运行中持续的写入—过期—合并—遗忘记没有做多轮压力测试（例如连续对话 1 000 轮后记忆库膨胀与检索漂移的问题），这使评测更接近“记忆容量与检索质量”而非“记忆治理”。

## 9. 总结与设计启示

这项研究为记忆增强代理领域提供了一条清晰的前进路径：

- **记忆应是被路由的系统，而非被选中的组件**。没有任何一个底物能够同时在知识密集型 QA 与决策型代理任务中取胜；真实代理应按任务特征（事实打捞 vs. 策略沿用 vs. 长程规划）在精炼、结构化、扁平存储之间切换，或采用多底物协作的架构。
- **“写入少、写得好、读时省”是比“读得多”更有效的策略**。无论对话还是代理场景，每轮检索条目不宜过多；把资源移到写入侧——生成摘要、提取策略、构建链接——反而能带来更稳定的性能。
- **评测必须双向度化**。仅报准确率的时代已经不够；未来的通用代理评测应当至少同时追踪“性能（P 类）”与“成本（E 类）”，否则“更好”可能只是“更贵”的假象。该文定义的 26 项指标可以成为社区后续评测的共同接口。
- **开放基座与固定辅助模型是保证可比性的必要条件**。该文以 Qwen3-8B/32B 与 Gemma4 作为骨干、以统一 GPT-4o-mini 作为辅助，既规避了闭源模型更新的不稳定性，也防止了“骨干换掉了导致记忆差异被混淆”的情况，这一设计应被后续工作沿用。

总体上，该文给“通用记忆 harness”搭建了一个坚实的地基。它没有给出一个“万能底物”，而是给出了一张完整的地图：哪种底物在哪种运行制度下值得部署、代价是什么、机理是什么。对任何想为长周期代理设计持久记忆子系统的人而言，这份评估是不可绕过的参考。
