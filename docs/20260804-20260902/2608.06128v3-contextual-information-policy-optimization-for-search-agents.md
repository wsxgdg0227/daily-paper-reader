## 摘要
搜索代理通过在多步推理中获取和使用外部证据，扩展了大型语言模型超越静态参数化记忆的能力。对于涉及复杂或动态变化信息的知识密集型任务，其可靠性不仅取决于检索相关证据，还取决于利用这些证据来指导后续推理。然而，现有方法主要奖励最终答案的正确性或中间进展，并未直接评估检索后的动作是否基于所检索到的证据。这种错位会鼓励先验驱动的推理：代理基于内部知识形成结论，并主要利用检索来确认这些结论，从而导致确认偏差和证据利用效率低下。为解决这一问题，我们提出了上下文信息策略优化（CIPO），一种面向证据的强化学习框架，显式地将策略优化与外部证据利用对齐。CIPO 为受检索信息影响的推理动作分配密集的、轮级（turn-level）的信用，同时将这种证据利用信号与全局结果奖励相结合，以保持答案正确性。通过这种方式，CIPO 抑制了脱离证据的猜测，并促进了检索到的事实能够指导或修正后续推理的推理轨迹。重要的是，CIPO 既不需要人工过程标注，也不需要额外的奖励模型。在七个领域内和领域外基准上的大量实验表明，CIPO 降低了先验驱动推理的发生率，并在大多数任务上取得了优异的性能。

## Abstract
Search agents extend large language models beyond static parametric memory by enabling them to acquire and use external evidence during multi-step reasoning. For knowledge-intensive tasks involving complex or evolving information, their reliability depends not only on retrieving relevant evidence but also on using it to guide subsequent reasoning. However, existing methods primarily reward final-answer correctness or intermediate progress, without directly assessing whether post-retrieval actions are grounded in the retrieved evidence. This misalignment encourages prior-driven reasoning: agents form conclusions based on internal knowledge and use retrieval mainly to confirm them, resulting in confirmation bias and inefficient evidence use. To address this issue, we propose Contextual Information Policy Optimization (CIPO), an evidence-oriented reinforcement learning framework that explicitly aligns policy optimization with external evidence use. CIPO assigns dense, turn-level credit to reasoning actions influenced by retrieved information, while combining this evidence-use signal with a global outcome reward to preserve answer correctness. With this manner, CIPO discourages evidence-detached guesses and promotes reasoning trajectories in which retrieved facts can guide or revise subsequent reasoning. Importantly, CIPO requires neither human process annotations nor an additional reward model. Extensive experiments on seven in-domain and out-of-domain benchmarks show that CIPO reduces the prevalence of prior-driven reasoning and achieves excellent performance on most tasks.

## 论文详细总结

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：搜索代理（Search Agents）让大语言模型不再局限于静态参数化记忆，能够通过检索工具获取外部证据，在多步推理中动态决定何时检索、检索什么，并将证据整合进推理轨迹中，以应对知识密集、复杂或动态变化的信息需求。
- **核心问题**：现有基于强化学习的搜索代理训练方法存在 **奖励错位（reward misalignment）**——它们只评估最终答案是否正确，或中间推理步骤是否朝正确答案方向进展，而**不直接评估检索后的动作是否真正基于刚检索到的证据**。
- **引发的负面现象——先验驱动推理（Prior-Driven Reasoning）**：模型仅依赖内部参数知识形成结论，检索不再是获取或修正信息的机制，而沦为"事后确认"的工具。这使得模型难以被外部证据纠正，产生确认偏差（confirmation bias），且在长尾知识或幻觉严重时，即使高质量证据已经出现在上下文中，也仍然无法被有效利用，造成证据浪费和可靠性下降。
- **研究意义**：这项工作的核心意图是让搜索代理从"用检索确认自己的想法"转变为"让检索结果真正引导、修正或推翻自己的想法"，从而提升其在知识密集型任务上的可靠性与证据利用效率。


### 二、方法论：CIPO 框架

#### 2.1 整体核心思想

CIPO（Contextual Information Policy Optimization）是一个面向证据的强化学习框架。核心思路是：**通过衡量"证据可见 vs 证据被遮蔽"条件下模型生成同一推理动作的概率差异，判断检索到的信息是否真的影响了该动作；并以此为密集轮级奖励，激励对证据敏感、基于证据推理的策略行为**，同时与最终答案的结果奖励（outcome reward）结合，确保正确性不被牺牲。

#### 2.2 关键技术细节与流程

1. **轨迹分段**：每条轨迹被划分为多个交互轮次（turn），每个检索轮由 `<think>`（推理）、`<search>`（搜索）、`<information>`（环境返回的证据）三类块组成。

2. **目标动作定义**：待评估的动作是检索后下一轮中模型自己生成的 `<think>` 和 `<search>` 块（不含环境返回的证据 Token）。

3. **证据可见与遮蔽两种条件**：
   - **可见条件**：模型正常生成目标动作，可正常注意力访问上一轮的 `<information>` 块；
   - **遮蔽条件**：通过修改注意力掩码（而非删除 Token），在每个 Transformer 层和注意力头，令目标动作的所有 Token **不能关注**上一轮的 `<information>` 块，其余上下文和位置关系保持不变。

4. **EALR 指标（Evidence-Access Log-Likelihood Ratio）公式**：

   \[
   s^{ealr}_{i,t} = \frac{1}{m}\left[\ell_{vis}(a_{i,t+1}) - \ell_{mask}(a_{i,t+1})\right] = \frac{1}{m}\log \frac{\pi_{\theta_{old}}(a_{i,t+1} | h_{i,t}, E_{i,t})}{\pi_{\theta_{old}}(a_{i,t+1} | h_{i,t}, \mathcal{M}(E_{i,t}))}
   \]

   - 描述：在同一策略下，对同一条轨迹中同一个动作，依次计算「证据可见」和「证据被注意力掩蔽」两种条件下的生成对数似然之差，除以 Token 数做长度归一化。
   - EALR > 0：检索到的证据提高了该动作的生成概率，说明动作对证据敏感；EALR ≈ 0：动作对证据几乎不敏感；EALR < 0：遮蔽证据后动作反而更可能。
   - 从期望角度看，EALR 与证据可见/遮蔽条件下两个动作分布的 KL 散度存在理论联系，表明它可视为策略层面的证据访问信号。

5. **稀疏与密集奖励的组内归一化与融合**：EALR 分数和终极结果奖励分别在同一 rollout 组内做标准化（z-score），使两种奖励尺度可比，再进行折扣累积：

   \[
   \hat{A}_{i,t} = \sum_{j=t}^{T_i} \gamma^{j-t} \tilde{r}_{i,j}
   \]

6. **策略优化**：采用类似 PPO 的 clipped 目标，将每个轮次的优势值广播到该轮内所有模型生成的决策 Token 上，同时附加 KL 散度惩罚项防止策略偏离参考模型过远。环境返回的证据 Token 不参与优化损失计算。

#### 2.3 方法特点

- 无需人工过程标注、无需训练额外奖励模型、**无需额外 rollout**——两次似然计算仅需对同一批已收集数据进行额外的 teacher-forcing 推理即可完成；
- CIPO 将"局部证据依赖"与"全局任务成功"解耦，分别用 EALR 轮级奖励和最终结果奖励覆盖，再通过优势函数设计将两者统一。

1. **评估协议引入额外模型依赖**：论文使用 GPT-5.5 对外部 LLM 判断轨迹是"先验驱动"还是"证据驱动"，这种方法本身具有较强的主观性和不可重复验证性；DeepSeek 标注的证据也需要人工检查，但其判定标准与 GPT-5.5 的判定标准可能有系统性偏差；
2. **训练集不完整的背景设置**：训练所用实验数据及其与领域内数据划分规则的描述在正文中较为简略（详细数据集划分细节不够充分），有一定可复现性影响；
3. **搜索环境的作用**：实验使用的是 Search-R1 架构的本地检索服务，论文未在多检索工具（如 Web 搜索、数据库查询、重排序）下验证 CIPO 的鲁棒性；
4. **模型规模覆盖有限**：仅在 3B 与 7B 的 Qwen2.5 上实验，未覆盖更大的模型或不同模型家族，无法验证方法的可扩展性与跨架构普适性；
5. **时间范围与证据时效性**：论文将"动态变化的信息"作为动机之一，但实验数据集中并无对时效性/动态信息更新的专项测试；
6. **最大交互轮数较小**：限制在 5 轮，虽然有效控制了 rollout 成本，但也限制了在更长、更复杂的任务（如多工具深度研究）上的适用性验证；
7. **推断与评测的近似问题**：本文通过"证据可见/遮蔽下的似然差"来近似度量证据使用。存在一个潜在风险——模型生成动作时可能因为将证据以间接方式编码进上下文或对证据做过推理加工，即使 EALR 较低，但证据仍然在推理中被使用；反之，模型也可能因为局部上下文扰动而产生不必要的 EALR 偏高。这种以第二次 teacher-forcing 打分为核心的方法与真实生成场景中的证据依赖仍存在一定偏差。
