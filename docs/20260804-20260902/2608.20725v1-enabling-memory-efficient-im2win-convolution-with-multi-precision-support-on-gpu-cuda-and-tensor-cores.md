## 摘要
卷积是深度神经网络中的主要计算瓶颈，其效率取决于算法与GPU硬件之间的紧密集成。现有的GPU卷积方法存在内存开销大、缓存利用率低、跨卷积核尺寸的有效性有限或数值不稳定等问题。本工作扩展了im2win范式——一种对所有卷积核尺寸具有连续内存访问的通用、内存高效的卷积方法——以在CUDA核心上以全精度和在张量核心上以半精度高效运行。通过引入新的内核设计和优化，如之字形内存访问和异步数据移动，im2win高效利用了硬件加速的半精度矩阵乘累加操作。在十二个CNN基准测试中，im2win的TFLOPS比其CUDA核心实现最高提升2.8倍，比cuDNN高1.4倍，比基于cuBLAS的GEMM卷积高6.4倍，同时其内存使用量分别仅为它们的53%和35%。这些结果确立了im2win作为现代GPU架构的统一高性能卷积框架。

## Abstract
Convolution is a principal computational bottleneck in deep neural networks, and its efficiency depends on tight integration between algorithms and GPU hardware. Existing GPU convolution methods suffer from large memory overhead, poor cache utilization, limited effectiveness across kernel sizes, or numerical instability. This work extends the im2win paradigm -- a universal, memory-efficient convolution method with contiguous memory access for all kernel sizes -- to run efficiently in full precision on CUDA cores and half precision on tensor cores. By introducing new kernel designs and optimizations such as zig-zag memory access and asynchronous data movement, im2win efficiently exploits hardware-accelerated half-precision matrix multiply-accumulate operations. Across twelve CNN benchmarks, im2win achieves up to 2.8x higher TFLOPS than its CUDA core implementation, 1.4x higher than cuDNN, and 6.4x higher than GEMM-based convolution with cuBLAS, while using as little as 53% and 35% of their memory, respectively. These results establish im2win as a unified, high-performance convolution framework for modern GPU architectures.

  - **FFT卷积**：对大卷积核有效，但在小卷积核上延迟高；
  - **Winograd卷积**：对小尺寸固定卷积核可减少计算量，但在大尺寸下数值不稳定；
  - **cuDNN隐式GEMM**：虽然避免了显式中间张量，但实际效果仍受限于内存与缓存策略。
- 本文的核心问题：**能否在兼顾内存效率、缓存局部性、数值稳定性的前提下，实现一种统一的、高性能、多精度的GPU卷积方案？**

### 2. 方法论：核心思想与关键技术

#### 2.1 核心思想：扩展 im2win 范式

- im2win 是一种针对**SIMD架构**提出的高效卷积数据变换方式，核心是将输入张量变换为 im2win 张量 $\hat{I}$，从而使得滑动窗口内的元素在**不同通道间连续排列**，实现连续内存访问和数据复用。
- 与im2col相比，im2win张量消除了重叠窗口的冗余存储：
  - 当 stride $s$ < 滤波器高度 $H_f$ 时，im2win所需内存严格小于im2col；
  - 当 $s = H_f$ 时二者内存一致；当 $s > H_f$ 时不成立（但通常情况下满足 $s \le H_f$）。
- 两个算法步骤：
  - **数据变换**：
    $$ \hat{I}(i, r, m, k \times H_f + u) = I(i, r, m \times s + u, k) $$
    即在通道方向上按卷积窗口重新编组数据，使同一窗口内元素连续存储；
  - **卷积计算**：与直接卷积类似，在变换后的张量上执行乘加操作。

#### 2.2 面向GPU的高性能实现：Tensor Core上的im2win

- 输入输出布局使用**NHWC**，以匹配卷积窗口对连续内存访问的需求。
- 将输出张量映射为二维GEMM维度：$M = C_o$，$N = N_o \times H_o \times W_o$，$K = C_f \times H_f \times W_f$。
- 每个线程块负责一个 $M_B \times N_B$ 的微块（如32×128、64×128）；
- 块内多个warp各自计算 $M_W \times N_W$ 的子块；
- 使用 **WMMA API** 在Tensor Core上执行16×16粒度的矩阵乘累加（mma_sync）。
- 数据加载路径：全局内存 → 共享内存 → 寄存器（WMMA fragment），全程使用16字节向量化load。

#### 2.3 关键优化技术

| 优化技术 | 作用 |
|---|---|
| **索引预计算（Index Precomputation）** | 将固定偏移量在主机端预计算并存于常量内存（constant memory），避免设备端冗余索引计算 |
| **异步数据移动（Asynchronous Data Movement）** | 基于PTX指令实现异步拷贝，使数据搬运和计算并发执行，隐藏访存延迟 |
| **Zig-Zag（之字形）内存访问** | 在线程块调度维度上引入交替方向访问，减少共享内存bank冲突 |
| **双缓冲（Double Buffering）** | 双份共享内存和寄存器缓冲配合异步拷贝，形成生产者-消费者流水线，进一步隐藏延迟 |
| 常规优化 | 分块（tiling）、数据预取、共享内存/寄存器复用、向量化访存等（沿用此前工作[6]） |

#### 2.4 多精度支持

- **CUDA核心版（im2win_CC）**：FP32全精度；
- **Tensor Core版（im2win_TC）**：FP16半精度，利用WMMA硬件加速。
- 半精度在Ampere架构上若不使用Tensor Core往往需要内部转换到FP32，反而降低性能，因此FP16版本强制走Tensor Core路径是合理的架构适配。
