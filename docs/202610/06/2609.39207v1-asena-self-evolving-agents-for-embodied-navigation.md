## 摘要
我们提出了 ASENA，一个具身智能体系统，它将通用编码智能体与机器人感知、计算、监督执行和持久经验相连接。智能体可以编写并执行程序、检查记录的结果、修复失败，并复用笔记和可执行技能，同时保持其模型权重固定。我们进一步引入 ASENA-VLN，一个 4B 单目导航策略，作为该可编程系统中的一个可选工具。ASENA-VLN 使用共享的视觉-语言解码器，在路线指令、视觉问答以及一个新构建的由几何推导的原子导航任务数据集上进行训练，从而为长距离路线和短时程行为预测机体坐标系下的轨迹。作为一个独立策略，ASENA-VLN 在 R2R 上达到 68.7%、在 RxR 上达到 70.2% 的最先进成功率。当与编码智能体集成时，学习到的导航使 ASENA 在两个智能体基准上的成功率提高 11 个百分点，同时减少执行时间。通过持久工作空间演化和模拟器反馈，在反复出现的 100 任务子集上进行十轮后，R2R 上的成功率从 72% 进一步提升到 98%，RxR 上从 65% 提升到 89%。在具身问答任务上，ASENA 以更少的交互步骤达到了最先进的准确率。最后，在 Unitree G1 上的真实世界演示结合了搜索、视觉检查、空间推理和合成手势，且无需预先构建地图，展示了在线编程如何将机器人行为扩展到路线跟随和预定义技能之外。

## Abstract
We present ASENA, an embodied agent system that connects general-purpose coding agents to robot sensing, computation, supervised execution, and persistent experience. Agents can write and execute programs, inspect recorded outcomes, repair failures, and reuse notes and executable skills while keeping their model weights fixed. We further introduce ASENA-VLN, a 4B monocular navigation policy that serves as an optional tool within this programmable system. ASENA-VLN predicts body-frame trajectories for both extended routes and short-horizon behaviors using a shared vision-language decoder trained on route instructions, visual question answering, and a newly curated dataset of geometry-derived atomic navigation tasks. As a standalone policy, ASENA-VLN achieves state-of-the-art success rates of 68.7% on R2R and 70.2% on RxR. When integrated with a coding agent, learned navigation improves ASENA's success rate by 11 percentage points on both agentic benchmarks while reducing execution time. Through persistent workspace evolution and simulator feedback, ten passes over recurring 100-task subsets further improve success from 72% to 98% on R2R and from 65% to 89% on RxR. On embodied question answering, ASENA achieves state-of-the-art accuracy with fewer interaction steps. Finally, real-world demonstrations on a Unitree G1 combine search, visual inspection, spatial reasoning, and synthesized gestures without a pre-built map, illustrating how online programming extends robot behavior beyond route following and predefined skills.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：具身导航机器人若仅能"到达目的地"远远不够。面对诸如"检查自动售货机里是否有某件商品并返回回答"这类任务，机器人必须自主决定**去哪搜索、识别什么、如何记忆、如何交流**。导航只是更大任务中的一个环节，下一步动作取决于实时观察结果。
- **核心痛点**：
  - 传统学习型导航策略虽提供运动能力，但无法应对"检查什么、计算什么、如何沟通"这类动态决策需求；
  - 现有系统依赖**预定义技能**与**固定策略**，难以在任务执行中在线修复失败、积累经验并扩展行为边界；
  - 物理部署还面临安全风险：人形机器人的全身运动涉及平衡与共享空间安全问题，程序快速变化会带来不可控风险。
- **整体含义**：论文提出 ASENA——一个将**通用编码智能体**接入机器人感知、计算、监督执行与持久经验的具身智能体系统，核心目标是在**模型权重完全固定**的前提下，让系统通过程序编写、执行反馈、失败修复与工作空间演化，持续提升任务表现，超越路线跟随与预定义技能的限制。

## 2. 方法论：核心思想与关键技术细节

### 2.1 系统总体架构（ASENA）

- **核心思想**：编码智能体（Codex、Claude Code 等）通过统一的**写—运行—检查（write–run–inspect）**工作流，获得对物理机器人的编程访问能力。
- **三大支柱**：
  1. **机器人反馈接地**：G1 机器人暴露 360° 相机、LiDAR、里程计、身体 IMU、关节状态等传感器；智能体处理并可视化这些输入以估计几何、检查物体、监控执行。
  2. **持久工作空间**：系统状态表示为 $W_k = (N_k, S_k)$，其中 $N_k$ 为笔记，$S_k$ 为可执行技能。固定权重的改进器利用执行轨迹 $\mathcal{T}_k$ 与反馈 $f_k$ 更新工作空间：
     $$W_{k+1} = I_\varphi(W_k, \mathcal{T}_k, f_k)$$
     模型与控制器权重始终保持不变。
  3. **监督执行与安全保障**：
     - 合成手势先在 MuJoCo 中在线验证（姿态连续性、关节与运动限制、自碰撞采样）；
     - 验证失败时返回违反的约束给智能体修复；
     - 导航使用 LiDAR 占据地图进行路径规划与障碍物间隙检查；
     - 独立安全机制强制运动限制，里程计过期或电量低时拒绝命令；
     - 心跳触发停止、手动急停、操作员审批门控。

### 2.2 ASENA-VLN：可复用视觉导航策略

- **定位**：4B 单目导航策略，作为可编程系统中的**可选工具**，智能体可决定何时调用、检查进度并与其他工具组合。
- **架构设计**：
  - 基于 Qwen3-VL-4B-Instruct 扩展，增加**轨迹 token**（660 个）与**像素目标 token**（683 个）专用词表；
  - 输入：最多 8 帧前视图像 + 结构化 JSON 指令（含导航命令、可选末端位姿、锚点物体、运动约束）；
  - 共享自回归解码器预测最多 8 个累积机体坐标系路点，每个表示为 $(x, y, \theta)$；
  - 固定分箱将轨迹 token 转换为显式运动目标，无需单独连续动作头；
  - 像素目标 token 提供辅助监督，但不可直接执行，评估中均使用轨迹 token。
- **原子导航数据**：在 MP3D 与 HM3D 中构建 9 类原子任务（度量运动、旋转、相对目标、精细对齐、房间目标、门穿越、走廊跟随、楼层切换等），通过测地距离、可见性与场景几何生成并验证。
- **训练数据混合**：原子任务 + 短时程 ObjectNav + R2R/RxR/ScaleVLN/SRDF 导航数据，使用 GPT-5.5 重述为结构化 JSON；训练采用 3:1 的轨迹预测与空间 VQA 混合，共 4.3M 样本。

## 6. 主要结论与发现

1. **独立策略性能领先**：ASENA-VLN-4B 在 R2R 达 68.7% SR、RxR 达 70.2% SR，NE 分别为 3.52 m 与 3.90 m，nDTW 达 73.1%，均为 SOTA。
2. **强编码智能体本身即强导航系统**：GPT-6 Astra 仅用几何与程序化工具即达 87% SR（R2R），接近人类 90% 水平，且超越独立 ASENA-VLN。
3. **学习导航对弱后端增益显著**：Claude Sonnet 5 接入 VLN 工具后，R2R 与 RxR 成功率均提升 11 个百分点。
4. **调用次数大幅下降**：VLN 工具使工具调用减少 46.9%–62.5%，显著降低智能体交互频率。
5. **工作空间演化效果显著**：十轮演化后，R2R 成功率从 72% 提升至 98%，RxR 从 65% 提升至 89%，且成本随演化下降。
6. **EQA 表现优异**：HM-EQA 达 81.2% 准确率，MT-HM3D 达 67.1%，均以更少探索步数实现 SOTA。
7. **真机验证可行**：G1 在无预建地图环境下完成洗手间寻找、咖啡机计数、零食比对与手势回应三项任务。

## 7. 优点

- **范式创新**：将编码智能体与物理机器人深度结合，提出"模型权重固定、工作空间持续演化"的自改进范式，避免昂贵的再训练。
- **安全保障分层**：从程序合成、MuJoCo 在线验证、操作员审批到物理执行，构建四层安全机制，对人形机器人部署尤为重要。
- **可选策略设计**：ASENA-VLN 作为可选工具而非强制组件，智能体可灵活组合几何导航与学习策略，适应不同后端能力。
- **原子导航数据集**：构建 9 类几何可验证的原子任务，为细粒度可复用行为提供直接监督，补充传统路线级训练。
- **全面的评估体系**：覆盖 VLN、ObjectNav、EQA、真机任务，包含多后端、多轮演化、量化部署等维度。
- **工程完整度高**：MCAP 记录、Jetson Thor 量化、SONIC 全身控制等细节均有报告，具备可复现性参考价值。

## 8. 不足与局限

- **算力信息不透明**：未披露 GPU 型号、数量与训练总时长，影响资源评估与复现成本判断。
- **真机任务耗时较长**：实际任务需 10–20 分钟，推理与执行速度仍是瓶颈。
- **工作空间演化的泛化性存疑**：演化实验仅在**重复出现的相同任务、场景、指令与初始位姿**上进行，对全新任务的迁移能力未充分验证。
- **VLN 工具收益依赖后端**：对强编码后端（GPT-6 Astra）增益有限，RxR 上甚至略有下降，说明策略与智能体的整合方式仍需优化。
- **像素目标未实际使用**：论文明确所有评估均使用轨迹 token 而非像素目标，辅助监督的实际价值未被充分验证。
- **安全机制依赖人工**：操作员审批门控在真实部署中可能限制自主性，且动态环境下的安全保障仍需加强（作者亦在讨论中承认）。

- **EQA 工作空间演化依赖真值反馈**：演化过程中使用的监督信号来自仿真环境的真值信息（如物体位置、房间标签），而真实部署中智能体只能获得带噪声的观测与自评估信号，这可能高估了自演化机制在实际场景中的收益幅度。
- **跨任务迁移证据不足**：论文展示了同一任务族内多轮演化的收敛性，但未给出"在任务 A 上积累的技能/笔记能否加速任务 B"的量化实验，工作空间的可迁移性是该范式能否规模化的关键前提。

- **真机实验缺少定量指标**：G1 上的三个任务以定性描述为主，缺乏成功率、耗时分布、干预次数等可比较指标，难以评估系统在真实噪声与动态干扰下的鲁棒性。
- **与"端到端 VLA"路线的对比不充分**：论文主要与导航专用方法比较，未与近期端到端视觉—语言—动作模型在长时程具身任务上做同条件对照，范式优劣的边界仍不清晰。

## 9. 总体评价与启示

- **核心贡献定位**：ASENA 的价值不在于刷新某一单项导航指标，而在于提出并验证了一条**"权重冻结 + 工作空间演化"**的具身智能体工程路线——把 LLM 编码智能体当作机器人的"程序员"，让能力增长发生在代码与笔记层面而非参数层面。这一思路与当前主流的"扩大预训练 + 后训练微调"形成互补，对快速迭代、安全可审计的机器人部署具有现实吸引力。
- **技术亮点**：将学习型导航策略（ASENA-VLN）降格为**可选工具**而非系统骨架，是本论文最有启发性的设计决策。它承认了单一策略的局限，同时保留了几何规划的可解释性与学习策略的泛化性，实验也证明这种"工具化"组合对弱后端增益最大。
- **方法论意义**：原子导航任务的构建方式（以几何可验证性为准则自动生成并过滤）为"可复用行为单元"的监督数据生产提供了可借鉴的范式；MuJoCo 在线验证手势、操作员审批门控等安全设计，则为人形机器人接入大模型智能体提供了工程模板。
- **待解决的核心问题**：自演化机制的**泛化边界**与**反馈来源**仍是两大未决问题。若工作空间只能在重复任务上收敛，而无法迁移至新任务，则该范式的收益将随任务多样性上升而迅速衰减；若演化依赖真值反馈，则真实部署中的自监督替代方案（如基于视觉一致性、任务成功自判的弱信号）仍需系统研究。
- **适用场景判断**：该方法目前更适合**结构化、可重复、允许人工监督**的任务（如巡检、定点检查、演示场景），对开放动态环境与高时效要求的任务，其 10–20 分钟级的真机任务耗时与人工审批环节仍是主要制约。
- **一句话总结**：ASENA 用"可编程 + 可记忆 + 可验证"的方式，把具身智能体的能力增长从参数空间迁移到工作空间，在保持权重不变的前提下实现了显著的任务级自改进，为安全可控的机器人持续学习提供了一条值得深入探索的路径，但其泛化性与真实反馈闭环的建立仍是下一步的关键。
