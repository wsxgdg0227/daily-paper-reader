## 摘要
记忆对于使基于 LLM 的智能体在长时程交互中保持连贯、个性化的行为至关重要。然而，现有记忆系统存在一个根本性局限：它们从不主动测试自身记忆，只有在真实查询暴露出缺陷后才进行修复。这种被动响应式范式意味着，每一次检索失败都对应着一次真实交互，而代价已经付出。我们提出 MemDream，一个能够为 LLM 智能体实现自探测记忆演化的框架。我们的框架周期性地进入离线“梦境”循环，在其中由三个专门智能体（Dreamer、Analyst、Consolidator）协同探测、诊断并修复记忆图，从而在失败发生之前完成修复。通过组相对策略优化（Group Relative Policy Optimization）训练的策略能够学习哪些修复操作可带来持久的检索改进，而软衰减机制则提供由同一预期信号驱动的可逆遗忘。在 LoCoMo 和 MemoryAgentBench 上的实验表明，与最强的反应式演化基线相比，MemDream 在 LoCoMo 上将答案 F1 提升 4.5 分，并在 MAB 上取得高 9.1 分的总体得分。

## Abstract
Memory is essential for enabling LLM-based agents to maintain coherent, personalized behavior over long-horizon interactions. However, existing memory systems share a fundamental limitation: they never proactively test their own memory, repairing it only after real queries expose weaknesses. This reactive paradigm means every retrieval failure corresponds to a real interaction in which the cost has already been paid. We propose MemDream, a framework that enables self-probing memory evolution for LLM agents. Our framework periodically enters offline dream cycles where three specialized agents (Dreamer, Analyst, Consolidator) collaboratively probe, diagnose, and repair the memory graph before failures occur. A policy trained via Group Relative Policy Optimization learns which repair operations produce durable retrieval improvements, while a soft decay mechanism provides reversible forgetting driven by the same anticipatory signal. Experiments on LoCoMo and MemoryAgentBench demonstrate that MemDream improves answer F1 by 4.5 points on LoCoMo and achieves a 9.1-point higher overall score on MAB over the strongest reactive-evolution baselines.

## 1. 核心问题与研究动机

- **根本痛点**：现有 LLM 智能体记忆系统是**被动反应式**的——它们从不主动测试自身记忆，只在真实查询暴露缺陷后才修复。这意味着每次检索失败都对应一次真实交互，代价已经付出（如错误推荐含坚果的菜谱给过敏用户）。
- **失效机制**：随着交互累积，记忆图会出现三类退化：
  - *碎片化*：相关信息散落在互不相连的节点；
  - *冗余*：重叠内容分布多个节点稀释检索精度；
  - *陈旧化*：过时信息与近期交互冲突。
- **现有工作局限**：
  - 结构化记忆架构（MemGPT、MemoryBank、MemoryOS、FluxMem 等）预设组织方式，内容维护依赖隐式/手工规则；
  - 多阶段检索流水线（Self-RAG 等）提升精度但不改变存储内容；
  - 自演化记忆方法（Auto-Dreamer、TrustMem、RecMem、Memory-R1 等）多依赖历史观测或任务反馈，缺乏主动构建"修复信号"的能力。
- **核心提问**：记忆系统能否在失败发生**之前**就定位并修复自身的潜在弱点？
- **核心洞见**：记忆系统应当**自我测试**——通过自生成的前瞻性探测查询，暴露"已存储但无法可靠检索"的隐藏缺陷，并将未被观测的未来查询分布转化为可训练的修复信号。

## 2. 方法论：MemDream 框架

### 2.1 总体思想

- 灵感来自睡眠中的记忆巩固（complementary learning systems 理论）。
- 系统在**离线梦境循环（Dream Cycle）**中异步运行，由三个共享 Llama-3.1-8B 骨干、各配独立 LoRA 适配器的智能体分工协作：**Dreamer 探测 → Analyst 诊断 → Consolidator 修复**。
- 在线交互不等待梦境循环完成，模型参数在部署时冻结，梦境循环只更新外部记忆。

### 2.2 记忆架构与问题形式化

- 三层层级记忆图 G = (V, E)：
  - **STIM**（短期交互记忆）：LRU 淘汰的近期页面；
  - **MTEM**（中期情景记忆）：按会话分组的页面及元数据；
  - **LTSM**（长期语义记忆）：压缩后的知识条目。
- 每个节点 v 携带内容嵌入、实体集、访问统计与检索权重 w_v ∈ [0,1]；边连接共享实体、同会话或被合并的节点。
- 检索采用稠密 + BM25 的 **RRF 倒数排名融合**，再乘以节点权重，经 cross-encoder 重排后取 Top-k：

  s(v, q) = [Σ_{i∈{dense,BM25}} 1/(k + rank_i(v,q))] · w_v

- **学习目标**：学习策略 π: G → G′，最大化未来可能查询分布 Q 上的期望检索成功率：
  E_{q∼Q}[Success(q, Retrieve(q, G′))]
- 由于 Q 未知，梦境循环的作用正是**学习从 Q 中采样**，把不可观测分布转为可训练信号。

### 2.3 三智能体梦境循环

- **Dreamer（探测）**：
  - 为每个节点计算弱点分 φ(v) = λ₁·连通性缺失 + λ₂·与邻居最大余弦相似度（冗余）+ λ₃·时间陈旧度；
  - 选出高弱点节点 v\*，再配对**桥接伙伴** u\*——不是按嵌入相似度，而是按"局部探测查询中共检索频率最高但无边的节点"，从而连接"反复共同出现却缺失链接"的节点；
  - 生成整合 {v\*, u\*} 的自然查询，**期望答案逐字复制自目标节点的存储内容**（而非模型生成），保证信号扎根于现有记忆、不会追逐幻觉目标。
- **Analyst（诊断）**：
  - 沿两个正交轴分类失败：**节点内/跨节点** × **召回/精度**，得到四类完整分类：
    - *buried*（节点内召回）：事实埋在冗长文本中 → extract
    - *scattered*（跨节点召回）：证据分散在未连接节点 → synthesize
    - *redundant*（跨节点精度）：内容重叠 → merge
    - *noisy*（节点内精度）：问候语等低价值节点 → prune
  - 按"最严重优先"排序输出目标节点 ID 与处方操作；分类轴穷举了检索失败方式，具备完备性且可扩展子类。
- **Consolidator（修复）**：
  - 执行 extract（结构化抽取）、merge（合并保边）、synthesize（生成带溯源链接的摘要节点）、prune（**软衰减而非硬删除**）：
    - 衰减：w_v ← γ·w_v，γ = 0.2；
    - 恢复：w_v ← min(1.0, w_v + η·success_count_v)。
  - 软衰减只降低检索排名、不丢信息，后续循环若发现重新相关可恢复权重，实现**可逆遗忘**。
- **收敛判据**：平均梦境查询 F1 ≥ τ 或达到最大轮数 T_max。

### 2.4 GRPO 训练与三阶段流程

- 三个智能体各用**独立的固定权重可解释奖励**（式 8–10）：
  - Dreamer：r_disc（区分弱/强区域）+ r_down（下游 QA 影响）+ r_cov（查询类型覆盖）；
  - Analyst：r_act（修复引用有效节点比例）+ r_div（操作类型多样性）+ r_size（修复数量适中）+ r_struct（输出格式良好）；
  - Consolidator：按操作类型设计，如 extract 用 QA-F1、覆盖度、时间线索保留、简洁度惩罚等。
- GRPO 损失对同组 N 个 rollout 的奖励做组内归一化优势估计，仅高于均值的 rollout 获得正梯度，形成**更难课程**：

  L = −(1/N) Σ A_i · log π_θ(a_i|s)，A_i = (r_i − r̄)/(σ_r + ε)

- **三阶段训练**：
  1. 三智能体分别用 GPT-4.1 教师数据做 SFT；
  2. 各自独立 GRPO（使用各自奖励）；
  3. **联合微调** Dreamer 与 Consolidator（Analyst 冻结），联合奖励为记忆质量提升 ΔF1 = F1(q, G′) − F1(q, G)，梯度只流入 Dreamer 与 Consolidator 适配器。
- 关键超参：学习率 1×10⁻³，组大小 N=4，探索率 ε=0.2（衰减），LoRA rank 16 / α=32，8-bit 量化，总可训练参数约 39.3M。

## 6. 主要结论与发现

- **主结果**：
  - LoCoMo（GPT-4.1）：平均 F1 55.14，较最强基线 FluxMem 提升 **+3.98**；时序类较 O-Mem 提升 +8.57；仅在开放式问题落后 FluxMem 1.41 F1。

  - **软衰减影响最大**：去掉后平均 F1 从 55.14 降至 41.04（−14.10），开放式问题降 18.54，说明硬删除会丢失后续会话仍需的节点；
