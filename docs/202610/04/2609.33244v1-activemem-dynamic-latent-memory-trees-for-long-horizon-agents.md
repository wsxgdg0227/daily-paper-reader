## 摘要
大型语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立上下文片段进行检索，忽略了多步执行背后的过程性依赖。随着记忆规模扩大，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，它递归地将智能体经验组织为依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索和剪枝策略。在多种智能体基准上的实验表明，相较于现有基于记忆的智能体，ActiveMem 持续提升任务完成度、推理稳定性和记忆效率。此外，ActiveMem 使紧凑的开放权重模型能够达到与规模显著更大的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

# ActiveMem 论文总结

## 一、核心问题与研究动机

- **背景**：LLM 智能体越来越多地依赖外部记忆来支撑长时程推理与决策，需要跨越扩展的决策轨迹保持连贯的过程性状态。
- **核心痛点**：现有记忆系统（如 ReAct、MemoryBank、ExpeL、AWM、MemGen 等）大多将历史轨迹、摘要或语义相似上下文作为**扁平、独立的片段**检索，忽略了多步执行之间的**过程性依赖**。
- **后果**：
  - **上下文碎片化**：检索到的动作片段之间缺乏因果/时序一致性；
  - **跨任务干扰（Cross-Task Leakage）**：例如在订机票任务中盲目套用订酒店的步骤（如"选房型、填日期、加早餐"），导致工作流错配；
  - 随记忆规模扩大，这些不一致会持续削弱推理稳定性与执行连贯性。
- **关键洞察**：长时程任务天然具备**层次化分解**结构——高层目标逐步分解为可复用子任务，执行依赖关系必须被保留。因此记忆不仅需要"存储"，更应支持**结构化抽象**与**依赖感知检索**。

## 二、方法论

### 2.1 核心思想

- 提出 **ActiveMem**：将智能体经验递归组织为 **层次化潜在记忆树（HLMT, Hierarchical Latent Memory Tree）**。
- 节点编码可复用的**子任务级推理抽象**（连续潜在向量），边捕获**执行依赖**，从而支持"按当前执行状态检索连贯推理路径"，而非孤立轨迹。
- 三个与先前工作的本质区别：
  1. 使用**连续潜在记忆**代替原始文本块；
  2. **主动优化记忆拓扑**，而非被动追加历史；
  3. 通过 RL **联合优化推理适配与记忆结构**。

### 2.2 问题形式化

- 智能体与环境交互产生轨迹 τ = (s₀, a₀, …, s_T)，历史前缀被压缩为动态树 T_t；
- 树通过离散更新函数演化：T_t = TreeUpdate(T_{t−1}, a^{tree}_{t−1})；
- 检索：P_t = f_retrieve(s_t, T_t)；控制器 W_φ 结合隐藏状态 h_t 与路径均值，输出：
  - 潜在记忆前缀 m_t（条件化冻结 LLM）；
  - 树动作 a^{tree}_t（管理拓扑）；
- 优化目标：max_φ E_{x∼D, τ∼π_{θ,φ}}[R(τ)]，采用 **GRPO** 优化（无需 critic）。

### 2.3 HLMT 结构

- 每个节点 n_i = (e_i, pa(i), ch(i))，e_i 为潜在摘要嵌入，父/子指针显式建模语义层次。
- 初始化虚拟根节点 n_r，不编码任务语义，在回合边界重置。
- **检索流程**：以 h_t 为查询，从根开始**递归贪心遍历**，每层选择与 h_t 余弦相似度最大的子节点，直到最大相似度低于阈值 τ_stop 为止，得到激活路径 P_t = (n₁, …, n_d)。
- **复杂度**：检索复杂度约 O(b log_b N)（b 为分支因子），远优于扁平检索的 O(N)；空间复杂度仍为 O(N)。

### 2.4 双头记忆控制器

- **共享表示**：u_t = MLP_shared([h_t; p̄_t])，其中 p̄_t 为路径节点嵌入的均值池化。
- **潜在注入头（Latent Injection Head）**：
  - 生成连续前缀 m_t = W_latent u_t ∈ R^{l_p × d_model}；
  - 直接**前置拼接到当前观测的输入嵌入**（作为动态软提示），避免逐层修改；
  - RL 梯度可穿过冻结 LLM 的计算图回传至控制器参数 φ，实现端到端更新。
- **树动作头（Tree Action Head）**：π_tree(·|u_t) = Softmax(W_tree u_t)，采样离散拓扑操作。

### 2.5 记忆拓扑更新（解耦为两类）

- **即时执行（TreeUpdateImmediate）**：在线进行高频语义更新。
  - `insert`：新节点 e_new = W_ins u_t，挂到检索叶子 n_d 下，显式保留时序层次；
  - `update`：以门控 α = σ(W_gate u_t) 精炼叶子表示：e_d ← (1−α)e_d + α W_upd u_t；
  - 所有新插入/更新的嵌入均做 **L2 归一化**，防止表示坍缩。
- **延迟执行（TreeMaintenance）**：回合结束时进行低频、基于效用的维护。
  - 计算节点效用 S(n_i) = Σ_{k=t_i}^T γ^{k−t_i} r_k（融合可验证过程奖励与最终回报）；
  - 用 EMA 平滑：S_EMA ← (1−β)S_EMA + βS(n_i)；
  - **剪枝**：S_EMA 低于 τ_del 的节点被删除，其子节点重挂到父节点；
  - **合并**：兄弟节点相似度 sim(e_i, e_j) > τ_merge 时平均池化融合。
  - 阈值设置：τ_stop、τ_merge 初始化约为 0.5 / 0.9；τ_del 采用动态百分位（每回合剪掉效用最低的 5%）。

### 2.6 训练配方（GRPO + 层次化优势）

- 采用 **GRPO**，无需 critic，降低长时程训练的内存开销。
- 引入**可验证过程监督**缓解最终奖励稀疏问题。
- 层次化优势函数：
  - A_i = λ_g · 组内归一化优势 + λ_l · (S(n_i) − S(pa(i)))，即"全局优势 + 局部（相对父节点）优势"；
  - 附加深度折扣：Ã_i = γ^{d_i} A_i。
- 联合目标：L(φ) = L^latent_GRPO(φ) + λ L^tree_GRPO(φ)，两者共享表示、梯度联合累积；latent 目标带 KL 散度惩罚防止策略崩溃。
- 两个变体：**ActiveMem-SFT**（监督微调）与 **ActiveMem-GRPO**（RL 进一步优化）。

## 六、主要结论与发现

1. **性能全面提升**：ActiveMem-GRPO 在所有基准上取得最佳或次佳结果。例如 Qwen3-8B 上 ALFWorld 95.57%、TriviaQA 87.46%、BigCodeBench 84.39%、GPQA 54.49%；SmolLM3-3B 上 ALFWorld 从 MemGen-GRPO 的 63.60% 提升至 73.26%。
2. **跨规模"跃迁"能力**：紧凑开源模型（1.5B/3B）通过分层记忆管理，性能可超越更大规模基线（如 Qwen2.5-14B-Instruct）。
3. **记忆效率显著**：在 16-objective 任务上，ActiveMem 仅用 14B 基线 **27.1% 的峰值 token** 和 **29.3% 的推理时间**；随任务复杂度上升，基线 token 消耗近线性增长，而 ActiveMem 保持近乎恒定的记忆占用。
4. **泛化能力强**：跨域迁移（如 KodCode→MATH、ALFWorld→FEVER）几乎无灾难性退化，优于 SFT、MemoryBank、MemGen 等。
5. **持续学习更稳定**：顺序训练 4 个数据集后，ActiveMem 在所有任务上均优于 SFT/ExpeL/MemGen，遗忘更少。
6. **消融结论**：HLMT 结构是**最关键组件**（去掉后 GPQA 从 54.49% 跌至 44.53%，BigCodeBench 从 84.39% 跌至 69.88%）；潜在注入与层次化优势同样关键；合并/删除操作影响相对较小但一致正向。
7. **理论支撑**：论文证明树检索可实现因果解耦（互信息降为 0）、树规模有界（O(1)）、GRPO 方差按 (T_mem/T_token)² 二次降低。

- **问题定位精准**：明确指出扁平记忆的"上下文碎片化 + 跨任务干扰"两大失效模式，并用具体例子（订机票 vs 订酒店）说明，动机直观有力。

- **训练算法匹配得当**：GRPO 免 critic，配合层次化优势（全局 + 相对父节点）与深度折扣，有效缓解长时程稀疏奖励与信用分配问题。
- **实验维度丰富**：不仅报告准确率，还系统测量峰值 token、推理时间、依赖长度等效率指标，并做跨域泛化、持续学习、WebShop、BrowseComp 等多场景验证。
- **理论分析完整**：从因果解耦（SCM/d-分离）、度量空间覆盖（有界增长）、策略梯度方差（二次缩减）三方面给出形式化论证。

## 八、不足与局限

- **未明确说明训练成本**：仅给出 GPU 数量（4×H100/H200）与框架，未报告总训练时长、总 GPU 小时、不同规模模型的成本差异，难以评估实际落地开销。
- **超参与配置存在内部不一致**：正文与附录在 batch size（64 vs 8）、学习率（1e-6/1e-5）、控制器维度等方面描述不统一；Table 3 与 Table 7 内容高度重复。
- **基线复现公平性存疑**：BrowseComp 等表格中部分基线数据来自原始论文或公开榜单，未在统一协议下复现；不同方法在训练目标（EM vs F1）与任务设定上存在差异，横向比较需谨慎。
- **对阈值与超参的敏感性未充分分析**：τ_stop、τ_merge、τ_del、λ_g、λ_l、γ 等关键参数的敏感性分析缺失，仅说明采用动态百分位与经验初始化。
- **理论假设较强**：Topological Domain Isolation（不同领域路径除根节点外拓扑不相交）在真实开放环境中未必成立，因果解耦结论依赖该假设。
- **应用限制**：
  - 依赖外部控制器与潜在注入，需要修改推理管线（拼接 KV 前缀），

- 对闭源或仅提供文本 API 的模型不适用；若部署框架不支持 KV 前缀注入或隐藏状态访问，则难以直接迁移。
  - 潜在记忆向量语义不透明，无法像文本记忆那样被人工审计、编辑或精确删除，可能带来调试与合规难题。
  - 树维护引入额外工程复杂度：插入、更新、剪枝、合并均依赖阈值与效用估计，需针对任务调参，增加落地成本。
  - 剪枝/合并可能删除低频但关键的长尾经验，在开放动态环境中造成不可逆的信息损失；EMA 效用对奖励尺度较敏感。
  - 实验主要覆盖文本搜索、具身、数学、代码等基准，尚未验证多模态、多智能体、实时交互与超长时程（数百至数千步）场景。
  - 安全、隐私与对齐问题讨论不足：跨任务记忆可能泄露敏感信息，潜在前缀也可能被注入攻击或用于越狱，缺少遗忘与访问控制机制。
  - 与部分基线并非在同一训练/推理协议下复现，且 batch size、学习率等超参在正文与附录不一致，结论的稳健性仍需更严格验证。

## 九、总体评价与启示

- **总体定位**：ActiveMem 将外部记忆从“被动检索的文本库”推进为“可主动优化的层次化潜在策略”，在长时程 LLM 智能体记忆方向上具有范式意义。
- **核心贡献**：HLMT 结构、双头控制器、即时/延迟解耦维护、GRPO 层次优势四者协同，兼顾性能、效率与训练稳定性。
- **实践启示**：对资源受限的智能体，优先采用结构化、依赖感知的记忆表示，通常比单纯扩大上下文或增加检索片段更有效；冻结主干 + 轻量控制器是一条低成本适配路径。
- **未来方向**：可解释潜在记忆、无监督/自监督树维护、跨模态与多智能体共享记忆、隐私保护与机器遗忘、统一基准与超参敏感性分析，以及在真实开放环境中的长期部署验证。
