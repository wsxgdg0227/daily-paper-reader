## 摘要
智能体可以从过去的执行中学习，但让不同智能体复用并基于彼此的经验继续构建仍然具有挑战性。我们提出 EpiCon，一种用于智能体集体学习的共享多模态记忆框架，且无需更新宿主模型参数。EpiCon 通过两个独立训练的 2B 模型——记忆控制器和树状自组织器——将问题级记忆演化与持久经验库连接起来。控制器在多次尝试中联合细化文本引导与视觉证据，并有选择地纳入视觉记忆。自组织器分层地整合经验教训，并为新问题检索经验和规则。我们在跨越四个多模态任务领域的十一个基准上评估 EpiCon，使用两种 harness 和多个骨干模型。一个冻结的经验库即使在一次求解尝试下也能改进其他系统。第二个 harness 在十一个基准上将原系统的宏平均分数提高 2.6 分。在四种宿主配置下，EpiCon 相较于 No Memory 将宏平均分数提高 1.7 至 4.9 分，并相对于骨干模型规模的记忆模型将记忆操作时间减少 67% 到 74%。

## Abstract
Agents can learn from past executions, but enabling different agents to reuse and build on one another's experience remains challenging. We introduce EpiCon, a shared multimodal memory framework for agent collective learning without updating host model parameters. EpiCon links question-level memory evolution to a persistent experience bank through two independently trained 2B models: a memory controller and a tree self-organizer. The controller jointly refines textual guidance and visual evidence across attempts and selectively includes visual memory. The self-organizer consolidates lessons hierarchically and retrieves experience and rules for new problems. We evaluate EpiCon on eleven benchmarks spanning four multimodal task domains, using two harnesses and multiple backbones. A frozen bank improves other systems even with a single solving attempt. A second harness raises the original system's macro-average score by 2.6 points across eleven benchmarks. Across four host configurations, EpiCon improves macro-average scores by 1.7 to 4.9 points over No Memory and reduces memory-operation time by 67\% to 74\% relative to backbone-sized memory models.

## 1. 核心问题与整体含义

- **研究动机**：基于语言模型的多智能体系统（MAS）在协作求解中会产生大量关于解题流程、失败模式和关键证据的经验，但**不同智能体之间难以复用并基于彼此经验继续构建**，阻碍了"集体学习"。
- **核心矛盾**：让经验跨系统迁移通常需要更新宿主模型参数（成本高、不可迁移），而外部记忆虽可避免参数更新，却大多以文本为主、缺乏多模态证据，且难以跨 harness / 骨干复用。
- **整体含义**：论文提出 EpiCon（Episodic Consolidation），一个**共享多模态记忆框架**，通过经验积累与复用实现智能体集体学习，且**宿主 MAS 的参数完全冻结**。记忆被设计为独立于 MAS 的持久经验库，可被不同 harness 和骨干读取与贡献。

## 2. 方法论

### 2.1 核心思想
- 用**专用 memory harness** 连接两层记忆：
  - **问题级记忆演化**（question-level）：单题内跨多次尝试迭代修正。
  - **持久经验库 B**（experience bank）：跨问题、跨系统积累、整合与检索。
- 由两个**独立训练的 2B 模型**承担核心操作：
  - **Memory Controller（Cθ）**：题内联合更新文本与视觉记忆。
  - **Tree Self-Organizer（Sϕ）**：分层组织、整合并检索经验与规则。

### 2.2 关键技术与公式流程
- **经验库更新**（维护步 k 处理一批被接受的教训 Uk）：
  - `B(k+1) = Sϕ(B(k), Uk)`；索引 k 为维护步而非单条经验；评估时经验库冻结。
- **文本—视觉协同演化**：问题级记忆表示为 `W_{i,t} = (M_text, M_vis)`；控制器依据上一状态、题目与图像、最新答案和执轨迹更新：
  - `W_{i,t} = Cθ_update(W_{i,t-1}, x_i, ŷ_{i,t}, τ_{i,t})`
  - 控制器联合提出修订文本、源图像与区域，可保留 / 替换 / 删除视觉证据；非法提议由 harness 校验后丢弃，记忆保持不变。
- **自适应视觉记忆注入**：门控 `g_{i,t} ∈ {0,1}` 决定下一次尝试是否注入视觉记忆：
  - `c_{i,t} = (T_{i,t}, ∅)` 若 g=0；`(T_{i,t}, V_{i,t})` 若 g=1
  - 门控只选择输入内容，**不删除已存储的视觉记忆**；原始题目图像始终可用。
- **树组织操作**：Place、Merge、Split + Lift、Consolidation；叶节点存题目级教训，内部节点分组摘要；满足证据条件时可升格为**可复用规则**。抽象层级与规则资格由 harness 依据支持度、失败、冲突与证据强度决定。
- **检索**：`R_i = Sϕ_retrieve(x_i, Recall(x_i, B))`；先用冻结文本编码器按节点索引（主题、范围、题目锚点）召回候选，再由 organizer 选择适用规则、具体经验或"空"。
- **数据构造与训练**：
  - 教师模型：Qwen3.8-27B 生成初稿，Qwen3.8-Flash-Next 选择性精炼；轨迹来自 CAMEL、Codex、DeepSeek-Harness。
  - **Repair** 变换（失败→成功）与 **Compress** 变换（保持成功且缩短文本、不增大裁剪面积，满足 `tokens(ℓ′) < tokens(ℓ)`、`area(b′) ≤ area(b)`）经离线 replay 筛选。
  - 得到约 **25K** 记忆变换监督、约 **6.5K** 树操作演示。
  - 训练配置：LoRA rank 16、scaling 32，冻结视觉编码器与 aligner；3 epochs、lr 1e-4、最大序列 8192、per-device batch 2、梯度累积 8；controller 取 step 1000，tree 取 step 258。

## 6. 主要结论与发现

- **冻结经验库即可迁移**：单个求解尝试下，他人构建的冻结经验库即可提升不同骨干（宏平均 +3.2）和不同 harness（+4.2）。
- **集体学习闭环成立**：另一 harness 演化经验库后，原系统宏平均从 53.5→55.7（+2.1，Codex）与 53.4→56.6（+3.2，DeepSeek-Harness），分别有 8 和 9 个 benchmark 提升。
- **主结果**：backbone-sized EpiCon 在四种宿主配置中宏平均均为最高，超过最强外部记忆基线 1.9–5.9 分；例如 Codex+Qwen3.8-27B 上 ParseBench 57.1→68.5、MATH-Vision 20.4→48.6。
- **紧凑模型的效率优势**：用两个 2B 模型替换骨干级记忆模型，记忆操作时间减少约 **67%–74%**，总时间减少 **25%–35%**，代价是宏平均低 0.9–3.6 分；2B 版仍比 No Memory 高 1.7–4.9 分，并处于经验性 Pareto 前沿。
- **视觉与自适应注入有效**：演化视觉记忆优于冻结视觉记忆（7 项提升、1 项持平）；自适应注入在 8 项中改善 7 项，并降低 MAS 执行时间（Codex 约 25%、DeepSeek 约 17%）。
- **树形组织有效**：树记忆在所有对比项优于扁平记忆（ParseBench 52.2→67.3）。
- **对更强求解器仍有效**：Codex + GPT-5.6-Luna 上四个 benchmark 全部提升（如 ParseBench 63.8→66.5，MATH-Vision 51.2→57.2）。
- **泛化边界**：对未训练领域的通用视觉推理，WorldBench 稳定提升（+3.2 到 +7.8），但 ReasonMap（+0.5 到 +1.9）与 BabyVision（−2.7 到 +4.8）提升小且不稳定。

## 7. 优点

- **范式清晰且实用**：把"记忆"从题内迭代扩展为跨系统共享的持久资产，且**不改动宿主参数**，部署成本低、迁移性强。
- **多模态记忆真正落地**：文本指导与图像区域联合演化，并有显式门控控制视觉注入，兼顾信息量与输入开销。
- **分层整合机制完整**：树结构支持放置 / 合并 / 拆分提升 / 整合，并可把多条教训抽象为可复用规则，而非简单向量检索。
- **效率设计突出**：两个独立 2B 模型在保持大部分收益的同时显著压缩记忆操作时间与 token，具备工程可行性。
- **实验协议严格**：单次尝试、经验库冻结、构建/评估分离、ReasonMap 按地图切分，降低了自证与泄漏风险。
- **迁移验证全面**：跨骨干、跨 harness、跨求解器三个维度验证了经验的可复用性，直接支撑"集体学习"主张。
- **消融体系完整**：对文本/视觉、冻结/演化、常驻/自适应、扁平/树形逐一剥离，结论归因较清楚。
