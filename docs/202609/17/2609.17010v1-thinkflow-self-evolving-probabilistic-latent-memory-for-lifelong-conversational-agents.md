## 摘要
终身对话智能体依赖记忆系统来维持与用户的深度、情境感知交互。然而，现有的显式文本记忆流程存在严重的信息瓶颈，往往会丢失细微的行为模式和情绪变化。此外，由于通常在部署后保持静态，它们无法在没有人工反馈的情况下自主适应用户的个人习惯和偏好。然而，认知科学表明，人类完全在潜在空间中维持心理模型，并通过预测编码不断对其进行细化。受此启发，我们提出 ThinkFlow，一种面向终身对话智能体的新型端到端潜在记忆框架。ThinkFlow 通过将对话流动态压缩为概率潜在记忆技能，绕过了文本瓶颈，能够在无语义干扰的情况下，自主将复杂用户状态整合为解耦的连续向量。为突破这一障碍，我们引入一种测试时演化范式。通过将教师引导的潜在对齐与自监督的下一用户话语预测任务相结合，以引导初始状态并进行持续细化，该框架成功克服了冷启动挑战，并实现了无标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow 显著优于主流记忆系统，能够在扩展的多会话交互中提供高度个性化和上下文准确的响应。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

## 2. 方法论

- **核心思想**：端到端潜在记忆框架，把连续对话流动态压缩为**概率潜在记忆技能（PLMS）**，并通过门控整合与动态对齐注入 LLM，最后以自监督测试时演化实现无标签终身学习。
- **形式化设定**：第 t 轮用户查询 $x_t$、智能体回复 $a_t$、文本历史 $H_{<t}$、潜在记忆状态 $M_t \in \mathbb{R}^{K \times D}$（K 个技能槽、D 维）。

### 2.1 三大架构组件

- **Probabilistic Latent Memory Skills (PLMS)**
  - 用可学习技能 $S \in \mathbb{R}^{K \times D}$ 对当前轮隐藏状态 $E_t$ 做交叉注意力，压缩为 K 个稠密技能向量；
  - 引入分布保持缩放因子 $1/\sqrt{c}$（$c=L/K$ 为压缩率）防止方差塌缩为确定性点质量；
  - 经两个并行线性层输出均值 $\mu_t$ 与对数方差 $\log\sigma_t^2$，用重参数化技巧采样 $\hat{S}_{new}=\mu_t+\sigma_t\odot\epsilon$；
  - 用 KL 散度将近似后验正则到标准高斯先验。
- **Gated Latent Consolidator (GLC)**
  - 信息增益门 $g_t=\sigma(W_2 \text{ReLU}(W_1[\hat{S}_{new}\|S_{old}]))$ 量化新信息相对已有记忆的新颖度；
  - 用 GRU 核心做条件式逐步更新 $S_t=g_t\odot\text{GRU}(\hat{S}_{new},S_{old})+(1-g_t)\odot S_{t-1}$，实现时序保持与优雅遗忘。
- **Context-Aware Hyper-Aligner (CAHA)**
  - 用超网络根据当前查询 $x_t$ 生成低秩变换 $W_{adapt}=W_{down}(x_t)\times W_{up}(x_t)$（瓶颈秩 r）；
  - 残差投影得到对齐技能 $S_{aligned}=S_t+S_t\times W_{adapt}$，再作为软提示前置到 LLM。

### 2.2 自监督测试时演化（两阶段）

- **Phase 1：教师引导的潜在对齐**
  - 解决冷启动：教师模型读取完整明文历史 $H_{<t}$ 输出分布 $P_T(y|H_{<t},x_t)$，学生仅读当前查询与潜在技能输出 $P_S(y|S_t,x_t)$；
  - 损失 $L_{Phase1}=D_{KL}(P_T\|P_S)+\alpha L_{KL}$，建立初始记忆技能锚点。
- **Phase 2：下一用户话语预测**
  - 从第 2 个会话起教师下线，将记忆演化建模为预测下一用户话语 $x_{t+1}$；
  - 若记忆未能捕捉核心上下文，交叉熵损失 $L_{CE}$ 高，直接迫使 GLC 门关闭，避免污染记忆库；
  - 引入最小熵置信先验 $L_{Conf}$ 防止语义塌缩；
  - 损失 $L_{Phase2}=L_{CE}(x_{t+1}|S_{t+1},a_t)+\beta L_{Conf}+\alpha L_{KL}$。
- **算法流程**：见论文 Algorithm 1，Phase 1 逐轮蒸馏对齐，Phase 2 逐会话在线演化。

## 7. 优点

- **范式创新**：首次系统性地用"概率潜在记忆技能"替代显式文本记忆，绕过文本瓶颈，保留连续语义与不确定性。
- **结构解耦设计**：K 个技能槽 + 交叉注意力强制解耦事实、情绪、偏好等不同侧面，避免语义干扰，兼具可解释性（t-SNE 可验证）。
- **自监督终身演化**：以"预测下一用户话语"作为免费监督信号，无需人工标注即可在线更新，并利用预测误差直接控制 GLC 门，形成优雅的"预测失败即拒绝写入"机制。
- **超网络对齐**：CAHA 用低秩动态变换桥接历史潜在技能与当前语义，参数量小、适应性强。
- **效率优势**：无隐藏 token 开销，token 与时间成本显著低于显式管线，适合实时陪伴场景。
- **实验较全面**：覆盖 4 个数据集/基准、2 个 backbone、多种上下文规模，并包含消融、缩放、可视化、case study 与效率分析。
