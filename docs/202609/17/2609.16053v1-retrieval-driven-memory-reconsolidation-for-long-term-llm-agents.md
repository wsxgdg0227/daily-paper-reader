## 摘要
长期记忆对于在长程交互中运行的基于LLM的智能体至关重要。现有记忆系统主要在新信息到来时更新记忆，将检索视为记忆访问的终点，而非记忆演化的驱动因素。因此，检索反馈很少被用于持续地重组记忆以支持未来访问。此外，大多数现有方法依赖预定义的记忆结构以及固定的检索流程，限制了智能体自主组织和演化自身记忆的能力。受认知神经科学中记忆再巩固的启发，我们提出REALM，一个再巩固-演化智能体长期记忆框架。它将长期记忆建模为一个持续生命周期，通过自主将记忆组织为异构认知图、经由自适应组合的图搜索原子检索证据，并基于检索反馈持续再巩固记忆。REALM在LoCoMo上达到75.97%的平均准确率，在LongMemEval上达到65.11%，分别超过最强基线7.17和1.31个百分点。消融研究证实，记忆再巩固能持续提升性能，进一步分析表明，它会逐步将相关记忆单元重组为更连贯的局部结构，以便在推理过程中进行集体证据召回与利用。这些结果表明，检索驱动的记忆再巩固为LLM智能体持续演化长期记忆提供了一种有效机制。

## Abstract
Long-term memory is essential for LLM-based agents operating over extended interactions. Existing memory systems primarily update memory when new information arrives, treating retrieval as the endpoint of memory access rather than a driver of memory evolution. Consequently, retrieval feedback is rarely exploited to reorganize memory for future access continuously. Moreover, most existing approaches rely on predefined memory structures together with fixed retrieval pipelines, limiting the agent's ability to organize and evolve its own memory autonomously. Inspired by memory reconsolidation in cognitive neuroscience, we propose \textbf{REALM}, a \textbf{r}econsolidation-\textbf{e}volution \textbf{a}gentic \textbf{l}ong-term \textbf{m}emory framework. It models long-term memory as a continual lifecycle by autonomously organizing memories into a heterogeneous cognitive graph, retrieving evidence via adaptively composed graph-search atoms, and continually reconsolidating memories based on retrieval feedback. REALM achieves an average accuracy of 75.97\% on LoCoMo and 65.11\% on LongMemEval, outperforming the strongest baselines by 7.17 and 1.31 points respectively. Ablation studies confirm that memory reconsolidation consistently boosts performance, with further analyses revealing that it progressively reorganizes related memory units into more coherent local structures for collective evidence recall and utilization during reasoning. These results suggest that retrieval-driven memory reconsolidation provides an effective mechanism for continually evolving long-term memory in LLM agents.

## 2. 方法论：REALM 框架

### 2.1 核心思想
将长期记忆建模为**持续生命周期**，由三个互补组件构成闭环：
1. **自主组织**：智能体自主构建局部拓扑，自下而上涌现为统一的"智能体认知图"；
2. **自适应检索**：将复杂图遍历分解为原子搜索动作，智能体动态组合出上下文定制的检索策略；
3. **记忆再巩固**：每次任务后对激活子图做局部再巩固，动态更新连接，实现检索驱动的持续演化。

### 2.2 问题形式化
- 传统范式：$G_{t+1}$ 仅由新观测 $o_t$ 经插入/合并/遗忘等前向操作更新，并被动抽取静态子图 $G_q \subset G_t$ 回答问题 $q$。
- REALM 引入**检索后再巩固阶段**：给定查询 $q$ 与答案反馈 $f$，将激活拓扑 $G_q$ 动态重组为优化状态 $G'_q$：
  $$G_{t+1} = \text{Reconsolidating}(G_t \setminus G_q \cup G'_q, f)$$

### 2.3 记忆组织：统一认知图
- **图表示**：$G=(V,E)$，节点空间 $V \subset \{\text{entity, event, episode, fact}\}$，边空间 $E \subset \{\text{logical, causal, hierarchical, associative}\}$。
  - 节点：$v = (\kappa_v, c_v, des_v, k_v, t_v)$，分别为节点类型、原始内容、语义描述、类型特定关键词/名称、时间跨度约束；
  - 有向边：$e_{ij} = (v_i, v_j, \kappa_{ij}, des_{ij}, w_{ij})$，$w_{ij}\in[0,1]$ 为置信权重。
  - 该表示将**原始记忆内容与拓扑解耦**，为下游检索与拓扑演化提供结构变量。
- **统一构建流水线**（将插入、合并、遗忘统一为单阶段）：
  - 提取候选记忆单元 $X=\{x_i\}$（结合对话摘要 $s_t$ 与近期信息 $c_t$）；
  - 对每个 $x$ 检索邻域 $N(x)=N_{sim}(x)\cup N_{recent}(x)$；
  - 智能体决定 **add / merge / skip**；
  - 若 add 或 merge，则推断 $x$ 与 $N(x)$ 之间的一组有向关系边。

### 2.4 记忆检索：策略原子组合
将图搜索形式化为**播种（seeding）→ 扩展（expanding）→ 过滤（filtering）** 三阶段动态流水线，策略为各阶段原子策略的组合：
$$\pi = \pi_{seed} \oplus \pi_{expand} \oplus \pi_{filter}, \quad \pi_p = (a^p_1, \dots, a^p_k),\; a^p_i \in A^p$$

- **种子定位**：智能体生成多个参数化检索计划 $p_i=(Q_i,K_i,T_i,\tau_i)$，分别定义查询串、关键词、目标节点类型、时间约束；支持 query_match / keywords_match / hybrid_match 三种匹配模式。
- **自适应证据扩展**：迭代评估当前证据集 $R_t$ 是否充分；不足则选择前沿 $F_t$，对每个前沿节点预测扩展动作 $a_v=(\text{mode, predicate, decay, inhibit})$。新发现节点的上下文感知访问分数：
  $$s_{aces}(v) = \beta\, s_{sim}(q, des_{ij}) + (1-\beta)w_{ij} - \Delta_{decay}(t_v)$$
  其中 $\beta$ 为平衡系数，$\Delta_{decay}$ 为时间惩罚。循环直至拓扑收敛或达到深度/预算上限。
- **证据聚合**：全局重排序，最终分数
  $$\text{Score}(v) = \alpha s_{aces}(v) + (1-\alpha)s_{sim}(v,q)$$
  取 Top-K 构成证据集 $V_q$，并诱导出激活局部子图 $G_q=(V_q,E_q)$ 作为再巩固的输入。

### 2.5 记忆再巩固：拓扑演化
- **检索引发的结构反馈**：先推断潜在主题结构 $T_q = \text{InferTopicStructure}(q, V_q)$，总结被回忆记忆间的语义关系，指导后续细化。注意再巩固**不修改记忆内容**，只利用 $V_q$ 中的拓扑共利用模式。
- **局部拓扑再巩固**：智能体生成修改集 $D=\{d_1,\dots,d_n\}$，每个决策为五元组 $d=(v_i, v_j, a, r, c)$，其中 $a\in\{\text{add, strengthen, weaken}\}$ 定义原子边操作，$c\in[0,1]$ 为决策置信度：
  - 同一推理上下文下被反复激活的记忆之间可**新建关系**；
  - 持续支持成功检索的关系被**增强**；
  - 反复引入无关证据的弱/误导关系被**抑制**。
- **置信度引导的拓扑更新**：设当前边权 $w_{ij}$、最小允许阈值 $w_{min}$，$w_b=\max(w_{min},\min(1,w_{ij}))$：
  $$w_{ij} \leftarrow \text{Clip}(w_{ij} + \eta\cdot c,\; w_{min},\; 1)$$
  $$\eta = \begin{cases} 0.8, & a=\text{add} \\ 1-w_b, & a=\text{strengthen} \\ -(w_b-w_{min}), & a=\text{weaken} \end{cases}$$
  该设计在权重边界附近平滑调节更新幅度，避免单次或重复检索实例破坏拓扑稳定性。
- **闭环演化**：$G_t \xrightarrow{\text{Retrieve}} (G_q, f) \xrightarrow{\text{Reconsolidate}} G_{t+1}$，记忆图逐步从初始语义组织演化为"使用感知"的认知结构。
