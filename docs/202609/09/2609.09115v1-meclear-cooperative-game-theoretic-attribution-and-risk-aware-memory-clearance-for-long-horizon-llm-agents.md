## 摘要
长时程大语言模型（LLM）智能体依赖外部记忆系统在扩展交互中保留用户偏好和任务知识。传统的检索机制优化语义兼容性而非下游效用，经常将过时、误导或冲突的证据引入活动上下文。我们提出MeClear，一种任务条件化的记忆清除框架，通过合作归因识别具有负面下游效用的记忆，并选择性地将其从智能体执行中抑制。MeClear将留一法筛选与采样的合作Shapley归因相结合，以在交互证据之间分配效用，有效解决单次删除评估无法处理的冗余冲突掩蔽问题。利用归因排名，MeClear在嵌套过滤上执行查询范围的极小清除策略，验证清除上下文上的任务恢复，而不永久改变持久记忆库。在十个长对话记忆池上的综合实验评估表明，MeClear达到了85.9%的目标召回率和82.3%的整体任务恢复率，相比留一法（LOO）基线提高了25.5个百分点。

## Abstract
Long horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing outdated, misleading, or conflicting evidence into the active context. We present MeClear, a task conditioned memory clearance framework that identifies memories featuring negative downstream utility through cooperative attribution and selectively suppresses them from agent execution. MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail. Utilizing attribution rankings, MeClear executes a query scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank. Comprehensive experimental evaluations across ten long dialogue memory pools demonstrate that MeClear achieves a target recall of 85.9% and an overall task recovery rate of 82.3%, representing a 25.5 percentage point improvement over Leave One Out (LOO) baselines.

# MeClear论文详细总结

## 一、核心问题与研究动机

- **背景**：长时程 LLM 智能体（long-horizon LLM agents）在执行跨多轮交互的复杂任务时，依赖外部记忆系统保留用户偏好、历史观测和任务知识。然而，随着交互历史不断累积，记忆库中会逐渐出现**过时、误导、冗余、冲突**的信息。传统基于检索的记忆管理系统只优化**语义相关性**，而非**下游任务效用**，导致高语义相似度的记忆反而可能在具体查询中引入有害证据，降低智能体实际表现。
- **核心难题**：
  1. 单条记忆删除（Leave-One-Out）评估在**冗余有害记忆**场景下失效——两条或以上可相互替代的记忆会互相“遮罩”，删除一条记忆后另一条仍然导致性能下降，造成归因盲区。
  2. 永久性编辑/删除持久记忆库具有高风险，因为某条记忆可能对该查询有害，却对后续查询不可或缺——任务相关性天然是**查询条件化**的。
  3. 现有的记忆过滤/准入方法只是基于启发式或表面特征过滤，无法对交互记忆进行细粒度的因果归因，也不验证清除后的行为恢复情况。

## 二、方法论框架

### 2.1 论文提出方法：MeClear 框架
MeClear 将记忆维护形式化为一个**任务条件化决策过程**，包含四个阶段：

- **任务条件化检索**：给定查询 qt，外部记忆系统冻结检索得到的固定上下文 Mt = {m1, ..., mK}（K为检索预算），后续所有干预均在此上下文上运行，不重新调用检索器，以将清除行为效应与检索随机性隔离。
- **本地反事实筛选（LOO筛查）**：对每条记忆 mi 计算 LOO 效应 $\hat{d}_{t,i} = \hat{v}_t(M_t) - \hat{v}_t(M_t \setminus \{m_i\})$，作为局部诊断参考信号（而非最终有害性判据）。通过定理 1（Redundant-Harm Blind Spot）证明若两条冗余有害记忆共同存在，LOO效应为零，而合作贡献为平均分配负效应 -Δ/2。
- **合作博弈归因**：将 (Mt, vt) 视为合作博弈，记忆为玩家，定义基于 Shapley 值的合作贡献。通过均匀采样 L 个排列进行估计，使得每条记忆的边际贡献在不同前驱联盟上求平均，从而可以暴露冗余交互中隐藏的负效用。同时提供成对交互剖析 $\hat{\omega}^{(L)}_{t,ij}$ 用于诊断直接/冗余/联合伤害结构。
- **验证式查询范围清除**：将有害记忆集合按贡献从低到高排序，构建嵌套清除候选序列 Ct,j（逐步移除），仅保留能产生正增益且通过任务恢复谓词验证的候选，对达到最大恢复增益的候选进行最小基数选择，最终返回清除后的上下文，且不修改持久记忆库。定理 2 保证经验性能不下降、最小干预和验证恢复。

### 2.2 关键公式与机制
- 价值函数：$v_t(S) = \mathbb{E}_{y \sim p_\theta(\cdot|q_t,S)}[r_t(y)]$，表示记忆联盟 S 下的任务条件化效用。
- Shapley 贡献（排列形式）：$\psi_{t,i} = \frac{1}{|\Pi_t|} \sum_{\pi \in \Pi_t}[v_t(P_i(\pi) \cup \{m_i\}) - v_t(P_i(\pi))]，通过 L 次采样近似。
- 有害记忆集：$\hat{H}_t = \{m_i \in M_t \mid \hat{\psi}^{(L)}_{t,i} < -\tau\}$，仅用一个容差参数 τ（避免额外超参数）。
- 最小清除目标（lexicographic）：先最大化任务恢复增益，再在所有同样增益的清除集中选最小基数，无参数化权重。

上述四阶段流程中，作者只引入三个可解释量：上下文容量 K、排列预算 L 和容差阈值 τ，无其他阶段特异的调优系数。

## 六、主要结论与发现

- 在整体 745 个case上，MeClear 达到：
  - **目标召回率 85.9%**（记忆级微平均）；
  - **精确故障集合匹配 47.0%**；
  - **完整记忆成功恢复 82.3%**；
  - 相比 LOO 提升 25.5 个百分点（95% 置信区间 [20.9, 29.8]），比 ProxySPEX +5.0 pp，比 qwen3.5-plus 高出 38.7 pp。
- 按故障类型分层看：
  - **直接冲突**：LOO 已经较好（68.3%召回、87.2%恢复），MeClear 仍提升至 83.2%召回和 89.6%恢复。
  - **冗余冲突**：LOO 完全坍塌至 12.3%召回、6.3%恢复；MeClear 通过联盟级归因将召回提升到 83.2%、恢复提升至 68.4%，精确集合命中率从 2.5%跃升至 49.1%。
  - **联合交互**：MeClear 达到 87.1%召回、91.8%恢复（LOO 精确命中率为 0.0%）。
- L=16 排列预算明显优于 L=4（召回从67.6%提升到85.9%），说明更多排列采样对暴露交互伤害的必要性。
- MeClear 能在不修改持久记忆库的情况下实现最高恢复率，且过度删除的背景记忆最少之一（0.623 条/案例），说明验证式候选选择确实实现了“最小干预、最大恢复”目标。

## 七、亮点与优势

- **新颖的博弈论归因视角**：将记忆价值分配建模为合作博弈中的 Shapley 贡献，能够显式建模非加性交互和冗余遮蔽；与单纯单次删除干预相比，从理论上（定理 1 严谨证明）和实践上突破“盲点”限制。
- **完整的理论保障链条**：关于冗余盲点（Appendix A）、有限样本估计的无偏性/集中性（Proposition 1）、查询级清除的非降级与恢复保证（Theorem 2），其推导自洽，说明框架的可靠性并非仅是经验上的。
- **“查询作用域、非破坏性”的工程权衡**：MeClear 不做永久删除，而是在活跃上下文上做“可见性控制”＋清除后的行为验证，真实避开了错误记忆在后续任务交叉回退的隐患。
- **参数效率与简洁**：只通过 L、K、τ（和 κ）控制流程，没有为阶段引入一堆额外超参数，更透明和可解释。
- 操作上缓解了语义检索与真实任务效用之间的不对齐问题，并且不修改、不重训检索器（作为后置检索层），便于对现有系统即插即用。
- 附录实验细致，包含敏感性分析、配对置信区间、跨子组检查，且提供了代码开源地址。

## 八、不足与局限

- **计算开销未刻画**：
  - MeClear 每个查询需要多次 LLM 推理（L 个排列 × 前缀联盟评估），等于在原始回答基础上多出大量额外生成调用；文中报告较好的归因精度要用 L=16，然而没有定量报告时间/API调用开销的总体增加，对实际代理部署（特别是频繁交互和上下文很长时）有可行性风险。
- **评估范围有限**：
  - 仅使用 10 条 LoCoMo 对话和合成注入的故障记录，各类故障结构靠人工制造的语义替代品；缺少在自然运行中积累的损坏记忆上的实验。
  - 其中“联合-时间”子类仅 n=5，作者说明是描述性的，但并没有追加额外数据来加固该方向的统计可靠性。
- **只有二元任务价值函数**：评估用 0/1 正确性打分评估记忆联盟的效用，可能不足以捕捉部分分数和复杂自然语言任务的部分正确，或在多轮对话的渐进成功等方面得分设计偏粗。
- **相对于其他归因法的公平指标解释要小心**：ProxySPEX 的 Exact Set Match（54.2%）高于 MeClear，仅在 Recovery 和 Recall 上落后；说明 MeClear 的目标不是“精确删除”而是“恢复+不误伤”，这种设计选择在结论表达时应同时呈现。
- **内存/可扩展性依赖排列的假设**：游戏公式隐含了对检索上下文（大小K=5）的枚举或采样的可行性。如果 K 变得非常大（比如数百条记忆），纯采样 Shapley 的方法预计需要更大的 L 和更更重的审计成本来维持目标置信置信度。

## 结论

MeClear 面对的是长时程 LLM 智能体记忆管理的深层挑战——**语义相关不等于任务有用**。论文将记忆价值视为一种博弈结构，将冗余、冲突和联合伤害系统地暴露和分析，并在维持非破坏性方面给出了灵活又验证性的清除机制。该工作确凿地证明了联盟级归因可以有效解决局部删除无法侦测的“冗余冲突遮蔽”问题，其理论化、模块化、可解释性的方法框架对智能体记忆安全相关方向具有贡献。主要待补强之处是算力估算和更大规模、更自然的长期记忆测试。
