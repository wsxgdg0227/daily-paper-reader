## 摘要
长期对话中的问答智能体必须对海量、时间上分散的对话历史进行推理。然而，现有的记忆机制主要将过去的信息视为被动存储的事实，导致语义鸿沟和不可靠的推理。为了解决这一局限，我们提出了RuleMem，一种基于规则的记忆框架，它从历史交互中归纳出可复用的逻辑规则，以主动指导证据检索和推理。具体而言，RuleMem从对话中构建自然语言的Horn子句，并通过规则困惑度一致性（RPC）机制对它们进行验证。这些归纳出的规则能够检索语义距离较远的证据，同时为答案生成提供显式的逻辑结构。我们在两个长期对话基准LoCoMo和LongMemEval_s*上对RuleMem进行了全面评估。在与LoCoMo上14个基线的严格比较中，RuleMem取得了最高准确率，超出基线平均值27.47个百分点（相对提升54.3%）。

## Abstract
Question answering agents in long-term conversations must reason over massive, temporally dispersed dialogue histories. However, existing memory mechanisms primarily treat past information as \textit{passively} stored facts, leading to semantic gaps and unreliable reasoning. To address this limitation, we propose RuleMem, a rule-based memory framework that induces reusable logical rules from historical interactions to \textit{actively} guide both evidence retrieval and reasoning. Specifically, RuleMem constructs natural-language Horn clauses from conversations and validates them via a Rule Perplexity Consistency (RPC) mechanism. These induced rules enable the retrieval of semantically distant evidence while providing an explicit logical structure for answer generation. We conducted a comprehensive evaluation of RuleMem on two long-term conversational benchmarks, LoCoMo and LongMemEval_s*. In a rigorous comparison against 14 baselines on LoCoMo, RuleMem achieved the highest accuracy, exceeding the baseline average by 27.47 points (a 54.3% relative improvement).

## 论文核心问题与整体含义

长期对话问答（Long-term Conversational QA）要求智能体在跨越大量轮次、时间上高度分散的对话历史中进行证据检索与逻辑推理。当前主流外部记忆机制存在两类核心缺陷：

- **事实记忆层（Fact Memorization）**：如 MemGPT、Mem0、LangMem，仅将对话片段按表面或浅层语义相似度存储与检索，面对语义鸿沟（如“预订假期”与“缺席会议”之间无显式关键词重叠）时经常无法召回相关证据，即**检索失败（Recall Failure）**。
- **事实组织层（Fact Organization）**：如 Zep、A-MEM、MemInsight，通过知识图谱、Zettelkasten 网络或分层摘要建立实例级结构关联，但随着规模增大，密集连接引入大量噪音，LLM 难以从杂乱上下文中自行构建有效逻辑链，导致**推理失败（Reasoning Failure）**。

论文整体含义在于：记忆不应只是“被动回忆的对象”，而应成为主动引导检索与推理的“抽象规则库”。作者从人类认知中获得启发——人们会从具体观察中归纳可复用规则（如“近期有出行计划的人可能缺席已安排的活动”），进而提出将记忆提升到**规则归纳**这一更高抽象层面，以同时缓解语义鸿沟和推理链条断裂问题。

## 论文提出的方法论

### 核心思想
RuleMem 提出一种“规则记忆”范式，将历史对话中的具体事实提升为抽象、可复用的逻辑规则，以自然语言 **Horn 子句**（Body ∧ … ∧ Body → Head）形式存储。这些规则在问答时充当“大前提”（Major Premise），主动提示应召回何种证据，并为最终结论提供显式逻辑骨架。

### 框架总览（三步闭环）
整个系统维持两个记忆空间：
- **事实记忆库（MF）**：存放从对话中抽取的（主体、关系、客体、时间戳）四元组。
- **规则记忆库（MR）**：存放经过验证的抽象自然语言逻辑规则。

流程为：**自底向上的规则归纳 → RPC 规则验证 → 自顶向下的规则引导问答**。

#### 1. 自底向上的规则构建
- **事实记忆化**：解析多轮对话，抽取实体关系四元组存入 MF。
- **推理路径挖掘**：将四元组组织为图结构，通过受约束的随机游走采样候选路径，再交由 LLM 筛选并重构形成逻辑连贯的推理路径（保留具体实体）。
- **规则归纳**：将结构相似的路径分组，LLM 将具体实体替换为类型占位符（[Person]、[Event] 等），归纳为通用 Horn 子句规则。

#### 2. 规则验证：RPC（Rule Perplexity Consistency）
由于直接让 LLM 归纳规则会产生过度泛化或幻觉，RuleMem 利用**条件困惑度下降**来检验规则是否同时得到「模型内部先验」与「外部事实证据」的双重支持。给定自回归模型 M，定义：

- **内部一致性信号**：  
  Δself(r) = ℓM(T_head | ∅) − ℓM(T_head | T_body)  
  即：加入规则体后，规则头（结论）的条件困惑度是否显著降低。

- **外部事实一致性信号**：  
  Δfact(r) = ℓM(T_head | T_body) − ℓM(T_head | T_body ⊕ T_evidence)  
  即：在规则体基础上再补充从事实库检索到的相关证据后，结论困惑度是否进一步降低。

- **最终置信度**：  
  RPC(r) = α · σ(Δself(r)) + (1 − α) · σ(Δfact(r))  
  其中 σ 为 Sigmoid，α 控制两个信号权重。只有 RPC 分数超过阈值 τ 的规则才进入规则库。

#### 3. 自顶向下的规则引导问答
- **规则激活**：将新问题与规则库中每个规则的 Head 做向量相似度匹配，选出 TopN 个候选规则（将问题映射到“抽象结论空间”）。
- **引导召回**：用激活规则的 Body（前提条件）作为检索线索，从事实库中召回 TopK 候选事实；再由 LLM 充当“语义合一算子”，根据问题中的具体实体与规则中的类型约束过滤错配证据，得到精确实例化的证据集。
- **显式推理**：将问题、激活规则、召回证据组织到结构化提示中，让生成模型同时获得推理模板与事实支撑，最终产出答案。

## 论文的主要结论与发现

- 在 LoCoMo 上，RuleMem 在多跳、开放域、时间推理等任务中均显著优于最优基线，平均 Accuracy 达到 78.05，比基线平均高 27.47 个百分点（相对提升 54.3%）。
- **引导召回有效缓解检索失败**：规则体作为检索条件使平均召回率从 0.56 提升到 0.79（相对提升 41.1%），说明基于规则的提示能找回语义距离远但逻辑相关的事实。
- **显式推理有效缓解推理失败**：注入抽象规则作为逻辑骨架后，平均推理失败数从 120.4 降到 105.9（下降 12.0%），在 Mem0g 上降低最多（15.5%）。
- **RPC 验证必不可少**：去掉 RPC 后，未过滤的无效规则会干扰推导并导致性能下降；去掉规则抽象后系统退化为基线水平，说明高层规则抽象与验证是核心组件。
- 超参数 α=0.4、τ=0.5 时性能最优，表明外部事实一致性信号占主导、适度内部先验有助于泛化。

## 优点

- **概念创新性强**：将记忆从“事实存储/组织”提升到“规则归纳”，与人类认知中的抽象归纳过程一致，视角新颖。
- **双管齐下解决两大痛点**：规则既充当检索线索（解决语义鸿沟），又充当推理骨架（解决逻辑链断裂），同时针对检索失败与推理失败。
- **规则表达形式严谨**：选用自然语言 Horn 子句，兼顾形式逻辑的整洁性与自然语言的灵活表达。
- **RPC 验证机制有理论支撑**：用条件困惑度下降同时评估内部先验与外部事实一致性，比单纯提示 LLM 检查可靠性更高。
- **实验分析细致**：不仅报告总体指标，还单独量化召回失败与推理失败的缓解幅度，证明每个机制的实际作用；提供案例分析与失败模式剖析，便于理解模型行为。
- **对不同基线的通用增益**：引导召回与显式推理在 7 个不同记忆框架上均带来提升，说明模块设计的迁移性较强。
