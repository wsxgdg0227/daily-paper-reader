## 摘要
智能体记忆系统在长期对话、个性化助手和视频理解方面展现出巨大潜力。然而，持续积累的记忆在推理过程中会引入大量存储和检索开销。为解决此问题，我们提出一种可适配多种智能体记忆系统的通用记忆压缩框架——\textbf{MemForest}。具体而言，MemForest利用全局语义相似性和局部时间连续性，将历史记忆划分为以事件为中心的单元。对每个单元，它构建一棵称为EventTree的最大生成树，并通过选择高权重边渐进式合并冗余记忆节点，从而降低存储开销。此外，我们引入一种锚点引导的传播检索机制，从关键节点的时间邻域中检索相关记忆节点，提高检索精度。大量实验验证了MemForest的有效性。在单模态Mem0框架下，MemForest在三个基准（LoCoMo、LongMemEval和PersonaMem）上以50%的历史记忆压缩率保留了原性能的\textbf{97.1%}，并实现了\textbf{1.89倍}的检索加速。在多模态M3-Agent框架下，它在两个基准（M3-Bench-robot和M3-Bench-web）上以50%的压缩率保留了原性能的\textbf{99.7%}，并实现了\textbf{2.24倍}的检索加速。\textcolor{RoyalBlue}{\textit{我们的代码可在[https://github.com/Celina-love-sweet/MemForest](https://github.com/Celina-love-sweet/MemForest)获取。}}

## Abstract
Agent memory systems have demonstrated significant potential in long-term dialogue, personalized assistants, and video understanding. However, continuously accumulated memory introduces substantial storage and retrieval costs during inference. To address this issue, we propose \textbf{MemForest}, a general memory compression framework adaptable to various agent memory systems. Specifically, MemForest partitions historical memory into event-centric units by leveraging global semantic similarity and local temporal continuity. For each unit, it constructs a maximum spanning tree, termed an EventTree, and progressively merges redundant memory nodes by selecting high-weight edges, reducing storage overhead. Furthermore, we introduce an anchor-guided propagation retrieval mechanism that retrieves relevant memory nodes from the temporal neighborhoods of key nodes, improving retrieval accuracy. Extensive experiments demonstrate the effectiveness of MemForest. Under the unimodal Mem0 framework, MemForest retains \textbf{97.1%} of the original performance while compressing \textbf{50%} of historical memory across three benchmarks (LoCoMo, LongMemEval, and PersonaMem), achieving a \textbf{1.89x} retrieval speedup. Under the multimodal M3-Agent framework, it preserves \textbf{99.7%} of the original performance with a \textbf{50%} compression ratio across two benchmarks (M3-Bench-robot and M3-Bench-web), achieving a \textbf{2.24x} retrieval speedup. \textcolor{RoyalBlue}{\textit{Our code is available at [https://github.com/Celina-love-sweet/MemForest.}}](https://github.com/Celina-love-sweet/MemForest.}})

- 现有智能体记忆系统普遍缺乏**通用、高效的记忆压缩机制**，无法在保持任务性能的同时有效削减记忆规模。
- 因此，论文旨在设计一种**与具体记忆系统解耦的通用压缩框架**，实现记忆瘦身的同时保证检索精度与下游任务表现。

## 二、方法论：MemForest 的核心设计

### 2.1 总体思路

MemForest 是一个**模型无关的通用记忆压缩框架**，可适配不同智能体记忆系统（如 Mem0、M3-Agent 等）。其核心逻辑为：  
> **“事件化划分记忆 → 树形结构化表达 → 冗余节点渐进合并 → 锚点引导精准检索”**。

### 2.2 关键技术细节

1. **事件单元划分（Event-Centric Partitioning）**
   - 利用**全局语义相似度**（判断信息内容是否相关）+ **局部时间连续性**（判断交互是否发生在相邻时间窗口）作为双重标准。
   - 将历史记忆切分为以事件为核心的高内聚单元，避免纯时间切分造成的语义割裂或纯语义聚类导致的时间混乱。

2. **EventTree 构建**
   - 在每个事件单元内部，将所有记忆节点视为图的顶点。
   - 基于节点间的语义相似度构建加权图，并计算该图的**最大生成树（Maximum Spanning Tree）**，即 EventTree。
   - EventTree 通过“最大权重优先”的连接策略保留节点间最强的语义关联，使树中父子节点代表高度相关的记忆内容。

3. **渐进式冗余合并（Progressive Merging）**
   - 在 EventTree 上，从高权重边开始，**逐步合并冗余的叶子/分支节点**到其相邻的关键节点中。
   - 合并策略为：若某节点与其父节点边的权重超过阈值，则说明两者语义高度冗余，可将子节点信息“折叠”入父节点，删除原节点，从而降低存储总量。
   - 整个过程是**渐进式的**，即逐层处理，直到达到目标压缩率或不存在可合并的高冗余边。

4. **锚点引导的传播检索（Anchor-Guided Propagation Retrieval）**
   - 检索时不再对全部历史记忆做暴力相似度匹配，而是先定位**关键节点（锚点）**。
   - 再沿锚点在 EventTree 内部的时间邻域（temporal neighborhood）展开传播，召回相关记忆节点。
   - 相比全局检索，该机制大幅缩减候选集规模，同时因利用了事件树中的语义结构，检索精度反而更高。

### 2.3 算法流程（文字说明）

1. 输入：原始记忆序列 \( M = \{m_1, m_2, ..., m_n\} \)。
2. 计算所有记忆向量之间的语义相似度，并结合时间相邻性，聚类为若干事件单元 \( \{E_1, E_2, ..., E_k\} \)。
3. 对每个事件单元 \( E_i \)，构建以相似度为权重的完全图，用 Kruskal/Prim 类算法生成**最大生成树** \( T_i \)。
4. 在 \( T_i \) 上从高权重边到低权重边依次检测冗余节点对，合并子节点进入父节点，更新树结构，直至达到预设压缩比例。
5. 将压缩后的多棵 EventTree 存入外部记忆库。
6. 推理时，对用户查询进行编码，先召回锚点节点，再在树结构中传播扩展，完成上下文填充。

## 七、亮点与优点

- **视角新颖**：将“记忆压缩”与“检索结构优化”统一进同一框架，压缩后的树形索引与检索机制天然兼容，而非先压缩再低效检索的两阶段割裂方案。
- **兼具语义与时间两个维度的划分信号**：全局语义相似度捕捉内容关联，局部时间连续性保留叙事脉络，划分结果更贴近真实事件的边界。
- **最大生成树的合理引入**：最大生成树在保留最强语义边的同时抑制完全图中的冗余连接，为渐进合并提供清晰的操作空间。
- **渐进式的合并策略**：从高权重边逐步操作，相当于优先消除“最冗余”的节点对，使压缩过程具备可解释性和可控性。
- **实验横向覆盖了单模态与多模态**：通过两种截然不同规模的智能体框架验证，说明方法不是对某一种记忆系统过拟合，普适性好。

## 八、不足与局限

- **可扩展性未知**：论文摘录未提及百万级记忆点时的 EventTree 构建开销，最大生成树计算在大规模图上成本不可忽视，大规模生产力环境下的实际表现仍需进一步验证。
- **细节部分披露不足**：渐进合并中“冗余”的量化阈值、节点合并时的语义融合方式（直接拼接 vs. LLM 摘要 vs. 向量加和）等关键技术细节缺失，影响复现性。
