## 摘要
Blackwell的4位浮点（FP4）张量核心并不会自动使注意力更快，因为一旦其矩阵乘积缩小，softmax转换和片上依赖就占据了主导。我们通过针对非因果推理的Direct-P和一条将前向量化直接传递到反向传播的因果路径来解决这一问题。Direct-P将分数直接映射为FP4概率，在NVIDIA GB200上达到最高2.13倍的bfloat16（BF16）前向吞吐量。因果路径从保存的量化查询和键中重建概率，并使用8位浮点（FP8）梯度操作数，将完整的单GPU 80亿参数更新加速至多1.14倍。相应的分布式训练保留了FP8概率和值；每个测试的MXFP4概率/值训练轨迹都会发散。

## Abstract
Blackwell's 4-bit floating-point (FP4) tensor cores do not automatically make attention faster because softmax conversion and on-chip dependencies dominate once its matrix products shrink. We address this with \emph{Direct-P} for noncausal inference and a causal path that passes the forward quantization directly into backward. Direct-P maps scores directly to FP4 probabilities and reaches up to 2.13$\times$ the bfloat16 (BF16) forward throughput on an NVIDIA GB200. The causal path reconstructs probabilities from saved quantized queries and keys and uses 8-bit floating-point (FP8) gradient operands, accelerating a complete single-GPU 8-billion-parameter update by up to 1.14$\times$. Matched distributed training retains FP8 probabilities and values; every tested MXFP4 probability/value training trajectory diverges.

# 硬件感知 FP4 FlashAttention-4 中文总结

## 1. 论文核心问题与整体含义

- **背景：** NVIDIA Blackwell 架构支持 4 位浮点（FP4）张量核，其矩阵乘法（如 QK 和 PV）速度远超 bfloat16（BF16）。然而，注意力机制内还包含 softmax 概率转换和在线归一化等中间环节，这些非矩阵步骤并不会因 FP4 而加速。当矩阵产品本身变得极快后，softmax 的分数归约、指数运算、概率分块/打包与尺度发布反而成为瓶颈，导致 "FP4 张量核≠ 自动加速注意力"。
- **总体问题：**
  1. **时序问题：** P（概率）处于关键路径上——PV 矩阵指令必须等 softmax 完成分数转换后才能启动，而此前的大量工作无法被隐藏。
  2. **数值问题：** softmax 概率输出跨越极大动态范围，4-bit 有效负载（E2M1）及其块尺度难以在保持精度的同时兼容软硬件约束。
- **核心含义：** 在 D128（head dim 128）的 Blackwell 调度下，仅降低算术精度不够；**TMEM（张量内存）的容量→所有权→依赖关系**，实为限制 QK / softmax / PV 三级流水线重叠的核心因素。需要在硬件敏感的核函数调度层面重新设计概率生成与归一化路径。

## 2. 方法论

### 2.1 总体思路
论文严格将问题分为三类测量边界：
- **非因果（noncausal）前向推理边界**：提出 **Direct-P**，将归一化分数直接映射到 MXFP4（E2M1）概率码，并令分母从"实际被 PV 消费的表示概率"中累积。
- **因果训练反向边界**：保存前向已量化的 NVFP4 Q/K 载荷、尺度与 softmax LSE，反向阶段从保存状态重建概率，避免另建一条 BF16 分数路径。
- **投影与全模型更新边界**：学习型投影（QKV/O）保持独立精度；输出前投影的 Q/V 布局在 epilogue 中直接发布，避免独立转置/量化 kernel。

### 2.2 前向核心——Direct-P 的三个修复

**Fix 1: 分数直接映射到 E2M1 码**
- 不是先算精确 FP32 指数再舍入，而是将 E2M1 七条舍入边界视为**码分类问题**；对线性加权分数做回归：
  - 每个 N32 分块选择 2 的幂幅度 αB=2eB（E8M0 字节 uB=eB+127）。
  - 理想输入映射：
    $$
    x_{ij}=(z_{ij}-m_i)\log_2e-e_B+\log_26,\quad q_{ij}=Q_{E2M1}(2^{x_{ij}})
    $$
  - 实现用打包 FMA（FFMA2）与 Blackwell 原生转换指令 (F2FP)，而不是逐项求指数；部分位置可选择硬件 EX2 以获得更均衡的调度。
- 通用快速系数 `A=1.50, B=1.20`；Wan 层使用 `A=1.60, B=0.95`。
- 该设计是为了**缩短关键路径**：避免先构造高精度 FP32 指数再舍入的冗余步骤。

**Fix 2: 以"被表示的"概率做归一化**
- 分母不来自独立近似的浮点 exp 求和，而是直接累加被 PV 消费的 E2M1 权重码与块（有效重构步长 δB=αB/6），使分子/分母描述同一个近似算子（公式 19–21）。
- 打包字求和用字节置换、无进位字节加与 DP4A 指令完成，减少寄存器活性与调度长度。

**Fix 3: 仅为极端 logits 层增加锚定/A防下溢**
- 在极少数层（如 Wan 的层 33–34 和 38–39）启用采样锚:
  - 约 128 个全局分布的 K/V 行被物理移到第一个 K/V tile，令锚值近似行最大。
  - 行参考 mi=ai+M/ln2，并设置存储尺度位移 L，使工作字节始终下界 ≥L+1，绝不在 E8M0 码 1 时发生次正规中间量（(s/6)·Σc 被冲刷为零的问题）——改为 s·(Σc/6) 的顺序。
- 保持 `M+L≤126`，以 2⁻L 公共因子在分子/分母间消去。

### 2.3 因果训练反向设计
- 前向保存：
  - NVFP4 Q/K 的字节与块尺度 + 每 head 全局 Q–K 因子；同时保存每行 LSE 归一化子。
- 反向将前向训练乘法展开为 5 个分块矩阵乘积：
  - dP=dO·Vᵀ（E5M2 dO，因 E4M3 会舍入 97% dO 为零）；dV=Pᵀ·dO。
  - 从保存的 Q/K 重建 P；用 dV 和 dP 计算中心化 dS=P⊙(dP−r1ᵀ)，其中 r=⟨O,dO⟩；
  - dQ=dS·K, dK=dSᵀ·Q。
- 梯度操作数采用 FP8：前向 P/V 为 FP8（E4M3；区间适用时辅以 E5M2 的 dO），而 QK 乘法保持 NVFP4 尺度，V 的 E4M3 视图为反向提供 dP。最终累积为 FP32，输出 dQ/dK/dV 为 BF16。

- **不足**：*单轨迹对比并不能估计 run-to-run 变异度*。大规模分布式是单次运行；一些表格来自历史快照或 “cross-run” 参考，并非完全局部 A/B（尤其 B300 行）；部分数据（如某些 B300 原始后端捆绑）未以 raw 形式完全公开，只校验了提交摘要。

## 6. 主要结论与发现

1. **Direct-P** 使非因果 D128 前向在 GB200 上的 BF16 几何平均加速达 **2.023×**，峰值 2998 TFLOP/s（S32768/H24）；对 B300 S8192 与 wave-aligned S9472，可达 3116/3159 TFLOP/s。
2. **加速的代价明确**：
   - NV/MX fast 平均余弦约 0.9438，HAO NV/FP8 约为 0.9899；相对 L2 ~0.336 对比控制。
3. 模型级误差可能被隐藏：
   - ViT S4096 fast 达到 top-1 88.5%，与 BF16 相同（预测一致性 95.5%）；ViT-MAE PSNR落回到 23.896 dB，仅为 −0.020±0.026 dB。
   - Wan 1.3B/14B 扩散快路径加速 1.75×/2.09×，但 20 步后漂移累积（如 14B 余弦 0.8496/relative L2 0.5337）。
4. **训练端因果反向**：
   - 隔离反向核心 1.405×，但一旦补齐 E5M2 dO/统计信息发布，只余 0.986×；
   - 投影参与的注意力（含 QKV projection、RoPE、注意力、梯度）可提速 1.245×；
   - 完整单卡 8B 更新在 B4 最高 1.14×（与 MXFP4 P/V 基本相同）。
5. **MXFP4 P/V 在训练中不稳定**：
   - 四个历史双臂测试和后续高批量测试（更新的 B4 test）均在 FP8 控制之后约 0.08–0.14B tokens 发生分歧；预修剪梯度 norm 高达 1.5M 甚至 18M。
   - 因此在生产训练路线中保留 FP8 P/V 和值（MXFP4 用于前向 P/V 仅在推理部署中有意义）。
6. **硬件启示**：
   - D128 TMEM 512 列已全由两份 128 列 score 与两份输出 accumulator 占用；
   - 真实瓶颈是**分配器所有权和操作数就绪**，而非缺少张量核吞吐：固定 P 的移除节省约 5.23% 时间；
   - B300 更快的原生 EX2 / FP4 并不会自动扩展整个注意力流水线。

## 7. 优点

1. **问题分解得当**：时间关键路径 vs 数值表示范围和格式选择二者分离。
2. **计算与精度分开处理**：Direct-P 的归一化依据被实际表示的 P 码进行，避免了没有意义的额外 FP32 精度开销和描述不符的算子。
3. **注重结果的完整透明度**：
   - 每个关键表说明支持的研究边界；明确废弃过的历史路线与为什么（附录 A/C/G）等。
   - 使用 receipts/commits/SHA256 检查证据链并保留 JSON 清单。
4. **对硬件的理解非常具体**：准确说明 TMA/MMA/tcgen05/TMEM 的所有权依赖、K64 发布粒度、quarter→PV 对、持久网格与波尾问题。
5. 除单算子误差外，还添加完整下游（ViT / BERT / Wan / MAE）和长序列训练验证，并展示多步扩散累积下误差增长的可见性。
6. 对核的精确人工控制：SASS 数量、FMA2 与本地 F2FP / EX2 等细节被直接观察并追求共效。

## 8. 不足与局限

1. **实验覆盖范围有限**：
   - 核心硬件/D128 结论不一定适用 D64——需要不同所有权与分析；
   - 模型的固定输入评估并非细致测量；训练稳定性仅基于单轨迹且设限定在 100B token（且排除全局平均值不确定性）。
2. **精度与效率妥协较大**：
   - fast 路径（平均 ~0.94 余弦）误差不小；20 步的 Wan 视频生成质量显著下降（相对 L2 ~0.53），仍然显著低于 BF16/已发布的 NV/FP8；
   - 精度需要真实依赖任务来决定是否合适；某些输出分布在任何固定输入中仍然边缘性不可用（极端日志情况），必须靠 guard 层保护。
3. **训练路线尚无全 FP4**：
   - 学习型投影和 注意力 P/V 仍然分开；梯度使用 FP8/E4M3/E5M2；MXFP4 的不稳定表明无法直接快速进化到全 FP4。
4. **透明度的界限**：
   - 一些 B300测量或历史对比不是完全线性同机的 A/B（是跨运行或硬件背景）；
   - 部分相关数据存储为 “summary” 而非完整原始序列；并未给出所有分布式轨迹的 raw 序列；
   - 有些被废弃的方向未给出详细数据，只给出了结果声明。
5. **无统计学检验**：
   - 分布式配对没有给出数据集差异估计；常用数字报告的是单一长期运行；
   - 分类测试数据（SST-2）很小；ViT S1024/S4096虽然足以支持某些初步推断，但有限的固定样本可能让预测结果偏差较大。
