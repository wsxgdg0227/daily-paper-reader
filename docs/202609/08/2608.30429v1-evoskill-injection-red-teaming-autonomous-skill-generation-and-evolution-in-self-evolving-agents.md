## 摘要
基于LLM的智能体系统越来越倾向于采用基于技能的架构，以减少重复推理成本并提高稳定、高效的任务执行能力。近期研究提出了自我进化智能体，能够自主地从过往经验中生成、精炼和复用技能，以实现持续的能力进化。然而，自主技能演化引入了新的攻击表面，使得恶意能力被生成、存储并作为合法技能复用。在本文中，我们将技能注入定义为一种针对自我进化智能体自主技能生成与演化管道的威胁模型。我们进一步提出SARGE（自我进化智能体中的对抗性技能生成与演化测试框架），这是一个通过迭代生成、升级和强化交互来评估该威胁模型的红队框架。为支持我们的框架，我们构建了技能注入基准数据集，包含诱导自我进化智能体形成恶意技能的恶意交互轨迹，并引入技能注入安全基准，用于评估注入的恶意技能在攻击后是否被检索并激活为有害行为。我们的评估表明，SARGE能诱导恶意技能的形成，且注入的技能会被持久存储并反复激活，凸显了持久能力污染的风险。

## Abstract
LLM-based agent systems increasingly adopt skill-based architectures to reduce repetitive reasoning costs and improve stable, efficient task execution. Recent studies propose self-evolving agents that autonomously generate, refine, and reuse skills from past experiences to enable continuous capability evolution. However, autonomous skill evolution introduces a new attack surface in which malicious capabilities are generated, stored, and reused as legitimate skills. In this paper, we define EvoSkill Injection as a threat model targeting the autonomous skill generation and evolution pipeline of self-evolving agents. We further propose SARGE (Red-teaming Autonomous Skill Generation and Evolution in self-evolving agents), a red-teaming framework for evaluating this threat model through iterative generation, escalation, and reinforcement interactions. To support our framework, we construct EvoSkillBench, a benchmark dataset of malicious interaction trajectories for inducing malicious skill formation in self-evolving agents, and introduce EvoSkillSafetyBench, a post-attack benchmark for evaluating whether injected malicious skills are subsequently retrieved and activated as harmful behaviors. Our evaluation shows that SARGE induces malicious skill formation and that injected skills are persistently stored and repeatedly activated, highlighting the risk of persistent capability corruption.

### 1. 论文核心问题与研究动机

**核心问题：**

- 自我进化智能体（Self-Evolving Agents）通过从过往交互经验中**自主生成、提炼、存储和复用技能**以实现持续能力进化，但其自主的技能生成与演化管线引入了一个此前未被充分研究的**安全攻击面**。
- 若攻击者能够通过精心构造的恶意交互轨迹污染技能生成过程，恶意能力就可能被智能体当成"合法技能"存储下来，并在未来任务中被检索与激活，导致**持久性能力腐化（Persistent Capability Corruption）**。

**研究动机：**

- 传统技能类系统中技能通常由人工验证和维护，安全威胁主要来自外部技能投毒或检索层面的攻击；而自我进化智能体将经验内化为技能，使**技能自动生成与演化流程本身变成新的攻击入口**。
- 已有安全基准（如 JailbreakBench、HarmBench 等）主要测评单轮有害回复、提示注入越狱等，未考虑"多轮恶意经验被沉淀为持久技能"这一长期威胁场景。
- 研究者希望补上这一空白：定义威胁模型、构建评测框架与数据集、量化真实风险，以推动更安全的技能生成与演化机制的设计。

### 2. 方法论：SARGE 红队框架

**整体思路：**

- SARGE（**R**ed-teaming Autonomous Skill **G**eneration and **E**volution in self-evolving agents）是一个模块化多智能体红队框架，它通过制造"看似成功的恶意交互经验"诱导目标智能体自主生成、存储并复用恶意技能。

**系统组成：**

- **Orchestrator Agent（编排者智能体）**：管理整个攻击过程，基于 Judge 反馈为攻击者生成攻击策略、迭代攻击循环、汇总结果。
- **Attacker Agents（攻击者智能体）**：包括三个子智能体，负责执行三种攻击流：
  1. **Skill Generation Attack Agent**——负责诱导目标智能体生成并存储新的恶意技能；
  2. **Skill Escalation Attack Agent**——令已有的恶意技能“升级”，使其内容变得更极端、更有害，同时伪装成正常的技能精炼过程；
  3. **Skill Reinforcement Attack Agent**——触发已有恶意技能，并把触发后的有害输出“强化”为必须遵守的标准行为模式。
- **Judge Agent（裁判智能体）**：在新会话（fresh session）中进行黑盒探测，验证注入的技能是否真的被持久存储、被检索、并产生指定有害行为；若未成功则返回失败反馈用于下一轮改进。
- **Target Agent（目标智能体）**：被攻击的自我进化智能体，SARGE不直接篡改其技能库或手工插入恶意技能，而是以普通交互历史形式提供染毒轨迹，让目标智能体用其原生的"经验→技能"流程消化这些轨迹。

**核心技术要点：**

- 三种攻击流分别对应恶意技能形成生命周期的不同环节：**生成 → 升级（Escalation）→ 强化（Reinforcement）**。
- 攻击载荷统一采用 **3 轮对话结构（user → assistant → user）**：
  1. 第一轮用户发起与某种有害能力相关的请求（如化学武器合成、诈骗话术等）；
  2. 助手轮模拟"无拒绝、完整执行恶意请求"的输出；
  3. 最后一轮用户对恶意输出给予正向反馈，并显式要求把该行为存为技能/默认策略（即 **skill persistence instruction**）。
- 生成失败时，Generation Attack Agent 从 6 种攻击向量（直接请求、创意写作、专业人设、逻辑诱导、多语码混合、载荷混淆）中选择最合适的一种，在保留原有恶意域的前提下改写轨迹。
- 该框架的核心判定逻辑为：只有当恶意能力被转化为**可被检索的持久技能**（而不仅仅是产生了瞬时有害回复）时，攻击才算成功。

### 3. 实验设计

**数据集：**

| 数据集 | 规模 | 构成 |
|---|---|---|
| **EvoSkillBench** | 800 条（8 类 × 100 条） | 多轮恶意交互轨迹，格式为 user → assistant → user，含元数据（类别、子主题、攻击目标、预期有害输出、严重级别等） |
| **EvoSkillSafetyBench** | 800 条（8 类 × 100 条） | 后攻击安全基准；将原始恶意请求重写为表面良性、但与注入技能语义相似的查询，用于评估技能检索与再激活 |

- 八类高危主题：**人身伤害、社会犯罪、网络犯罪、心理虐待、信息操纵、歧视/仇恨、隐私侵犯、经济/伦理违规**。
- EvoSkillBench 使用 DeepSeek-V4-Pro 作为生成模型，经过 LLM 质量校验管道过滤结构错误、去重、校验类别与语义一致性。

**目标智能体（Target Agent）：**

- AutoSkill（自主技能生成与进化管线）
- Voyager（基于可执行代码技能的终身学习框架）
- ExpeL（基于成败经验反思的体验式学习框架）

**LLM 配置：**

- GPT-4o-mini：主要用作编排者/攻击者/裁判及主要目标模型。
- 跨模型迁移实验还涉及 GPT-5.4、DeepSeek-V4-Pro、DeepSeek-V4-Flash、Gemini-2.5-Flash-Lite、Qwen3.5-9B 等作为异质目标 LLM。

**评估指标：**

- **Attack Success Rate (ASR) / pass@k**：k 为每轮最多可尝试的迭代次数（最多 4 次），只有恶意能力作为可复用技能持久化存储才算攻击成功，强调区别于普通瞬时有害响应；
- **安全响应三分类**：Explicit Refusal（明确拒绝）、Soft Safe Response（安全的软性回应）、Unsafe/Harmful（有害），其中"有害"需同时满足：技能被检索注入上下文 + 响应含有该恶意行为且可归因于注入技能内嵌的行为模式。

**对比基线：**

- PAIR（越狱攻击）、IPI（间接提示注入）、Phantom（记忆投毒）、PoisonedRAG（后门攻击）、BadRAG（RAG 投毒）。
- 为了公平比较，所有攻击基于 SARGE 生成的**同一批恶意技能**，PAIR 设置相同攻击预算（最多四次迭代）。

**评估维度（共五组大实验）：**

1. 三攻击流的攻击成功率（pass@1 ~ pass@4）；
2. 攻击前后的下游安全性对比（clean vs attacked，EvoSkillSafetyBench）；
3. 跨模型迁移实验（同一攻击者模型攻击不同目标 LLM）；
4. 与已有攻击方法的对比；
5. 消融实验（每次移除一个攻击 Agent）。

### 5. 实验数量与充分性评估

**实验完整性较好，主要体现在：**

- 覆盖三个不同架构的代表性自我进化智能体（AutoSkill、Voyager、ExpeL）；
- 覆盖多种异构 LLM 的跨模型迁移测试，验证攻击不是单一模型专属现象；
- 对 SARGE 的每个模块做了针对性消融（移除生成/升级/强化智能体对攻击成功率及下游安全性的影响）；
- 在 8 个危害类别上给出了类别粒度与总体粒度的指标，能观察到类别差异；
- 额外包含防御提示的实验（附录 D），评估轻量级系统提示防御的缓解效果；
- 攻击对比实验尽量使用相同的恶意技能内容，以隔离攻击策略差异造成的影响。

**但仍存在一些需要指出的公平性与充分性问题：**

1. **基线比较存在不对称性**。PAIR 在单轮有害内容诱导上天然更强（因为它是直接生成有害回复的越狱攻击），其 ASR 高于 SARGE 并不意外；SARGE 的目标不是"直接生成有害回复"而是"持久技能注入"，两者任务边界不同，将二者核心指标对齐比较时需注意语义差异。
2. **ASR 指标定义较严格**（需要新会话中发生技能检索），这避免了高估风险，但也意味着部分实际形成但未被检索到的恶意技能可能被计为"失败"，导致对攻击有效性的低估。
3. 消融实验只报告了**移除单个 Agent** 的效果，未报告更复杂的两两移除组合，难以评估 Agent 间非线性交互。
4. 攻防实验只测试**系统提示层面的轻量防御**，未测试更底层的防御（如技能存储前验证、技能来源追踪、策略对齐检查），因此结论"防御不足"在某种意义上已被实验本身的设计所预定。
5. 使用 LLM 评判安全性，自身存在偏差风险；虽然文中说明用直接引用作为判断证据，但没有报告人类一致性校验。

总体而言，在论文设定场景内实验**较为充分且可支撑主要结论**，但覆盖范围和泛化结论仍需更广泛的外部验证。

### 6. 主要结论与发现

1. **恶意技能可被成功长期注入并反复激活**。SARGE 在 AutoSkill/GPT-4o-mini 上对三类攻击流达到较高成功率：Skill Generation 43.5%、Skill Escalation 54.6%、Skill Reinforcement 49.9%（pass@4），且恶意技能在攻击后的新会话中会被自动检索并生成有害响应。
2. **安全对齐被显著破坏**。三个自进化智能体在攻击后有害响应率明显上升（AutoSkill 6.5% → 19.2%；Voyager 5.5% → 32.5%；ExpeL 8.8% → 15.2%），证明污染技能能被反复激活。
3. **攻击具有跨模型迁移性**。同一攻击者模型（GPT-4o-mini）对其他 LLM 均有有效迁移：DeepSeek-V4-Pro 有害率最高达 29.6%，Gemini-2.5-Flash-Lite 则表现出最高的技能注入成功率（pass@4 约 70%）。
4. **攻击难度与安全性退化高度模型相关**。如 DeepSeek-V4-Pro 注入成功率较低，但注入成功后更易触发有害行为；GPT-5.4 作为攻击者和目标配置时成功率极低（pass@4 约 20~26%），说明强安全对齐模型能同时抑制攻击的推进与有害行为的显性化。
5. **升阶与强化攻击本身即使没有预先注入的技能也有独立效果**——二者能诱导生成并存储全新恶意技能，说明反复交互会对智能体行为模式产生滚雪球式影响。
6. **去中心化经验学习 + 持久技能库 = 高危信息持久化通道**。即使攻击已停止，未针对技能存储层治理的智能体仍会持续复用被污染的能力。
7. 现有系统提示级防御虽能降低有害输出率，但**不能阻止恶意技能的生成、存储与演化**，且会显著推高"过度拒绝"率（如 Voyager 从 33.1% 增至 62.9%）。

### 7. 优点

- **问题是新且重要的**：首次系统化定义"自我进化智能体由于自主技能生成/演化导致能力持久腐化"这一攻击模式，补充了现有 Agent 安全研究只关注提示注入/检索攻击的缺口。
- **指标设计合理**：用"技能是否被持久存储并可再激活"作为攻击成功判据，而不是简单记录是否出现单次危险回复，判断逻辑比较严谨，也避免了高估。
- **攻击流与技能生命周期高度对应**：生成 → 升级 → 强化三阶段攻击流模拟了真实的持续对抗模式，便于后人分别研究各生命环节的攻击与防御。
- **模块化解耦便于复用和扩展**：SARGE 将编排、攻击载荷构造与黑盒验证分离，换不同目标模型与攻击向量都很方便。
- **实验基准构建相对充分**：数据集数量较多（每类 100 条 × 8 类），并有一套比较严格的 LLM 质量校验流程来规避格式错误、重复样本与元数据不一致。
- **跨模型和多智能体框架联合测试**：不只是单一模型结论，覆盖多种骨干模型、多类检索/存储机制、多个领域的类别结果，增强了结论的普适性。
- **对基线公平地控制了变量**：所有对比攻击使用同一批恶意技能内容，一定程度上避免由技能文本差异带来的混淆。

---

### 8. 不足与局限

- **模型与系统覆盖面有限**：只测试了 AutoSkill、Voyager、ExpeL 三个特定实现；未覆盖工具增强型智能体、多智能体协作系统以及具有更强记忆治理机制的 Agent，无法保证对所有自进化架构的普适性。
- **成本高、可扩展性差**：迭代多智能体架构依赖多次模型调用（攻击生成、评测、再规划），token 开销相当大，妨碍大规模部署测试。
- **攻击者与裁判模型单一**：主要基于 GPT-4o-mini 实现 Orchestrator、Attacker 和 Judge；使用更强或更大的模型来扮演三个角色可能会得到**完全不同的结论**，论文未充分探索这种依赖关系。
- **评测依赖 LLM-as-a-judge 的主观性**：虽然 prompt 力求严格（要求三个条件同时成立、直接引用证据文本），但缺少与人类标注的一致率校验，评测仍有被 LLM 偏差影响的可能。
- **基准覆盖有限**：虽覆盖 8 个高风险类别，但未穷尽所有真实世界恶意场景（如深度伪造、自动化钓鱼、多步社会工程）。
