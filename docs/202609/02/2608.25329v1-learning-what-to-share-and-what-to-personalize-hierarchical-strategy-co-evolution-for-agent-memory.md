## 摘要
记忆增强型智能体在长对话中维护紧凑的用户画像，从而无需处理全部对话历史即可生成个性化且连贯的响应。这些用户画像的质量依赖于底层的记忆管理策略：在每一步中，智能体必须决定保留、压缩或丢弃哪些内容。然而，现有方法通常采用训练前设定的静态、一刀切策略。实际上，最优记忆决策本质上是用户特定的，并随策略优化而动态演变。为解决这一问题，我们提出了\textbf{HiPS}（\textbf{H}ierarchical \textbf{P}ersonalized \textbf{S}trategy，层级个性化策略），该框架将记忆管理解耦为全局共享基础与用户特定自适应层。具体而言，HiPS采用\textbf{通用策略}从跨人设轨迹中提取共享原则，同时通过\textbf{人设增量蒸馏}为行为偏离普遍模式的用户生成定制化规则。\textbf{跨层规则流}通过提升广泛验证的个性化规则并降级矛盾的全局规则，动态校准其边界。该架构构建了一个协同进化循环，其中的机制确保所有策略改进均锚定于任务结果。大量实验表明，与记忆增强基线相比，该方法取得了一致的性能提升。

## Abstract
Memory-augmented agents maintain compact user profiles throughout extended conversations, enabling personalized and consistent responses without the need to process the entire dialogue history. The quality of these user profiles relies on the underlying memory management strategy: at each step, the agent must determine what to retain, compress, or discard. However, existing methods typically employ a static, one-size-fits-all strategy established before training. In practice, the optimal memory decision is inherently user-specific and dynamically evolves alongside policy optimization. To address this, we propose \textbf{HiPS} (\textbf{Hi}erarchical \textbf{P}ersonalized \textbf{S}trategy), a framework that decouples memory management into a globally shared foundation and a user-specific adaptive tier. Specifically, HiPS employs \textbf{Universal Strategy} to extract shared principles from cross-persona trajectories, alongside \textbf{Persona Delta Distillation} to generate tailored rules for users whose behaviors diverge from general patterns. \textbf{Cross-Level Rule Flow} dynamically calibrates their boundary by promoting broadly validated personal rules and demoting contradicted global ones. The architecture establishes a co-evolution loop where a mechanism guarantees that all strategy refinements are anchored to task outcomes. Extensive experiments demonstrate consistent improvements over memory-augmented baselines.

- **研究意义**：该问题直接制约记忆增强型智能体在长期交互中的个性化表现，是构建真正“认识用户”的对话系统的重要瓶颈。

### 2. 论文提出的方法论：核心思想、技术细节与算法

#### 核心思想

将记忆管理策略 `S_p` 分解为两层结构：

```
S_p = S_u ∪ ∆p
```

- **共有策略层（Universal Strategy, S_u）**：跨用户共享的通用记忆管理原则；
- **个性化增量层（Personal Delta, ∆p）**：针对行为偏离普遍模式的用户定制的适应性规则。

通过三层机制实现共享与个性化之间的边界**动态协同进化**。

#### 关键机制

**① Universal Strategy Distillation（USD，通用策略蒸馏）**
- 从**跨用户**的高/低奖励对比轨迹中，让 LLM 元优化器输出**结构化差异（structured diff）**，包含三类操作：
  - `V`（validate）：验证现有规则；
  - `H`（hypothesize）：提出新规则（格式限定为 “[Label]: When [condition], [action]”）；
  - `R`（revise）：修改或撤销规则。
- 每条规则携带**证据级别**（tentative / supported / established），通过多轮验证信号不断升降级，防止噪声规则污染策略。

**② Persona Delta Distillation（PDD，人设增量蒸馏）**
- **先计算分歧度（Divergence）**：

$$D_p = \sum_{r \in S_u} |PG(r|p) - PG(r)|$$

  其中预测增益（Predictive Gain）为：

$$PG(r) = P(Y=1|r^+) - P(Y=1|r^-)$$

- 当分歧度超过阈值 `θdiv` 时，判定该用户需要个性化；低于阈值的用户继续使用通用规则，避免不必要的计算开销和噪声。
- 为需要个性化的用户生成与通用规则**严格不同**的规则，且规则需为**行为导向**（management-oriented）而非内容导向。

**③ Cross-Level Rule Flow（跨层规则流）**
- **Generalization（∆p → Su）**：某条个性化规则在多个用户中得到验证（出现比例 ≥ θflow），则提升为通用规则；
- **Specialization（Su → ∆p）**：当通用规则被修改或撤销时，为受影响用户生成专门的替代规则；
- 该机制让两层规则持续双向流动，动态校准共享与个性化的边界。

**④ 策略注入与协同进化**
- **Submodular 规则选择**：在 token 预算 `B` 内，依据预测增益和语义冗余度选择多元、低重复的规则注入 prompt。
- **奖励设计**（反循环设计, anti-circularity）：
  - `Rans`（任务正确性）→ 仅用于蒸馏缓冲区的轨迹排序与策略更新中的优势计算；
  - `Rfollow`（规则遵循度）→ 仅用于 GRPO 策略优化。
  - 两者分离，防止“规则自我验证”的确认偏误。

#### 训练流程（Algorithm 1）
每步：通过 submodular 选择构建激活策略 → 注入 rollout prompt → 收集轨迹并计算 `Rans` 与 `Rfollow` →（仅使用 `Rans`）更新蒸馏缓冲区 → GRPO 更新策略（使用组合奖励 `Rans + λ·Rfollow`）→ 每隔 `K2` 步执行 PDD、每隔 `K1` 步执行 USD，并执行跨层规则迁移。

### 6. 主要结论与发现

1. **HiPS 在所有 12 个实验设置中均优于全部基线**，验证了分层协同进化设计（通用基础 + 个性化增量 + 动态边界）的有效性。
2. **优势随上下文规模扩大而增强**：在 PersonaMem 128K 上 HiPS 达 62.01%，比最强基线 MemSkill（55.37%）高 6.6 个百分点；在 32K 上（73.49% vs. 64.45%）差距约为 9 个百分点。长上下文中优势更明显。
3. **“域内 vs. 域外重要性翻转”发现**：
   - 域内（PersonaMem）：通用策略（USD）与预测增益（PG）机制是主导因素；
   - 域外（PERMA）：跨层规则流（Flow）与分歧门控（Gate）成为关键，移除 Flow 平均下降 19.4 个点，移除 Gate 平均下降 11.9 个点。
4. **规则确实随训练演化成熟**：Fig. 3 显示 Su 中规则从 tentative 逐步升级为 established，准确率随规则成熟从 52.4% 升至 72.1%，验证了策略确实在动态进化而非静态。
5. **个性化规则的影响高度异质**：部分用户受益巨大（+18.6%），但也不乏受到轻微负面影响者（-3.3%），正好支持分歧门控设计的必要性。
6. **策略具有跨模型迁移性**：蒸馏出的策略可直接移植到其他骨干模型（GPT-4o-mini、Gemini 2.5 flash、GPT-5）并保持优势，说明策略学到了与具体模型无关的记忆管理原则。
7. **记忆规模增长可控**：即使对话从 4K 扩展到 128K tokens，记忆库大小约从 1,000 增至 1,900 tokens 后趋缓，未线性膨胀。

### 7. 优点（亮点）

- **问题定义新颖且深刻**：将记忆管理策略共享与个性化的边界问题形式化为协同进化问题，比单纯的“静态规则蒸馏”或“完全个性化”更具洞察力。
- **反循环奖励设计（Anti-circularity）**：将 `Rans` 用于蒸馏决策、`Rfollow` 仅用于策略优化，从设计层面防止了自我验证偏差——这是一种细粒度且重要的方法论设计。
- **结构化差异提示（structured diff）**：相比自由文本反馈，将规则更新分解为 validate/hypothesize/revise 三类操作，配合证据级别跟踪，使策略更新可审计、可控。
- **分歧门控（divergence gate）**：以预测增益差异识别真正需要个性化的用户，兼顾效果与计算效率，同时缓解冷启动问题。
- **跨层双向迁移**：Generalization 和 Specialization 双向通道让两层策略并非静止并存，而是持续校准边界——这创造了一个真正的分层协同进化循环。
- **跨模型迁移实验**：验证了所蒸馏策略的模型无关性，增加了方法的实用价值。

### 8. 不足与局限

- **语言覆盖有限**：实验仅聚焦英文对话基准，未验证多语言或跨语言场景中的记忆管理策略有效性（作者在 Limitations 中已承认）。
- **长期演进深度不足**：实验最长覆盖约 1M token 交互，但对于“数年日常交互”级别的长期对话中用户基本人格可能发生的范式级漂移，仍缺乏处理方法（作者已承认）。
- **训练数据规模较小且来源单一**：仅从 PersonaMem 32K 中采样 423 个训练实例，未验证数据规模扩大或训练数据跨基准混合时的影响。
- **客观偏差风险**：
  - 所有 HiPS 主实验结果基于同一骨干模型（Qwen2.5-7B），而部分基线使用更大模型（MemSkill: Qwen3-Next-80B-A3B），在模型能力不对等的条件下 HiPS 仍能超过它们，说明方法有一定鲁棒性，但也留下了“更大骨干模型上还能否复现”的疑问；
  - 规则合规性的估算（PG、Rfollow）依赖轻量级关键词匹配启发式，虽在相对排名中具有一定鲁棒性，但其绝对精确性不足。
- **计算开销**：训练中需要定期调用 LLM 元优化器进行策略蒸馏（USD/PDD），推理时虽无额外 LLM 调用，但训练流程整体较为复杂、资源消耗大；文中未报告端到端训练总成本。
- **应用门槛**：框架依赖多个超参数（K1、K2、θdiv、θflow、B、λ 等共 8 个），实际部署到新场景时需重新调参，缺乏自适应调参机制。
