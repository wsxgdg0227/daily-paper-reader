## 摘要
大型语言模型（LLM）越来越多地与外部环境交互并积累大量行为经验，然而现有的智能体基准大多将其作为固定策略进行评估。因此，尚不清楚智能体是否能够主动测试其行为、评判所获得的经验，并利用这些经验来改进未来的决策。我们引入了\textbf{S\textsuperscript{3}Gym}，一个交互式基准，通过三种耦合能力来评估LLM的自我改进：\textbf{自我测试}、\textbf{自我评判}和\textbf{自我改进}。S$^3$Gym将宽松的探索与严格的留出评估分开，并在七个具有可执行环境验证器的基于文本的游戏中实现了该协议。我们评估了三种纳入交互经验的途径：直接历史上下文学习、基于分数的摘要记忆以及参数训练。我们的实验揭示，自我改进既不是自动的，也不是统一的。上下文级别的经验可以提高若干模型-游戏对的性能，但最有效的途径在很大程度上取决于任务结构：当经验可以压缩为可复用的策略规则时，摘要有益，但当成功依赖于精确的、依赖于状态的信息时，摘要往往不如原始历史。参数训练在某些任务上产生了显著的增益，但在其他任务上则表现出不稳定的改进和严重的负迁移。这些发现表明，识别成功行为是不够的；智能体还必须将反馈转化为可执行且可迁移的策略。S$^3$Gym提供了一个统一的框架来诊断这一过程，并识别阻止智能体将交互经验转化为可靠自我改进的瓶颈。

## Abstract
Large language models (LLMs) increasingly interact with external environments and accumulate substantial behavioral experience, yet existing agent benchmarks largely evaluate them as fixed policies. It therefore remains unclear whether an agent can actively test its behavior, judge the resulting experience, and use that experience to improve future decisions. We introduce \textbf{S\textsuperscript{3}Gym}, an interactive benchmark for evaluating LLM self-improvement through three coupled capabilities: \textbf{Self-Testing}, \textbf{Self-Judging}, and \textbf{Self-Improvement}. S$^3$Gym separates permissive exploration from strict held-out evaluation and instantiates this protocol in seven text-based games with executable environment verifiers. We evaluate three pathways for incorporating interaction experience: direct History ICL, score-conditioned Summary Memory, and parameter Training.   Our experiments reveal that self-improvement is neither automatic nor uniform. Context-level experience improves performance for several model--game pairs, but the most effective pathway depends strongly on the task structure: summaries are beneficial when experience can be compressed into reusable strategic rules, yet often underperform raw history when success depends on precise, state-contingent information. Parameter training produces substantial gains on some tasks, but also exhibits unstable improvement and severe negative transfer on others. These findings show that recognizing successful actions is insufficient; agents must also transform feedback into executable and transferable policies. S$^3$Gym provides a unified framework for diagnosing this process and identifying the bottlenecks that prevent agents from translating interaction experience into reliable self-improvement.

## 二、论文提出的方法论

### 2.1 核心思想

- 提出 **S3Gym**（Self-Testing, Self-Judging, and Self-Improvement Gym）：
  - 每个评测周期包含五个阶段：
    \[
    R(p)_t = \text{Explore} \rightarrow \text{Judge} \rightarrow \text{Consolidate} \rightarrow \text{Update }p \rightarrow \text{Evaluate}
    \]
  - 引入 **宽松的探索阶段（Exploration）** 与 **严格的留出评估阶段（Evaluation）**，用不同随机种子和不同难度配置，验证经验能否迁移到新情境。
- 关键设计：把**环境可验证的奖励/分数**与**模型自己生成的自评判分数**明确分离：
  - 模型在探索时只能看到可观察反馈和自己的自评分数；
  - 基准后台才记录 verifier 计算的真实逐步奖励和最终得分；
  - 通过二者对比，可以研究“自评判是否可靠”和“改进失败来自评判错误还是转化能力不足”。

### 2.2 关键技术细节

- 每个回合中，模型基于当前观察、局内历史以及跨回合的经验状态 Z(p) 输出动作和自评即时分数：
  \[
  (a_{x,i}, s_{x,i}) = \pi_{\theta_t}\left(O_{x,i}, H_{x,i}; Z_t^{(p)}\right)
  \]
- 环境执行动作后返回下一观察、可观察反馈、真实奖励和终止信号：
  \[
  (O_{x,i+1}, F_{x,i}, r_{x,i}, d_{x,i}) = \text{Env}(O_{x,i}, a_{x,i})
  \]
- 真实奖励 \(r_{x,i}\) 不直接暴露给模型，仅在后台用于评判可靠性分析；最终得分 \(y_x\) 用于评测性能。

### 2.3 三种经验整合路径（三条技术路线）

1. **History ICL（直接历史上下文）**：
   - 将带自评分的轨迹序列化后直接拼接到后续上下文中；
   - 保留完整交互证据，但受上下文长度限制。
2. **Summary Memory（摘要记忆）**：
   - 模型把已评判轨迹压缩成“可保留策略、应避免的错误、下一步改进方向”三类摘要；
   - 形成信息瓶颈，依赖摘要和自评判质量。
3. **Parameter Training（参数训练）**：
   - 将探索轨迹中高自评分动作制成 SFT 正样本，过滤或修正低分动作，更新模型参数；
   - 不依赖推理时的外部记忆，但可能把错误经验固化为参数，造成负迁移。

## 六、论文的主要结论与发现

1. **自我改进既不是自动的，也不是统一的**。
   - 同一个模型在不同游戏上的改进幅度差异很大；不同模型在同样游戏上表现也不同。
2. **不存在普遍最优的经验整合路径**：
   - **History ICL** 在依赖精确、状态相关信息的任务（如 Minesweeper、PvZ、Snake）上更稳；
   - **Summary Memory** 在经验可压缩成可复用规则的任务（如 Nullify、Tetris、Trust）上更好；
   - 摘要并非总是优于原始历史，反而可能丢弃状态证据或保留错误判断。
3. **参数训练可以带来增益，但问题严重**：
   - Qwen3-8B 在 Trust Evolution 上显著提升（AUC+ 163.5）；
   - 在 Chess 只有微弱后期提升，在 Snake 上时好时坏；
   - 在 Minesweeper、Nullify、Tetris 无提升；
   - 在 PvZ 出现**严重负迁移**（初始 23 分降到固定 6 分）。
4. **自评判不可靠，且准确的局部自评判不足以驱动改进**：
   - 部分游戏（PvZ）有较高二元一致性但 NMAE 高达 0.882，说明“知道对错”不等于“估得准”；
   - Chess 与 Trust 的自评判几乎接近随机，过自信率偏高；
   - 分块分析中，事件一致性与后续分数增益相关性接近 0（ρ ≈ -0.01 至 0.07）。
5. **核心瓶颈在“把反馈转化为可执行、可迁移的策略”**：
   - 摘要若只给出“泛泛建议”或“高层次提醒”，常常无效；
   - 只有把低分信号转化为“明确可执行的动作规则”时，摘要才真正带来改进。

## 七、优点

- **问题设置新颖且关键**：从“静态智能评测”转向“经验驱动的自我改进评测”，切中了 agent 部署中“如何持续从反馈中成长”的核心痛点。
- **统一且可分解的协议**：将自我改进拆为测试、评判、整合、更新、评估五个可操作环节，可诊断瓶颈所在。
- **环境验证器与模型自评判严格分离**：既不过早泄露真实奖励，又能可靠测量评判错误，避免了“用自生成反馈作为唯一真相”的问题。
- **三路径横向对比**：在相同探索预算和相同评测条件下，比较了 History ICL、Summary Memory 与 Parameter Training，便于分析各机制的取舍。
- **诊断深度好**：不仅给分数，还报告 Agreement、NMAE、过自信率、不足自信率以及评判-改进耦合相关性，并展示成功/失败的摘要案例，结论很有解释力。
- **场景选择有层次**：七个游戏覆盖稀疏离散奖励（Chess, Minesweeper, Nullify）和密集连续反馈（Tetris, Snake, PvZ, Trust），有利于区分“偶发突破”和“持续改进”。

## 八、不足与局限

- **算力与实现信息不透明**：未报告 GPU、训练时间、API 成本，难以评估训练路径的可重复性和资源门槛。
- **参数训练实验规模较小**：只有 Qwen3-8B，一个中小型模型，无法判断大模型在参数训练路径下的行为是否不同。
- **自评判分数定义与真实奖励语义不完全对齐**：虽然论文要求模型估计“即时收益”，但真实奖励的稀疏性/尺度多样，可能使 NMAE 等指标存在比较偏差。
- **缺乏对随机方差和任务顺序的正式鲁棒性检验**：N exp / N eval 次数有限，未报告多轮独立重复评估的置信区间。
- **外部效度有限**：文本游戏距离真实世界任务（如代码仓库、客户工作流）仍有较大鸿沟；“可执行规则”的迁移方式不一定能推广到开放环境。
- **部分商业模型被排除**：只在完整跑完 7 个游戏的模型上做汇总，可能引入幸存者偏差；GPT 系列与 Gemini 系列版本更新也会导致结论漂移。
- **自我改进定义存在边界**：论文聚焦单轮探索-评估循环，更长期的递归自我改进（多次持续积累、技能库动态维护）并未被充分验证。
