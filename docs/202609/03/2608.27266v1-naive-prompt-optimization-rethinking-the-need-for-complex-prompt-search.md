## 摘要
高效地跨多样任务改进自主代理对于加速代理型人工智能中的递归自我改进（RSI）至关重要，而提示优化作为一种有前景的方法，能够提供与微调模型权重相当的性能提升，同时降低优化和推理阶段的计算成本。然而，近期的发展越来越倾向于采用不必要复杂的提示优化器。我们引入了朴素提示优化（NPO），一种轻量级单系方法，利用教师模型通过推出反馈迭代地修订提示。NPO以更少的推出次数实现了与GEPA相当或更好的性能，并且其优势随着教师模型能力的增强而增加，这表明更强的教师推理能力可以部分替代优化器端的搜索复杂性。在互动游戏中，NPO总体上与GEPA保持竞争力，而GRPO在某些不太适合提示优化的任务上表现更好。我们还表明，将NPO优化的提示逐字应用于其他学生模型时，能引发类似的性能提升，尤其是同系列模型之间。总体而言，我们的初步结果表明，简单、线性的提示优化可以与更复杂和精细的搜索过程相媲美。

## Abstract
Efficiently improving autonomous agents across diverse tasks is central to accelerating recursive self-improvement (RSI) in agentic AI, with prompt optimization emerging as a promising approach capable of delivering performance gains comparable to those achieved by fine-tuning model weights, while reducing computational costs in both optimization and serving. However, recent developments increasingly favor unnecessarily complex prompt optimizers. We introduce Naive Prompt Optimization (NPO), a lightweight single-lineage method that iteratively revises prompts using a teacher model with rollout feedback. NPO achieves comparable or better performance than GEPA with fewer rollouts, and its advantage increases with stronger teacher models, suggesting that stronger teacher reasoning can partially substitute for optimizer-side search complexity. In interactive games, NPO remains broadly competitive with GEPA, while GRPO performs better on some tasks less amenable to prompt optimization. We also show that NPO-optimized prompts elicit similar performance improvements when applied verbatim to other student models, especially across models within the same family. Overall, our preliminary results show that simple, linear prompt optimization can rival substantially more sophisticated and complex search procedures.

## 2. 方法论

### 2.1 NPO 的核心思想

- NPO 是一种**轻量级、单一谱系（single-lineage）** 的提示优化方法。
- 它不维护多提示候选池，也不使用显式的搜索算法，而是只保留、迭代更新一个当前 prompt。
- 优化过程由一个“教师/反思”模型（teacher/reviser/reflection model）完成：教师观察当前提示、完整的 rollout 轨迹与奖励，然后生成下一版本提示。

### 2.2 算法流程

NPO 的基本流程（伪代码见原文 Algorithm 1）可描述如下：

1. 初始化一个初始提示 P(0)，从任务环境中采样数据样本；
2. 对迭代次数 i = 0, 1, ..., Y−1：
   - 从数据集中采样大小为 N 的小批量 Bi；
   - 使用当前提示 P(i) 在学生模型上运行，得到 rollout 轨迹和奖励 Ri；
   - 构造一个**滑动窗口反馈**：使用最近 W 轮的记录 {P(j), Rj}（j 从 max(0,i−W+1) 到 i）作为教师上下文；
   - 教师模型基于“当前最新提示 + 历史提示与轨迹/奖励”生成新提示 P(i+1)；
3. 返回提示序列和最优候选。

- 与 OPRO 的重要区别：OPRO 仅传入历史 prompt 和标量得分，而 NPO 向教师提供**完整 rollout 轨迹**和每条 rollout 对应的奖励，更加“丰富”；
- 算法使用滑动窗口（如 W = 2）以在“提供足够上下文”和“避免超出教师上下文窗口”之间取得平衡。

### 2.3 对比方法

- **GEPA（GEneric-PAreto）**：维持一个候选 prompt 池，通过 reflection 和基于帕累托的选择机制不断扩展；NPO 与它在“候选谱系结构”上有本质差异。
- **GRPO（Group Relative Policy Optimization）**：基于策略梯度的权重微调方法；将 rollout 奖励组内去均值、按标准差缩放得到优势，使用低秩适配器（LoRA）做参数更新。

### 2.4 受控评测设计（方法论亮点）

为保证对比公平、降低噪声：

- **共享伪随机性（shared pseudorandomness）**：不同优化方法在相同随机种子、相同环境实例上做 rollout，从而进行配对评估；
- **约束解码（constrained decoding）**：使用前缀 trie 对合法动作集合进行 token 级约束解码，强制输出 `<think>...</think> [action]` 结构，避免“格式错误”被误判为“决策错误”。具体实现采用“局部重归一化”：

  \[
  q(t \mid s)=\frac{\exp z_t(s)}{\sum_{u\in A(s)}\exp z_u(s)}
  \]

  也就是在 trie 每个节点上，对标量动作集合内的合法后续 token 做 softmax 重归一化，以消除强制格式 token（如方括号）对动作选择的干扰。

## 3. 实验设计与 Benchmark

### 3.1 数据集/任务

- **HotpotQA**：多跳问答 benchmark；
- **TextArena（22 个游戏）**：覆盖单人和双人交互游戏，包括 2048、Countdown、Minesweeper、LogicPuzzle、Blackjack、KuhnPoker、Checkers、Chess、ConnectFour、Nim、Othello、WildTicTacToe 等，用于测试复杂策略规划与决策能力。

### 3.2 对比设置

- 固定学生模型为 **Qwen3-8B**；
- 教师模型变化：**Qwen3-8B**、**DeepSeek-V4-Flash-preview-0424**、**GPT-5.5**；
- 对比方法：**NPO vs GEPA vs GRPO**；
- 在 TextArena 交互环境中，每个方法使用相同 rollout 预算（约 408 个完整 episodes）进行对比。

### 3.3 跨模型迁移实验

- 在 Qwen3-8B 上优化出的 prompt，不加修改地应用到：Qwen3-14B、Qwen3-32B（同族）、Llama-3.1-70B-Instruct、Llama-3.3-70B-Instruct（跨族）；
- 在 Llama-3.1-8B 上优化出的 prompt，迁移到：Llama-3.1-70B-Instruct、Llama-3.3-70B-Instruct（同族）、Qwen3-32B、StepFun-3.7-Flash（跨族）。

### 3.4 主要评测结果概览

- 在 IFBench/HotpotQA 中，当教师为 GPT-5.5 时，NPO 的收敛速度和峰值性能最好，且使用 rollout 数少于 GEPA；
- 跨模型迁移中，同族迁移（如 Qwen→Qwen）增益明显，跨族（如 Qwen→Llama）也有增益但更不稳定；
- 在 22 个 TextArena 游戏上，NPO 和 GEPA 相当；部分任务上 GRPO 更优，提示优化并不总是能压过 RL。

## 6. 主要结论与发现

- **NPO 用更少 rollout 达到或超过 GEPA**：在 IFBench 和 HotpotQA 上，NPO 相比复杂多候选搜索方法 GEPA，性能相当或更好；
- **教师越强，NPO 优势越明显**：随着教师模型从 Qwen3-8B 到 DeepSeek-V4-Flash 再到 GPT-5.5，NPO 的提升更一致、收敛更快；而 GEPA 从更强教师中获得的收益相对有限；
- **提示可迁移性**：优化出的 prompt 可以直接迁移到其他学生模型。同族跨规模迁移基本稳定保留增益，跨族迁移也有增益但更弱、更不稳定；
- **在交互游戏中没有“万能冠军”**：NPO 与 GEPA 大体相当，GRPO 在若干任务（如部分 RL 更适用的环境）上表现更好，说明不同任务可能适合不同形式的优化；
- **验证集泄漏不存在显著风险**：NPO/GEPA 优化出的 prompt 会自然积累训练集答案信息，但与验证集标准答案的重合几乎为零；
- **总体主张**：简单线性迭代式提示优化已经是一个稳健、有竞争力的强基线；复杂的提示搜索或参数优化只有在特定任务上带来明确收益时才值得采用。

## 7. 方法上的亮点

- **极简设计**：NPO 仅用一个 prompt 谱系、一个教师模型加 rollout 反馈，不需要维护候选池、帕累托选择等机制，代码层面应该也很简单；
- **强反馈信息**：利用完整轨迹而不是标量分数，让教师能更充分理解失败模式和语义错误；
- **低方差评测**：共享环境随机性 + 约束解码的组合非常关键，可以避免“格式崩坏”和“环境难度不一致”导致的方法误判；
- **泄漏检测实验**：作者专门对比 prompt 与训练集/验证集答案的 overlap，排除“评测集污染造成增益”的疑虑；
- **跨模型迁移研究**：验证了提示优化的“便携性”这一核心优势，比只看同模型自我优化更贴近实际应用场景；
- **负责任-使用讨论**：同时考虑了教师模型可能被恶意用于增强有害任务 agent、以及需要屏蔽敏感数据的问题。

## 8. 不足与局限

- **任务覆盖仍有限**：没有证明 NPO 的优势能扩展到更复杂、更长时程的 agent 环境；用户任务上的长程规划问题尚无结论；
- **未评估最新最强学生**：没有将 GPT-5.5 这类前沿闭源模型作为学生，原因包括 API 时间性能不一致、缺少 token 级 logits 和足够细粒度的解码控制；
- **RL 对比存在不完全公平风险**：GRPO 的 reward 设计因任务而异，部分任务更利于 RL；论文也指出 RL 在部分游戏上训练不稳定，不同任务可能偏好不同 RL 算法或奖励形式；
- **跨族迁移不够稳定**：虽然整体上有正增益，但个别任务/模型组合出现负迁移或增益很小；
- **上下文成本问题**：更长轨迹会显著增加 teacher 的上下文负担，滑动窗口设计的适用性仍有待更复杂环境验证；
- **泄露判断不能完全排除训练数据污染可能性**：尽管验证集 overlap 很低，但教师模型从训练数据中获取“参数化知识”再间接影响 prompt 的风险仍难以完全量化。
