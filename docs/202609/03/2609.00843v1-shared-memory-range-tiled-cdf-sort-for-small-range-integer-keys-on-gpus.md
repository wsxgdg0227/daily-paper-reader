## 摘要
我们研究了GPU上对元素位于已知整数范围内的数组进行不稳定整数排序的问题。聚焦于基于计数排序的方法，该方法通过每个值的频率及频率的前缀和确定其输出区间，我们提出并评估了范围分块CDF排序（RT-CDF），它将可能的取值范围划分为适合共享内存的小区间，称为块。对于每个块，RT-CDF构建直方图，计算其前缀和作为局部CDF，并直接从该局部CDF生成输出数组。我们将RT-CDF与三种基线进行比较：CUB DeviceRadixSort（其处理的位范围限制为$[0,\lceil\log_2 R\rceil)$以利用已知范围大小$R$）、Ref-H-P排序以及基于Kolonias等人算法的实现。在NVIDIA GeForce RTX 4090上，针对范围大小从$R=2^7$到$2^{18}$、输入大小从$n=10^6$到$10^9$，以及均匀分布、正态分布和全相等输入进行的实验表明，对于小到中等范围，RT-CDF在广泛的条件下优于基线，相对于最快基线实现了最大4.39倍的加速。然而，对于$R=2^{18}$，在每个评估的输入大小和输入分布下，至少有一个基线优于RT-CDF，这表明直方图构建的成本限制了RT-CDF对更大范围的适用性。

## Abstract
We study unstable integer sorting on GPUs for arrays whose elements lie in a known integer range. Focusing on counting-sort-based methods that determine the output interval of each value from its frequency and the prefix sums of the frequencies, we propose and evaluate Range-Tiled CDF sort (RT-CDF), which partitions the possible value range into small intervals, called tiles, that fit in shared memory. For each tile, RT-CDF constructs a histogram, computes its prefix sum as a local CDF, and directly generates the output array from the local CDF. We compare RT-CDF against three baselines: CUB DeviceRadixSort, whose processed bit range is restricted to $[0,\lceil\log_2 R\rceil)$ to exploit the known range size $R$; Ref-H-P sort; and an implementation based on the algorithm of Kolonias et al. Experiments on an NVIDIA GeForce RTX 4090 with range sizes from $R=2^7$ to $2^{18}$, input sizes from $n=10^6$ to $10^9$, and uniformly distributed, normally distributed, and all-equal inputs show that RT-CDF outperforms the baselines over a broad set of conditions for small to medium ranges, achieving a maximum speedup of 4.39 over the fastest baseline. For $R=2^{18}$, however, at least one baseline outperforms RT-CDF for every evaluated input size and input distribution, showing that the cost of histogram construction limits the applicability of RT-CDF to larger ranges.

## 1. 核心问题与研究动机

- **研究问题**：面向 GPU 的、针对已知整数取值范围数组的**不稳定排序**问题。其核心设定是：输入数组 `A` 包含 `n` 个整数，其取值范围已知为 `[minVal, maxVal)`，范围为 `R = maxVal - minVal`。
- **研究动机**：
    - 排序是 GPU 计算中的基础操作，但通用排序（如基数排序）未充分利用“取值范围已知且较小”这一先验信息。
    - 现有的计数排序类方法（如 H-P sort、RefHP 等）通过直方图与前缀和来确定每个值的输出区间，但面临两个关键瓶颈：
        1.  **内存访问开销大**：构建用于整个范围的直方图（或 CDF）涉及全局内存的读写，代价高昂。
        2.  **工作负载不均**：如果排序线程按“值”分配，当某个值出现次数极多时，该线程会成为严重瓶颈（如全等输入场景）。
    - 因此，需要设计一种能充分利用已知小范围特性、规避上述瓶颈的高效 GPU 排序算法。

## 2. 方法论：RT-CDF

- **核心思想**：采用**分块处理（Range-Tiling）** 策略，将整个值域 `R` 划分为若干个**互不重叠、且宽度 `T` 适合放入共享内存**的小区间（称为 Tile）。该方法将计数排序的核心操作（直方图构建与前缀和）局部化到每个 Tile 的共享内存中完成，从而避免全局内存的频繁访问与原子操作竞争。

- **关键术语**：**局部 CDF** (Local CDF)：指单个 Tile 内直方图的排他性前缀和数组，数组的最后一个元素值表示该 Tile 包含的元素总数，数组的每个元素给出了该 Tile 内对应值的输出边界。

- **算法流程**（包含四个阶段）：
    1.  **分块直方图构建**：每个线程块只负责扫描输入数组并更新**一个特定 Tile** 的共享内存中的直方图。原子操作只会发生在共享内存中，降低了全局原子操作的延迟。
    2.  **局部 CDF 构建**：在全局内存中对每个 Tile 的直方图执行**独立的前缀和扫描**，原地生成该 Tile 的局部 CDF。
    3.  **Tile 偏移量计算**：通过顺序累加每个 Tile 的局部 CDF 的最大值，计算出每个 Tile 的**起始偏移量**（即比该 Tile 所有值都小的元素个数）。
    4.  **输出生成**：对于每个非空 Tile，启动**独立内核**，将局部 CDF 从全局内存加载到共享内存。每个线程负责确定一个输出位置的值，通过**二分查找**局部 CDF，找到该值所在的输出区间，然后直接写入 B 数组。

- **算法核心（输出生成）**：不同于传统方法扫描输入或对整个输出数组计算前缀最大值，它直接利用各Tile的局部CDF进行**二分查找**，并行地为每个输出位置确定值。

## 6. 主要结论与发现

- **RT-CDF 在中小范围（R ≤ 2^17）下全面占优**：在绝大多数实验条件下，RT-CDF 的性能均优于 CUB、RefHP 和 Kolonias 实现。相对于最快基线，最大加速比达到 **4.39 倍**（R = 2^9 且全相等输入）。
- **天然适应偏斜数据**：面对全相等或正态分布等非均匀数据时，其性能受输入分布影响很小。相比之下，Kolonias 方法因按“值”分配工作量而严重失衡，而 CUB（基数排序）等也会因数据分布而波动。RT-CDF 通过按 Tile 和输出位置分配线程，天然规避了负载不均的问题。
- **性能边界清晰**：RT-CDF 的优势在 **R = 2^17** 时开始减弱（仅对极大输入仍保持优势），到 **R = 2^18** 时性能完全被基线方法超越。
- **性能瓶颈揭示**：通过时间分解实验发现，RT-CDF 的性能瓶颈在于**分块直方图构建**阶段。由于需对每个 Tile 都扫描一次输入数组，输入规模 n 和分块数 m 的增加会导致 `O(mn)` 次的输入读取，这成为限制其扩展到更大范围的关键因素。
