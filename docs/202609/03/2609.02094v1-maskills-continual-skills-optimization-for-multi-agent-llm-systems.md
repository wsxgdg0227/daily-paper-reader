## 摘要
基于LLM的多智能体系统在复杂任务上表现出色，但从交互经验中持续改进仍然具有挑战性。现有的自我反思方法构建经验记忆，但这些记忆大多难以调用、细化或扩展，而智能体技能提供了一种更具可操作性的单元：结构化的程序性知识，规定了何时行动、如何行动以及使用哪些资源或工具。我们提出了MASkills，一种通过智能体技能优化多智能体LLM系统的持续学习框架。MASkills提出了一种新的智能体优化流程，该流程整合了技能条件信用分配、层级信用聚合和动量平滑优化，使得智能体技能库能够通过细化、归纳、整合和剪枝进行演化。在HotpotQA、LoCoMo和GAIA上的实验证明了MASkills在多种智能体任务上的有效性。我们的代码可在https://github.com/DaRL-GenAI/MASkills获取。

## Abstract
LLM-based multi-agent systems have shown strong performance on complex tasks, yet continual improvement from interaction experience remains challenging. Existing self-reflection methods build experience memories, but memories are mostly hard to invoke, refine, or scale, while agent skills offer a more actionable unit: structured procedural knowledge that specifies when to act, how to act, and which resources or tools to use. We introduce MASkills, a continual learning framework that optimizes multi-agent LLM systems through agent skills. MASkills presents a new agent-optimization pipeline that integrates skill-conditioned credit assignment, hierarchical credit aggregation, and momentum-smoothed optimization, enabling agent skill libraries to evolve through refinement, induction, consolidation, and pruning. Experiments on HotpotQA, LoCoMo, and GAIA demonstrate the effectiveness of MASkills across multiple agentic tasks. Our code is available at https://github.com/DaRL-GenAI/MASkills

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：基于 LLM 的多智能体系统（multi-agent LLM systems）已在复杂任务上展现出强大性能，通过角色分工、协作和长周期交互来解决单一智能体难以完成的挑战。
- **核心问题**：多智能体 LLM 系统如何从历史交互经验中**持续改进自身能力**？现有方法（如自我反思、经验记忆）虽然能保留部分有用经验，但存在以下结构性缺陷：
  - 记忆只记录了"发生了什么"，而非"哪种行为策略值得复用"；
  - 缺乏可靠、可泛化的调用条件；
  - 随着记忆不断增长，无用、噪声和过时的记录混杂，难以扩展和精炼。
- **核心洞察**：相比"经验记忆"，**技能（Skill）** 是更可操作的持续改进单元——它是结构化程序性知识包，明确说明"何时调用、如何行动、使用哪些资源/工具"，支持渐进式披露（progressive disclosure）与按需加载。
- **多智能体场景下的特有挑战**：
  1. **技能级信用分配困难**：团队奖励需要归因到"正确的智能体 × 正确的技能"，而非仅到智能体层面；
  2. **交互噪声与异构性**：语言反馈不稳定，且不同协调拓扑（集中/去中心/层次化）产生不同依赖与信用传播模式；
  3. **离散且高风险的技能更新**：技能是语言工件（如 SKILL.md），不同于参数向量，修改直接改变智能体的有效动作空间，稳定性难以保证。
- **整体含义**：MASkills 提出了一种语言空间中的持续学习范式——将多智能体策略改进从"参数空间"迁移到"技能空间"，使系统能够从分布式经验中不断打磨可复用的程序性知识库。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架

MASkills 将多智能体系统建模为 **Dec-POMDP**，并把每个智能体的策略通过其技能库重新参数化。优化目标是直接优化智能体的技能库集合，采用**语言空间中的策略梯度风格框架**——"策略梯度"是一种结构化类比而非真实导数，包括四步闭环流程：

1. **多智能体技能执行**（Multi-Agent Skill Execution）
2. **细粒度技能信用分配**（Fine-Grained Skill Credit Assignment）
3. **稳定化语言梯度下降**（Stabilized Language Gradient Descent）
4. **技能演化**（Skill Evolution）

### 2.2 核心机制

- **技能工件表示**：每个技能是一个文件系统式结构，包含元数据文件 `skill.yaml`、程序性指令文件 `SKILL.md`，以及可选辅助资源（脚本、引用、配置等）。每个智能体维护一个可演化的技能库 Ki。
- **技能执行方式**：轮询（rollout）时仅注入轻量级元数据（技能名与描述）作为可供调用的工具；智能体自主决定是否调用、调用哪个技能、如何组合技能。只有当技能被选中时，才动态加载其完整 SKILL.md 与资源，以保持上下文精简。
- **技能条件信用分配**：集中式语言评论家（critic）对轨迹中**每个被调用的技能**进行反事实评估，输出结构化自然语言信用，判断该技能是对协作有正向贡献、冗余、造成失败，还是需要泛化/特化。同时产生**智能体级残差信用**，用于捕捉无法归因于任何单一技能的效果，为"新技能归纳"提供触发信号。
- **稳定化语言梯度下降**：
  - **编辑方向提取**：将文本信用信号转换为结构化的轨迹级编辑方向（建议的精炼、调整、泛化或删除）；
  - **层级聚合**：在批量轨迹、技能、智能体、协调拓扑等多个层面递归合并编辑方向，消除冲突、去除冗余；
  - **动量平滑更新**：将当前聚合反馈与历史周期的编辑方向结合，近似数值优化中的动量项，抑制瞬态噪声，鼓励长期一致的技能演化。
- **四类技能演化算子**：
  1. **精炼（Refinement）**：对"有用但不完美"的技能执行局部 patch 式修改，保留未涉及已验证行为；
  2. **归纳（Induction）**：当现有技能库无法解决持久性失败时，从困难轨迹中提出全新技能；
  3. **整合（Consolidation）**：合并功能重叠的技能，形成更高层抽象，控制技能库膨胀；
  4. **剪枝（Pruning）**：定期移除持续低效用、冗余或极少被调用的技能。
- **验证与回滚**：在 held-out 验证集上评估候选技能库，仅当验证性能不低于原版本（设容忍噪声的阈值 δ）时才接受更新，否则回滚——相当于技能空间的"信任域约束"，防止噪声评论或过拟合导致的能力退化。

## 6. 主要结论与发现

- **性能显著提升**：MASkills 在三个 benchmark 上均取得最好成绩——HotpotQA F1 达 76.3（远超最强基线 69.2）；LoCoMo 单跳/多跳 F1 与 BLEU 全面提升（如单跳 F1 27.61 vs. MemGPT 26.65）；GAIA 平均 23.3%（远超 R1-Searcher 20.4%）。
- **演化技能优于即时生成的技能**：对比"提示词生成技能"与 MASkills 迭代优化得到的技能，后者带来显著更大增益（例如 LoCoMo 多跳 F1：0.17 vs. 0.02）。
- **技能具跨任务迁移性**：从源环境学到的技能无需额外优化即可提升未见目标任务表现，说明 MASkills 学到的是可复用的过程性抽象，而非任务特定的提示词技巧。
- **拓扑鲁棒且最优结构因任务而异**：去中心化 peer 结构在 HotpotQA/GAIA 上最佳（有助于多样化探索），集中式在 LoCoMo 上最佳（保持全局一致的长期记忆）；层次化居中——证明框架与特定拓扑解耦。
- **各组件均重要**：消融表明移除任何组件都会降低性能，其中**验证回滚影响最大**（防止迭代崩溃），技能级信用分配其次，动量平滑与整合/剪枝提供一致性增益。

- 通过跨任务迁移、主干泛化、拓扑鲁棒性等实验，证明了所学技能具备超越单一任务上下文的过程性抽象能力，增强了论文结论的一般性。

### 9.3 局限性的全局判断

方法论在**合作式、角色稳定、可自动评估**的环境中表现良好，但其有效性高度依赖两个外部条件：一是强力的中心化评论家 LLM，二是可靠的离线验证环境。当移向开放世界、竞争对抗、动态拓扑或无法低成本自动评分的场景时，MASkills 的若干关键机制能否维持，仍需更多后续工作才能回答。

## 10. 未来研究方向（论文隐含的延展空间）

- **优化器的轻量化与去中心化**：探讨使用开源中等规模模型充当信用分配/技能批评者的可行性，或引入多评论家互相校验来提升信用信号质量；
- **动态协调拓扑**：让智能体在技能层面即可协商、重组协作结构，而非固定于预设拓扑；
- **跨系统技能交换与标准化**：研究技能库的表示标准化与工具化生态，使不同团队建立的多智能体系统之间能够共享与移植技能；
- **开放式环境下的验证替代方案**：在缺少自动回报的真实任务中，探索基于规则、人类偏好模型或自一致性校验的批量验证机制来替代 held-out 回滚；
- **技能库的容量理论**：分析技能数量、抽象层次与任务性能之间的理论关系，刻画"何时应新增、何时应整合"的最优策略。

## 11. 结论（一句话概括）

MASkills 通过将多智能体 LLM 系统的持续改进从"记忆经验"升级为"演化技能"，并配以技能级信用分配、稳定化语言梯度下降与验证回滚机制，在多个多跳推理基准上取得了显著领先，是语言空间中可扩展、可迁移式多智能体策略学习的一次有价值的系统性探索；但其对强评论家与可自动验证环境的依赖，也为后续研究留下了清晰而重要的开放问题。
