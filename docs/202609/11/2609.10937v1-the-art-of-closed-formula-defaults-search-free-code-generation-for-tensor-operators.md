## 摘要
智能体搜索与 GPU 内核自动优化是大型语言模型推理的有力工具。然而，它们的有效性并不取决于搜索本身的复杂程度，而取决于所求解优化问题的清晰程度。我们提供一种应用优先的方法，驱动分层代码生成工具从算子规格说明一直下到 GPU 指令，并表明清晰定义的计算模型使优化问题变得可处理。

## Abstract
Agentic search and automated optimization of GPU kernels are powerful tools for large language model inference. Their effectiveness, however, depends not on the sophistication of the search itself, but on the clarity of the optimization problem being solved. We provide an application-first approach that drives a hierarchical code generation tool from operator specifi cation down to GPU instructions, and show that a clearly defined computational model makes the optimization problem tractable.

### 2. 方法论
- **核心思想**：将张量算子描述为**分层算法树**。树的层级从设备、CU、wavefront 到硬件指令；每层将输入分块、局部计算并累积输出。树由 visitor 惰性遍历：`ComputeVisitor` 用于验证，`EmitVisitor` 用于生成 GPU kernel。二者共享同一棵树，保证“验证的就是编译的”。
- **硬件抽象**：用 `HardwareDescriptor` 和 `MFMAAtom` 编码关键硬件参数，如 LDS 容量、VGPR 预算、wavefront 大小、CU 数量、HBM 带宽、峰值算力、MFMA 指令形状与 dtype。接口最小化，只保留 tile 推导需要的量。
- **CU 为中心的闭式 tile 推导**，按固定顺序施加三个约束：
  - **LDS 约束决定 CU tile**：CU 级同时加载 A、B tile，需满足  
    \[
    (t_M+t_N)\times t_K\times elem \le LDS
    \]  
    取等号且令 \(t_M=t_N\)，可得  
    \[
    t_M=t_N=\left\lfloor\sqrt{\frac{LDS/2}{elem}}\right\rfloor,\quad
    t_K=\left\lfloor\frac{LDS/2}{(t_M+t_N)\cdot elem}\right\rfloor
    \]  
    在 64 KB LDS、4 字节元素下得到 \(t_M=t_N=128,\ t_K=32\)。
  - **VGPR 约束决定 warp tile**：每个线程需保存累加器。若 warp tile 为 \((t_{wm},t_{wn},t_{wk})\)，每线程累加器数为 \(t_{wm}t_{wn}/wf\)。约束写为  
    \[
    V(u)=u\cdot\frac{t_{wn}}{n}\cdot c+V_{overhead}\le V_{budget}
    \]  
    其中 \(u=t_{wm}/m\)，MFMA 形状为 \((m,n,c)\)。warp tile 取满足不等式的最大且与 atom 对齐的尺寸。
  - **CU 数量约束占用率**：网格块数 \(\lceil M/t_M\rceil\times\lceil N/t_N\rceil\) 与 CU 数之比决定占用率。若低于 1，则缩小 tile。
  - **Atom 对齐**：最终 tile 维度必须是 MFMA 形状 \((m,n,k)=(16,16,4)\) 的倍数，避免 padding。
