## 摘要
大语言模型通过合成可执行代码推动了自动化算法发现，但现有框架将其困在具有预定义控制流的刚性搜索流水线中。这一局限限制了自适应推理，阻碍了跨范式迁移，并丢弃了有价值的执行反馈。我们提出 AlgoEvo，一个统一的智能体框架，将自动化算法发现转化为交互式、知识累积的过程。自主智能体基于运行时反馈动态检查、诊断和编辑代码。设计技能中心将特定范式的知识与核心发现引擎解耦，使单一工作流能够无缝处理单目标、多目标和多组件设计。同时，分层经验机制将搜索轨迹组织为任务级树以指导探索，并将跨任务模式整合为可复用技能。在六个代表性基准任务上，AlgoEvo 以显著更少的评估次数和更低的 token 消耗匹配或超越专门方法，展现出强大的任务内累积、跨任务迁移，以及通过灵活技能激活复现或超越现有最先进性能的能力。

## Abstract
Large language models have advanced automated algorithm discovery by synthesizing executable code, but existing frameworks trap them in rigid search pipelines with pre-defined control flows. This limitation restricts adaptive reasoning, blocks cross-paradigm transfer, and discards valuable execution feedback. We propose AlgoEvo, a unified agentic framework that transforms automated algorithm discovery into an interactive, knowledge-accumulating process. An autonomous agent dynamically inspects, diagnoses, and edits code based on runtime feedback. A design skill hub decouples paradigm-specific knowledge from the core discovery engine, allowing a single workflow to seamlessly handle single-objective, multi-objective, and multi-component design. Meanwhile, a hierarchical experience mechanism organizes search trajectories into a task-level tree to guide exploration and consolidates cross-task patterns into reusable skills. Across six representative benchmark tasks, AlgoEvo matches or surpasses specialized methods with substantially fewer evaluations and reduced token consumption, demonstrating strong intra-task accumulation, cross-task transfer, and the ability to reproduce or exceed existing state-of-the-art performance through flexible skill activation.

  - 限制交互式调试、诊断分析与深层结构重构；
  - 范式特定逻辑与框架强耦合，单目标、多目标、多组件任务往往需要维护不同代码库，造成框架碎片化；

- **整体含义**：论文提出 **AlgoEvo**，将自动化算法发现重构为**交互式、知识累积、自演化**的智能体过程。其目标是：用统一引擎处理单目标、多目标、多组件设计，并通过经验积累与跨任务迁移，使算法发现从孤立试错走向持续自我改进的科学过程。

## 2. 方法论

### 2.1 核心思想

- 不再让 LLM 执行固定“生成—评估—选择”循环，而是让**自主智能体**根据运行时反馈动态决定何时检查代码、诊断瓶颈、编辑组件或评估候选。
- 通过两个核心组件支撑统一搜索：
  - **设计技能中心（Design Skill Hub）**：解耦范式特定知识，使同一搜索循环适配不同算法设计范式。
  - **层级经验库（Hierarchical Experience Bank）**：把历史搜索轨迹转化为结构化经验，指导后续探索并抽象为可复用技能。

### 2.2 智能体搜索循环

- 在步骤 \(t\)，发现状态为 \(s_t=(\Pi_t, C_t, E_t, F_d(x|\Pi_t))\)，分别表示当前算法、工作上下文、经验库和性能反馈。
- 智能体选择动作 \(a_t\)，可执行：读取/检查代码、修改策略、运行诊断、评估候选等；执行后产生转移 \(\tau_t=(s_{t-1},a_t,r_t,s_t)\)。
- 当动作更新算法时，即时奖励定义为性能提升：
  \[
  r_t = F_d(x|\Pi_{t-1}) - F_d(x|\Pi_t)
  \]
  \(r_t>0\) 表示改进。最大化累积改进 \(\sum_{t=1}^T r_t\) 等价于最小化最终性能 \(F_d(x|\Pi_T)\)，从而对应全局发现目标。
- 智能体可交错进行诊断、修改和评估：遇到瓶颈时做针对性分析，有证据时进行结构编辑，而非按固定周期运行。

### 2.3 设计技能中心

- 算法空间 \(S\) 的结构依赖范式：单目标构造启发式、多目标进化算子、耦合 destroy-repair 系统在策略角色、接口和有效修改原则上不同。
- AlgoEvo 将这些差异外化为**可插拔设计技能**，新范式只需增加技能，而不修改引擎。
- 每个设计技能声明：
  - 可设计策略 \(\Pi=(\pi_1,\dots,\pi_K)\) 的角色；
  - 代码接口；
  - 指导有效修改的原则；
  - 任务特定评估约定。
- **生命周期**：
  - 任务开始时选择并激活匹配技能；
  - 任务完成时，经验被整合进经验库；技能不在单任务内更新，而是在跨任务层面进化；
  - 当至少两个不同任务的经验一致支持某有效设计模式时，该模式被抽象回技能中心。
- 技能还可编码已有算法设计方法的知识，继承其归纳偏置，同时保留自主执行过程。

### 2.4 层级经验库

- **Level 1：经验卡**  
  评估事件产生奖励，并被蒸馏为经验卡，记录设计上下文、修改内容、奖励和理由。经验卡是经验库基本单元，跨评估和任务持久存在。
- **Level 2：任务级经验树**  
  同一任务的经验卡构成树，节点为卡，边表示“派生自”关系。使用 MCTS 四操作：
  - **选择**：最大化 UCB：
    \[
    UCB(v|q)=\bar r(v|q)+c\sqrt{\frac{2\ln N}{n(v,q)}}
    \]
    其中 \(q\) 是由当前搜索状态和近期反馈总结出的情境，可包含 stagnation、bottleneck、coupling、sparse front 等条件。
  - **扩展**：新验证候选的卡挂到其演化来源节点下。
  - **评估**：候选被评估，产生奖励 \(r_t\)。
  - **反向传播**：奖励传播到祖先节点，维护子树评估次数 \(m(v)\) 和累积奖励 \(S(v)\)，子树价值 \(\bar R(v)=S(v)/m(v)\) 估计设计方向平均奖励。
- **Level 3：跨任务整合**  
  当某设计模式在至少两个任务中被有效决策支持时，被抽象到对应设计技能，把具体经验转化为范式级知识。

### 2.5 算法流程概述

- 匹配任务到技能，初始化经验树，加载相关经验卡；
- 重复：
  - 检测当前搜索情境 \(q\)；
  - 用 UCB 选择经验节点；
  - 智能体执行动作；
  - 若评估候选，则蒸馏经验卡、加入经验库、挂为子节点、计算奖励并反向传播；
- 直到预算耗尽或智能体终止；
- 选择最优算法，并将有效跨任务模式整合进技能中心。

## 6. 主要结论与发现

- AlgoEvo 在六个基准任务上匹配或超越专用方法，同时显著减少评估次数和 token 消耗。
- **单启发式**：TSP 和 CVRP 上训练与测试质量最佳；TSP 比最强 LLM-AHD 基线高 4–7%，比最近邻高 12.3%；约 35–39 次评估即可确定设计，而基线用满 500 次仍落后。
- **多目标**：Bi-TSP 上 HV 和 IGD 最佳；Bi-FJSP 上 HV 最佳，IGD 略逊于 MEoH，但前沿覆盖更广。
- **多组件**：CVRP-DR 两个 split 最佳；FJSP 4-Ops 留出集最佳，并超过专家算子；此类任务使用较多预算，但 token 仍低于多数基线。
- **经验累积有效**：热启动优于冷启动；多轮渐进累积带来单调提升，如 TSP tour 从 4.8928 降至 4.7995，Bi-FJSP HV 从 0.1549 升至 0.1862。
- **跨任务迁移有效**：CVRP→CVRP-DR 平均成本从 10.314 降至 9.816；TSP→Bi-TSP HV 提升约 4.7%。
- **行为差异**：不同种子呈现编辑驱动、诊断驱动或混合风格；诊断驱动种子在该样本中取得最佳成本，但样本量不足以建立确定相关性。
- **方法知识可迁移**：将已有方法编码为技能后，AlgoEvo 可达到或超过原生方法质量，且评估次数更少，说明方法知识可脱离原搜索框架被
