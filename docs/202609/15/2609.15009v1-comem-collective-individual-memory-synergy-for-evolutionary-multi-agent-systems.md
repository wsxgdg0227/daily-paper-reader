## 摘要
设计有效的记忆机制对于推进 LLM 驱动的多智能体系统（MAS）至关重要，有助于智能体共同学习并随时间推移表现更佳。尽管近期工作已带来强大的协作能力，但大多数方法仍使用扁平、无结构的记忆，这类记忆容易被噪声填满，并抹平智能体之间的差异。为解决这一问题，我们引入集体-个体记忆协同的概念，并提出 CoMem，一种将私有经验与共享知识统一用于多智能体学习的架构。CoMem 具有以下特点：(i) 私有经验沉淀，使每个智能体能够随时间保留并更新自身有用的记忆；(ii) 集体智慧策展，仅精心选择被广泛验证的想法在智能体之间共享；(iii) 并行双流检索，使智能体既能从自身记忆又能从群体智慧中获取信息，并利用聚类确保多样性。在 ALFWorld 和 PDDL 基准上的实验表明，CoMem 取得了强劲的总体性能，并稳健地避免了记忆污染。

## Abstract
Designing effective memory mechanisms is crucial for advancing LLM-driven Multi-Agent Systems (MAS), helping agents learn together and perform better over time. While recent work has led to strong cooperation skills, most methods still use flat, unstructured memories, which easily get filled with noise and erase differences between agents. To address this, we introduce the concept of collective-individual memory synergy and propose CoMem, an architecture that unifies both private experience and shared knowledge for multi-agent learning. CoMem features:(i) Private Experience Sedimentation, which lets each agent keep and update its own useful memories over time;(ii) Collective Wisdom Curation, which carefully selects only widely proven ideas to be shared among agents;(iii)Parallel Dual-Stream Retrieval, which allows agents to draw both from their own memory and the group's wisdom, using clustering to ensure diversity.Experiments on ALFWorld and PDDL benchmarks show that CoMem achieves strong overall performance and robustly avoids memory pollution.

  - **(b) 行为同质化（behavioral homogenization）**：不同角色的策略轨迹被反复覆盖与"平均化"，角色特异性丧失，论文形式化为 \(\lim_{t\to\infty} H(\pi_{a_i}\|\pi_{a_j}) = 0\)。

- **目标**：构建解耦的记忆空间 \(\mathcal{M} = \langle \{M^{(i)}_{priv}\}_{i=1}^{|A|}, M_{coll} \rangle\)，在保留个体专长的同时，仅在群体层面沉淀经过验证的通用智慧。

## 2. 方法论

### 2.1 核心思想

- 双层、物理隔离的记忆架构：
  - **私有层（Private Layer）**：每个智能体独占，杜绝跨智能体污染；
  - **集体池（Collective Pool）**：只接纳通过严格实证验证的洞见。
- 双向流动形成良性循环：私有层向上"晋升"可信发现，集体池向下"引导"个体行为。

### 2.2 关键技术细节

**（1）记忆元数据结构**

- 每条记忆 \(m = \langle \text{doc\_content}, \text{metadata} \rangle\)，其中 \(\text{metadata} = \{\text{agent\_name}, S, n_{use}, n_{succ}, \iota_{prom}\}\)，分别表示归属智能体、效用分、调用次数、成功次数、晋升状态。

**（2）私有经验沉淀（Private Experience Sedimentation）**

- 每个 episode 结束后，智能体 \(a_i\) 从执行轨迹 \(\tau^k_i = \{(s_1,x_1,y_1),\dots\}\) 中，由**基于 LLM 的反思蒸馏器（Reflection Distiller）**从自身视角提炼出少量简洁、可迁移的文本洞见，写入 \(M^{(i)}_{priv}\)，初始效用分为 \(S_0\)。
- 严格按智能体身份做访问控制，保证存储层零污染。
- **滚动剪枝（Rolling Pruning）**：为每条未晋升条目维护连续未命中计数 \(K_{miss}(m)\)；被检索注入提示则清零，否则 +1；超过阈值 \(K_{max}\) 即永久删除，以过滤陈旧/无用知识。

**（3）集体智慧策展（Collective Wisdom Curation）**

- **实证晋升门（Empirical Promotion Gate）**，采用基线条件化的合取判据：
  \[
  \iota_{prom} = \mathbb{I}\big[(N_{use}(m) \ge N_{min}) \wedge (\bar{R}_m \ge \bar{R})\big]
  \]
  即要求"足够曝光（统计下限 \(N_{min}\)）"且"平均任务得分 \(\bar{R}_m\) 不低于环境全局滑动基线 \(\bar{R}\)"。晋升后条目复制到 \(M_{coll}\)，并从原私有库移除以避免冗余。
- **混合效用评估**：对每条被检索的集体条目计算
  \[
  U_t(m) = w \cdot R_{norm} + (1-w)\cdot\Big(\frac{1}{|A_m|}\sum_{a\in A_m}\frac{\mathrm{LLM}_a(m)}{L_{max}}\Big)
  \]
  即客观归一化奖励与 LLM 主观评分的加权融合。
- **长期效用 EMA 更新**：
  \[
  S_{t+1}(m) = (1-\alpha)S_t(m) + \alpha\,(S_{max}\cdot U_t(m))
  \]
  分数持续低于自适应阈值的条目被系统性清除，使集体池保持精简、相关、长期有效。

**（4）并行双流检索（Parallel Dual-Stream Retrieval）**

- 新任务查询到来时，每个智能体**同时**从两个隔离库检索，避免串行查找瓶颈，也避免跨层污染：
  - **私有流**：基于语义嵌入相似度（RAG 式）取 top-k 私有条目，注入提示以提供个性化战术指导；
  - **集体流 + 多样性过滤**：从共享池检索经实证验证的条目，并引入**在线层次聚类**，按语义距离分组、每组只保留最具代表性的条目，压缩冗余、节省 token，同时保证视角结构丰富。

## 6. 主要结论与发现

- **结论 1（性能一致性）**：CoMem 在所有 4 个框架上均取得最强或接近最强的结果。MacNet 上 ALFWorld 从 79.85 → 89.55，PDDL 从 60.78 → 70.19；平均绝对提升为 **ALFWorld +8.02、PDDL +4.70**。即便在强基线 CARD 上（ALFWorld 84.33、PDDL 70.01），仍提升至 90.30 与 72.74。
- **结论 2（共享记忆常"帮倒忙"）**：传统协作式共享记忆频繁低于无记忆基线。例如 DyLAN+PDDL 下 G-Memory 为 59.53（No-memory 67.78），MetaGPT 降至 52.80。单智能体记忆迁移方案（Voyager、MemoryBank）表现不稳定，时好时坏——与"噪声累积 + 行为同质化"的记忆污染机制吻合。
- **结论 3（成本可控）**：CoMem 以适度 token 增量（源于并行双流检索与晋升验证）换取稳定增益；而协作基线常常花费相当甚至更多 token 却无一致收益，性价比更优。
- **结论 4（检索深度）**：性能对 \(k\) 呈领域/框架依赖的最优点，中等取值 \(k \in \{3,5\}\) 最稳健；\(k\) 过大会注入噪声，过小会缺失上下文（AutoGen-PDDL 上 \(k=1\) 的 74.80 与 \(k=5\) 的 80.40 相差 5.60 分）。
- **结论 5（两层缺一不可）**：完整 CoMem 优于任一单层变体。AutoGen+PDDL 上去掉集体层下降 12.03 分（74.44→62.41），去掉私有层下降 9.34 分（74.44→65.10），说明**私有层是更强的抗污染屏障**，但两层功能互补、均不可替代。
- **结论 6（超参规律）**：\(K_{max}\) 与 \(\alpha\) 均呈**倒 U 型**关系。PDDL 最优 \(K_{max}=5\)（74.44），ALFWorld 最优 \(K_{max}=6\)（88.81）；\(\alpha\) 过小（0.3）导致评分滞后、过大（0.8）导致对单次异常过度反应，两基准最优均为 **\(\alpha=0.5\)**，可作为稳健默认值。

- **LLM 评分引入主观偏差风险**：集体条目的混合效用依赖 LLM 主观评分，可能受评分模型偏好、提示模板、位置偏差等影响；若评分模型与执行模型同源，还可能放大既有偏差。
- **超参数仍需领域调优**：\(K_{max}\) 与 \(\alpha\) 虽呈倒 U 型且 \(\alpha=0.5\) 较稳健，但 \(K_{max}\) 在两个基准上最优值不同，说明实际使用中仍需一定调参成本。
- **对抗与安全场景未涉及**：私有层可防跨智能体污染，但若某个智能体被恶意操控或持续产生高奖励但有害的“成功经验”，晋升门是否仍能可靠拦截，论文未作讨论。
- **与更简单筛选机制的对照缺失**：未与“规则过滤”“人工审核”“固定阈值筛选”等无 LLM 或弱 LLM 方案比较，因此 LLM 反思蒸馏器与 LLM 效用评分的独立贡献尚难完全剥离。

## 9. 总体评价与启示

CoMem 的核心价值在于把“群体记忆”从单一共享池重构为**私有经验层与集体共识层解耦**的双层架构，并用“反思蒸馏—实证晋升—效用演化—剪枝遗忘—双流检索”构成较完整的记忆生命周期。它针对的不是单纯“记忆容量”问题，而是 MAS 长期协作中更隐蔽的**记忆污染与行为同质化**问题，问题意识明确，机制设计有较强针对性。

从实验结论看，传统协作式共享记忆在多个框架上反而低于无记忆基线，这一发现对当前“多智能体共享记忆越多越好”的直觉构成有力反例；而 CoMem 在 4 个 MAS 框架、2 个基准上均取得稳定增益，说明“先个体验证、再集体沉淀”的路径具有跨框架潜力。其插件式、骨干无关设计也提升了工程可用性。

未来可优先补足的方向包括：公开算力与复现细节、增加多种子与显著性检验、扩展消融到全部宿主框架、验证跨域与超长时程稳定性、引入对抗鲁棒性测试，并探索自适应超参与更可解释的晋升准则。总体而言，CoMem 为 MAS 的可持续群体记忆提供了一种结构清晰、可插拔且具启发性的解决方案。
