## Abstract
Large language model (LLM) driven multi-agent systems have shown promise in complex clinical reasoning, yet existing approaches rely on static strategies and lack persistent clinical memory, preventing self-evolving from prior diagnostic successes and failures. We present EMR, a self-evolving medical multi-agent system via Experience Mining and Reuse. EMR introduces a hierarchical clinical experience library that organizes accumulated knowledge into three levels: clinical principles, diagnostic patterns, and representative cases. During inference, EMR emulates multidisciplinary consultation: a planner agent coordinates domain-specific department agents for specialized reasoning, while a summary agent synthesizes their analyses into a final decision. Critically, EMR automatically extracts correct diagnostic insights and failure-related warnings from multi-agent reasoning trajectories, incrementally updating the experience library to guide future cases. ## 1. 核心问题与整体含义

- **研究背景**：LLM 驱动的多智能体系统在复杂临床推理中展现出潜力，可通过角色分工模拟多学科会诊。
- **核心问题**：
  - 现有医疗多智能体系统大多依赖**静态推理策略**，面对复杂或未见病例时容易重复诊断错误。
  - 系统通常将每个任务视为**孤立实例**，缺乏持久化临床记忆，无法从既往成功经验与失败教训中持续学习。
  - 已有经验驱动方法多停留在原始轨迹存储、扁平摘要或图结构记忆，缺乏系统化抽象、分层复用与跨智能体迁移能力。
- **整体含义**：论文主张多智能体系统应显式地从自身推理轨迹中抽取可复用知识，并存储为可迁移、可扩展、模型无关的经验，从而在不更新模型参数的前提下实现“自演化”。EMR 将这种经验对应为临床指南、诊断启发式与代表性病例。

## 2. 方法论

### 2.1 核心思想

- EMR 由三部分组成：
  - **多智能体医疗系统**：模拟多学科会诊。
  - **经验挖掘**：从协作推理轨迹中提取成功与失败经验。
  - **经验复用**：通过分层经验库增量更新与检索，指导后续推理。
- 关键特点：不修改 LLM 参数，而是将经验作为外部、模型无关的知识源动态注入推理过程。

### 2.2 多智能体医疗系统

- **规划智能体（Planner Agent）**：
  - 识别问题级医学领域 \(D_q\) 与选项级领域 \(D_o\)，将推理空间分解为专科子问题。
  - 结合检索到的经验 \(E_r\)，避免冗余探索和既往错误。
  - 形式化：\(D_q = LLM(q, E_r \mid r_p, \pi_q)\)，\(D_o = LLM(q, O, E_r \mid r_p, \pi_o)\)。
- **科室智能体（Department Agents）**：
  - 每个领域 \(d\) 对应一个专科专家智能体，结合问题、选项、领域与检索经验进行推理。
  - 形式化：\(a_d = LLM(q, O, d, E_r \mid r_d, \pi_d)\)，所有分析汇总为 \(A = \{a_d \mid d \in D_q \cup D_o\}\)。
- **总结智能体（Summary Agent）**：
  - 整合跨科室分析，解决冲突并纠正局部错误。
  - 形式化：\(\hat{y}, a_{sum} = LLM(q, O, A, E_r \mid r_s, \pi_s)\)。

### 2.3 经验挖掘

- **轨迹生成**：记录完整推理轨迹 \(\tau = (q, O, D_q, D_o, A, a_{sum}, \hat{y})\)，并与真实答案 \(y\) 比较，判断成功或失败。
- **经验收集与分类**：
  - **Golden Experience**：来自成功轨迹，捕捉有效推理策略、诊断原则与验证过的决策模式。
  - **Warning Experience**：来自失败轨迹，总结失败原因、误导线索与反复出现的错误模式。
  - 形式化：\(\epsilon = Collect(\tau, y \mid r_c, \pi_c)\)。
- 通过双通道学习，既利用正确路径，也避免重蹈覆辙。

### 2.4 经验复用

- **分层经验库**：
  - \(L = \{L_{principle}, L_{pattern}, L_{case}\}\)。
  - **原则层**：抽象诊断规则与高层推理原则。
  - **模式层**：可复用推理结构与决策模板。
  - **案例层**：具体临床场景与详细推理痕迹。
- **更新机制**：
  - 对新经验 \(\epsilon\)，先检索相关经验 \(R = Retrieve(L_t, \epsilon)\)。
  - 计算语义相似度：\(Sim(\epsilon, R) = \max_{\epsilon_i \in R} \cos(e(\epsilon), e(\epsilon_i))\)。
  - 若相似度低于阈值 \(\theta\)，直接加入；否则由 LLM 判断合并或丢弃。
  - 默认阈值 \(\theta = 0.85\)。
- **检索机制**：
  - 根据查询上下文 \(c\) 检索 \(E_r = Retrieve(L, c, k)\)，默认检索 3 条。
  - 分层检索：先高层原则，再推理模式，最后具体案例。
  - 检索结果注入规划、科室与总结智能体，作为外部指导。

## 6. 主要结论与发现

- **整体性能**：
  - Qwen3-8B 上，EMR 平均准确率从 MDAgents 的 77.8 提升至 **81.1**。

- **迁移性**：

- **效率与泛化**：

- **失败模式分析**：
  - 参数知识依赖、医学概念混淆、浅层因果推理、集体幻觉是常见失败模式。

## 7. 优点

- **显式分层经验建模**：将经验组织为原则、模式、案例三级，兼顾泛化性与细节保留。
- **成功与失败双通道学习**：Golden 与 Warning 经验互补，提升鲁棒性并避免重复错误。
- **模型无关且可解释**：不修改模型参数，经验以自然语言存储，人类可读，便于审查与迁移。
- **架构无关性**：可嵌入其他医疗多智能体框架，如 MDAgents 与 RECONCILE。
- **效率较优**：相比多轮讨论式多智能体方法，token 与时间开销更低。
- **实验较全面**：覆盖多数据集、多模型、消融、迁移、鲁棒性、效率与泛化分析。
- **临床流程模拟合理**：规划、专科、总结三阶段与多学科会诊过程对应，具有一定可解释性。

## 8. 不足与局限

- **模态覆盖有限**：仅针对文本医学问答，未纳入医学影像、实验室信号、电子健康记录等多模态临床信息。
- **经验质量依赖底层 LLM**：错误或幻觉轨迹可能引入噪声经验；虽然相似度更新可部分缓解，但仍需更稳健的验证与过滤机制。
- **检索机制较简单**：主要依赖语义相似度与分层抽象，可能无法充分捕捉复杂医学因果关系；经验库增大后检索效率与长期维护面临挑战。
- **缺乏真实临床验证**：实验为受控离线基准评估，未在真实临床环境中验证，输出不应被视为临床建议。
- **潜在偏差放大**：从特定数据集或 LLM 挖掘的经验可能过度代表某些疾病分布、推理风格或临床假设，影响对多样人群和罕见病例的鲁棒性。
- **隐私与安全风险**：若扩展到真实患者数据，经验存储与检索可能涉及隐私和安全合规问题。
- **计算成本增加**：相比单智能体系统，多智能体协作仍显著增加计算成本与推理延迟，可能限制资源受限场景的部署。
- **算力细节缺失**：未报告 GPU 型号、数量等硬件信息，复现与成本评估存在一定不透明性。
