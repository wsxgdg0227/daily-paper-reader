## 摘要
数字智能体常常必须适应新环境，而这些环境的接口、工具和失效模式并未被预训练模型充分刻画。我们提出 RSIAgent，一个无需训练的多智能体框架，通过自主记忆构建实现递归自我改进。RSIAgent 协调课程智能体、执行者智能体和验证者智能体，持续探索环境、验证结果，并保留环境特定的知识，包括动作、条件与后果之间可复用的因果关系。它还采用先广后深的探索策略，将用于发现多样环境结构的并行广泛递归自我探索，与用于揭示困难案例、隐藏约束、边界条件以及此前未知因果依赖的聚焦深度自我探索相结合。由此得到的记忆会被冻结，并可直接复用于下游任务，而无需更新模型参数。在 OSWorld-v2 和 Agent's Last Exam 上的实验表明，RSIAgent 显著提升了强大的开源模型，使 Kimi-K3 和 GLM-5.3 能够超越包括 GPT-6 在内的前沿闭源模型。

## Abstract
Digital agents must often adapt to new environments whose interfaces, tools, and failure modes are not fully captured by pretrained models. We introduce \textbf{RSIAgent}, a training-free multi-agent framework for recursive self-improvement through autonomous memory construction. RSIAgent coordinates curriculum, actor, and verifier agents to continually explore the environment, validate outcomes, and retain environment-specific knowledge, including reusable causal relationships between actions, conditions, and consequences. It further adopts a \textbf{broad-then-deep} exploration strategy, combining parallel broad recursive self-exploration for discovering diverse environment structures with focused deep self-exploration for uncovering hard cases, hidden constraints, boundary conditions, and previously unknown causal dependencies. The resulting memory is frozen and can be directly reused for downstream tasks without updating model parameters. Experiments on OSWorld-v2 and Agent's Last Exam show that RSIAgent substantially improves strong open-source models, enabling Kimi-K3 and GLM-5.3 to outperform frontier closed-source models including GPT-6.

- **核心问题**：论文提出一个根本性追问——**智能体能否在新环境中自主发现因果关系，并将其组织为可复用的记忆，从而实现自我改进**，而无需更新模型参数？
- **整体含义**：作者类比人类学习新软件的过程（先确定学什么 → 与环境交互积累经验 → 从结果中蒸馏知识），认为这不只是经验堆叠，更是一种**因果发现**过程：通过主动尝试不同动作并观察后果，逐步推断决定成败与状态转移的关键因素。RSIAgent 正是这一过程的工程化实现。
- **定位**：一种**免训练（training-free）** 的智能体级自我改进范式，用上下文与记忆管理替代参数更新，目标是缩小甚至逆转开源与闭源基础模型之间的能力差距。

## 2. 方法论

### 2.1 核心思想

- 采用**多智能体 harness 框架**，通过“课程—执行—验证”的递归闭环，持续探索环境、验证结果、沉淀环境特定知识（含可复用的因果关系）。
- 采用**先广后深（broad-then-deep）** 的两阶段探索：先用广度探索建立环境整体覆盖，再用深度探索攻坚难例、隐藏约束与边界条件。
- 探索结束后记忆被**冻结**，在测试时直接复用，模型参数全程不变。

### 2.2 形式化设定

- 给定任务指令 \(q\)，智能体 \(\pi_\theta\) 在步骤 \(t\) 依据交互历史 \(h_t=(o_0,a_1,\dots,a_{t-1},o_{t-1})\) 与持久记忆 \(M\) 生成动作：
  - \(a_t \sim \pi_\theta(\cdot \mid q, h_t, M)\)
  - \((s_t, o_t) \sim \mathcal{E}(\cdot \mid s_{t-1}, a_t)\)
- \(s_t\) 为不可直接观测的环境底层状态；交互历史在切换任务时重置，而 **\(M\) 跨任务持久保留**。
- 实现上采用 **code-as-policy**：每个动作 \(a_t\) 是一段可执行程序（Python/Bash），作为控制异构软件（含 GUI 应用）的通用接口。

### 2.3 三个智能体角色

- **Actor（执行者）智能体**：主策略模型，负责理解环境并生成可执行动作；配备**可演化记忆**，在验证后新增、修订或删除知识，更新后的记忆被子后续 Actor 实例继承。
- **Verifier（验证者）智能体**：独立评估者，直接检查环境反馈（执行结果、界面状态等可观测证据）并给出 PASS/FAIL（目标场景还支持 UNVERIFIED）；**与 Actor 的私有推理和记忆隔离**，以降低相关性错误。
- **Curriculum（课程）智能体**：高层协调者，依据目标、当前记忆与历史结果生成练习任务，选择前置技能、信息性变体、失败驱动练习与压力测试用例；当新任务预期不再带来显著新知识时停止探索。

### 2.4 两阶段探索流程（算法流程）

- **Stage-1 广度递归自我探索（BRS）**：
  - 课程智能体每轮提出**多个不同方向的探索任务**，并行执行与验证；
  - 收集轨迹与验证反馈后，识别剩余知识缺口，生成下一轮更具信息量的任务；
  - 递归扩展环境特定知识、可复用流程与失败模式的覆盖面。
- **Stage-2 深度递归自我探索（DRS）**：
  - 课程智能体先提出**可能暴露隐藏约束或记忆弱点的高难度任务**；
  - Actor 借助已有记忆尝试，Verifier 给出接地反馈；
  - 依据成败与新暴露的不确定性，课程智能体生成**更具挑战性的后续任务**；
  - 每个经验在被验证后先写入记忆，再提出下一任务，持续推向更难、更少探索的案例。
- **测试时记忆复用**：冻结记忆后关闭课程智能体与一切记忆更新；Actor 直接复用记忆中的流程、约束与失败教训，Verifier 对照任务要求评估，循环直至满足全部要求。

### 2.5 关键实现细节（附录）

- **经验归属学习**：产出该经验的 Actor 负责蒸馏（distillation）与调和（reconciliation），检查与旧记忆的矛盾并限定结论范围；失败经验也可贡献证据，但不能记为已验证成功。
- **规范记忆所有权**：只有完成的 Actor 学习更新才会被提升为持久记忆；课程智能体只能查看一次性副本，其本地编辑不同步回主记忆。
- **并行工作、顺序更新**：BRS 中同一波次的所有项目共享同一份不可变的波前记忆快照，互不可见；待全部判定完成后，各 Actor 上下文按课程智能体指定顺序**逐个**提交到最新规范记忆。
- **验证与评测分离**：Verifier 在 QEMU checkpoint 保护的候选副本上探查，结束后恢复，避免探查改变被评状态；最终由官方评测器在全部智能体上下文之外打分。
- **记忆冻结评测**：记录冻结记忆的文件树哈希，拷入评测环境，禁用课程决策与宿主记忆回写。

- **不足与偏差风险**（论文在附录中较为坦率地承认）：
  - **聚合口径不一致**：OSWorld 的 RSI 行仅替换了 41 个非诊断性 RSI 结果，其余任务保留基线分数；ALE 行由 19 个 RSI 分数与 48 个基线分数混合而成。保留的基线分数并非独立的 RSI 评测结果。
  - **任务选择偏差**：扩展队列按“基线未满分且尚未被 RSI 覆盖”的规则挑选任务，天然偏向有提升空间的任务；基线满分任务不做额外探索。
  - **非匹配协议比较**：跨系统对比使用各系统原始 harness 与执行预算，未做统一评测协议；ALE 上部分记录包含本地修正分数、公开标签迁移的 ECG 结果等。
  - **重复次数有限**：Full RSI 的分数是两个历史冻结记忆评测的均值，消融中单阶段条件多来自单次记录，而非多次重复。
  - **指标不一致**：ALE 上 RSIAgent 的 Binary 为 50.75，低于 GPT-6 Astra 的 52.24，部分优势并不延伸到所有指标。
  - **异常值处理**：OSWorld 的 T082 因 setup 失败无有效官方分数，按约定计为 0。

## 6. 主要结论与发现

- **RSI 有效提升聚合性能**：OSWorld Partial 从 71.97 → 78.98，Binary 从 37.80 → 42.68；ALE Partial 从 83.75 → 84.82，Binary 从 49.25 → 50.75。
- **开源模型可超越闭源前沿模型**：使用 GLM-5.3 与 Kimi-K3 的 RSIAgent 在 OSWorld 2.0 达 78.98、ALE 达 84.82，分别超出 GPT-6 Astra 报告值 6.38 与 2.56 个百分点，也高于 Claude Opus 5。
- **两阶段互补且缺一不可**：四任务消融中 Full RSI 平均 74.54%，仅广度 65.52%，仅深度 56.50%；仅深度在 T085、T089 上甚至低于基线，说明必须先广度覆盖再深度精修。
- **分数提升呈离散跃迁**：随着记忆逐步覆盖目标任务的关键要求，解决某个瓶颈会带来分数的台阶式上升（T044/T065 达 100%，T049 达 80%）。
- **游戏开发场景同样受益**：RSIAgent 在四类基座生成器上均一致提升游戏质量（如 Codex+GPT-5.5 组 Overall 52.77 → 61.28），而 Play2Code 在强基座上收益递减甚至退化。
- **三类失效机制**：探索目标不精准（目标技能错配、假设未被挑战）、验证不完整（接地缺口、覆盖缺口、保真缺口）、记忆固化不可靠（规则作用域丢失、不确定性未被强制执行）。

## 7. 优点

- **免训练、可迁移**：不更新任何模型参数，通过冻结记忆直接复用，规避了再训练的高成本与私有环境数据采集难题。
- **多智能体角色隔离设计**：Verifier 与 Actor 的私有推理、记忆完全隔离，且验证基于环境证据而非 Actor 自述，能有效抑制相关性错误。
- **先广后深策略有明确类比**：BRS 对应“预训练”式广度覆盖，DRS 对应“后训练”式精修，结构清晰且消融验证

了两阶段互补的必要性，也为“为何不能只做深度精修”提供了直接证据。

- **记忆更新机制工程化程度高**：通过“波前不可变快照 + 全部判定后顺序提交”，避免了并行探索时的记忆写冲突与相互污染；规范记忆只由完成任务的 Actor 提交，课程智能体仅有只读副本，权责边界清晰。
- **验证—评测解耦**：Verifier 在 QEMU checkpoint 保护的候选副本上探查并在结束后回滚，既保证验证的接地性，又避免验证行为本身改变被评状态；最终分数由官方评测器在智能体上下文之外给出，降低了“自己判自己”的风险。
- **负面经验被显式利用**：失败经验可写入记忆作为负证据，但不允许被记作已验证成功，这一约束既保留了失败信息的价值，又防止错误知识被固化。
- **场景覆盖有广度**：同时覆盖桌面 GUI、任务型 Web、专业软件（REAPER、FreeCAD、3D Slicer）、可验证交付物工作流与自主游戏开发，说明该范式不局限于单一环境类型。
- **对自身缺陷较为坦诚**：附录主动披露了聚合口径、任务选择偏差、非匹配协议比较、重复次数有限等问题，学术诚实度较高，也为后续复现与批判性评估留出了空间。

## 8. 局限与不足

- **测试时成本不可忽视**：BRS/DRS 需要大量探索、练习与验证调用（OSWorld 练习预算达 2,000 次迭代、86,400 秒看门狗），论文虽承认“可能带来可观的计算成本”，但未给出硬件级量化，难以评估其性价比边界。
- **记忆冻结后丧失在线适应能力**：冻结记忆虽保证了评测的确定性与可复现性，但也意味着部署后若环境发生漂移（接口变更、版本升级），记忆可能失效甚至产生误导，论文未系统讨论再冻结/增量刷新策略。
- **对基座模型能力存在依赖**：Actor、Verifier、Curriculum 三角色均需较强模型支撑，尤其 Verifier 的判断质量直接决定记忆的可信度；弱基座下该范式是否仍然成立，论文证据有限。
- **失效机制尚未被根治**：论文自述的三类失效——探索目标不精准、验证不完整、记忆固化不可靠——本质上说明“因果发现”仍是启发式近似，可能把相关性误当作因果性并写入长期记忆。
- **评测公平性存疑**：RSI 行与基线行分数来源不同（部分替换、部分混合），且任务按“有提升空间”筛选，聚合增益存在被高估的风险；单阶段消融多为单次记录，方差未知。
- **指标层面优势不全面**：ALE 上 Binary 指标（50.75）低于 GPT-6 Astra（52.24），说明该方法更擅长“部分正确”的推进，而非稳定达成满分交付。
- **泛化边界未验证**：练习任务由课程智能体自行生成，其分布与目标任务的关系缺乏形式化刻画，“记忆是否只对相似任务有效”缺少跨任务族的迁移实验。
- **可复现性信息缺口**：未报告 GPU 型号/数量，也未完整给出提示词、记忆 schema 与课程停止判据的全部细节，独立复现难度较高。

## 9. 启示与未来方向

- **“记忆即能力”的新范式**：在参数规模与训练数据趋于饱和的背景下，RSIAgent 提示了一条以**上下文与结构化记忆**为增长点的路径——智能体能力可以“外挂”而非“内化”，并可在不同基座间移植。
- **因果发现视角的价值**：把环境适配从“模仿轨迹”重构为“推断成败与状态转移的决定因素”，为设计更具样本效率的探索策略提供了理论抓手（如主动挑战假设、定向补足覆盖缺口）。
- **验证器是新的瓶颈**：既然记忆质量受制于验证可靠性，未来工作可聚焦于更强的接地验证（如引入可执行断言、形式化契约、多验证器交叉审查）以缓解“覆盖缺口/保真缺口”。
- **记忆生命周期管理**：包括记忆的压缩、去重、冲突消解、作用域标注与过期机制，以及环境漂移下的增量再冻结，都是自然且必要的后续课题。
- **成本—收益权衡研究**：需要建立“探索预算 vs 目标性能”的定量曲线，明确在何种任务难度与基座水平下 RSI 才划算，避免对简单任务过度练习。
- **跨环境记忆迁移**：若不同软件共享因果结构（如“保存前需先确认格式”），则可探索记忆的抽象化与跨域复用，进一步提升探索效率。

## 10. 总体评价

RSIAgent 提出并系统验证了一种**免训练、智能体级、以记忆为载体的递归自我改进范式**：通过 Curriculum–Actor–Verifier 的分工与“先广后深”的两阶段探索，把环境交互结果蒸馏为可复用的因果关系与操作知识，并在测试时冻结复用。其最大贡献不在于单点指标，而在于示范了“不更新参数也能显著提升新环境表现”的可行性——尤其在 OSWorld 2.0 与 ALE 上，开源基座组合能超越闭源前沿模型报告值，具有较强的示范意义。

同时，论文的结论应被谨慎解读：聚合口径不统一、任务选择偏向有提升空间的样本、重复次数有限、Binary 指标未全面领先等问题，意味着当前增益幅度可能被部分高估；三类失效机制也表明该方法尚未达到可靠的因果发现水平。总体而言，这是一项**思想清晰、工程扎实、验证尚需加强**的工作：它把“测试时算力”确立为与“训练时算力”并列的能力杠杆，并为后续在验证可靠性、记忆生命周期与成本控制方向的研究提供了明确入口。
